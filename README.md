## 🚀 国内镜像

1. 打开 https://dash.cloudflare.com → Workers & Pages
2. 点 **Create** → **Pages** → **Connect to Git**
3. 授权 Cloudflare 访问 GitHub，选择 `s66899/lamb` 仓库
4. 部署配置：分支 `book`，框架预设 `None`，输出目录 `/`
5. 点 **Save and Deploy**，等1分钟获得 `xxx.pages.dev` 域名
