## 📖 每章结构

每章均包含三部分：

1. **专业知识详解**（60%）—— 该主题的核心专业知识
2. **动机心理学分析**（30%）—— 用快乐原则解释为什么拖延、如何克服
3. **行动建议**（10%）—— 具体可操作的实践建议
