# 第二章 整体方案设计

## 2.1 设计要求分析

### 2.1.1 功能需求

根据前期调研和用户需求分析，本设计需要满足以下功能需求：

1. **辅助起身功能**：帮助老年人从坐姿状态顺利转换到站姿状态
2. **辅助下落功能**：帮助老年人从站姿平稳坐回坐姿
3. **折叠收纳功能**：不使用时可折叠，减小占用空间
4. **高度调节功能**：适应不同用户的身高和使用习惯
5. **一键控制功能**：操作简便，老年人可独立使用
6. **安全保护功能**：具备自锁和紧急停止功能

### 2.1.2 性能指标

本设计的性能指标要求如下：

| 参数 | 指标值 |
|------|--------|
| 额定载荷 | ≥150kg |
| 升降行程 | 150-250mm |
| 升降速度 | 10-20mm/s |
| 折叠角度 | 0°-90° |
| 电源 | 24V直流 |
| 电机功率 | ≤100W |

### 2.1.3 安全要求

1. 具备机械自锁功能，断电状态下不会快速下降
2. 设置紧急停止按钮
3. 设置限位开关，防止超程运行
4. 具备过载保护功能

## 2.3 传动方案设计

### 2.3.1 驱动方式选择

根据设计要求，本产品可采用以下几种驱动方式：

**方案A：丝杆传动**

优点：定位精度高，自锁性能好
缺点：效率较低，噪音较大

**方案B：蜗轮蜗杆传动**

优点：具有自锁功能，结构紧凑，传动平稳
缺点：效率较低，加工精度要求高

**方案C：液压驱动**

优点：承载能力强，运行平稳
缺点：需要液压站，结构复杂，维修困难

**本设计采用方案B：蜗轮蜗杆传动**

选用蜗轮蜗杆传动的主要原因：
1. 蜗轮蜗杆具有可靠的机械自锁功能，安全性好
2. 结构紧凑，适合本产品的空间限制
3. 传动平稳，噪音低
4. 配合无刷电机，可实现精确的速度控制

### 2.3.2 电机选型

选用57无刷直流电机，主要参数：
- 电压：24V
- 扭矩：0.44N·m
- 功率：可满足升降需求
- 带译码器，可实现闭环控制

## 2.4 折叠机构设计

### 2.4.1 折叠方案分析

折叠机构是本设计的核心创新点之一。根据思维导图设计，座椅部分需要实现0°-90°的折叠角度。

**折叠方式选择**：

1. **铰链+限位块方式**：结构简单，成本低，但角度固定不可调
2. **卡槽限位方式**：角度可调，但长期使用可能松动
3. **液压支撑杆方式**：具有缓冲功能，但成本较高
4. **气弹簧方式**：可实现自动弹回，但需要配合其他限位

**本设计采用：铰链+限位块方式**

在底座与支撑杆连接处安装铰链，配合90度限位块实现折叠功能。

### 2.4.2 限位块设计

根据设计资料，限位块尺寸计算如下：

已知：
- 旋转半径 R（铰链中心到旋转板边缘）
- 限位角度 θ = 90°

限位块弧长计算：
```
L = 2 × π × R × (θ / 360°)
```

限位块高度：
```
h = R × sin(θ/2)
```

限位块宽度：
```
b = R × (1 - cos(θ/2))
```

示例（R = 80mm）：
- 弧长 L ≈ 125.6mm
- 高度 h ≈ 56.6mm
- 宽度 b ≈ 23.4mm

## 2.5 材料选择

### 2.5.1 框架材料

选用6063铝合金作为框架材料，具有以下优点：
- 密度小，质量轻
- 强度高，承载能力强
- 耐腐蚀性好
- 易于加工成型
- 表面处理多样（阳极氧化、喷塑等）

### 2.5.2 座椅材料

座圈和座椅部分选用：
- **主体**：抗菌塑料（PP或ABS）
- **坐垫**：软质PU材料，舒适易清洁

### 2.5.3 紧固件材料

螺栓、螺母等紧固件选用304不锈钢，具有良好的耐腐蚀性。

## 2.6 控制方案设计

### 2.6.1 控制方式

采用一键启动的控制方式，操作简便：
1. 按下启动按钮
2. 设备自动执行上升/下降
3. 到达目标位置后自动停止

### 2.6.2 控制模块组成

1. **主控芯片**：单片机或PLC
2. **电机驱动**：无刷电机驱动器
3. **传感器**：限位开关、位置传感器
4. **安全模块**：过载保护、紧急停止

### 2.6.3 安全控制策略

1. **机械自锁**：蜗轮蜗杆传动提供基础自锁
2. **电气制动**：电机驱动器内置制动功能
3. **软起动/软停止**：避免速度突变
4. **急停功能**：紧急情况下立即停止

## 2.7 本章小结

本章根据设计要求，确定了可折叠辅助站立坐便椅的总体方案。采用蜗轮蜗杆传动机构实现升降功能，具有可靠的自锁性能；采用铰链+限位块方式实现折叠功能；选用铝合金作为框架材料，抗菌塑料和PU材料作为座椅材料；采用一键启动的控制方式，操作简便。下一章将详细介绍机械结构的设计。
