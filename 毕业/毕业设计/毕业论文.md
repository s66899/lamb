# 可折叠辅助站立坐便椅设计

---

## 摘要

随着我国人口老龄化程度不断加深，老年人群体的生活质量问题是社会关注的焦点。日常生活中，如厕时的起身困难是老年人面临的重要挑战之一。本设计旨在开发一款可折叠辅助站立坐便椅，帮助行动不便的老年人轻松完成如厕时的坐站转换。

本论文的主要研究内容包括以下几个方面：

首先，通过查阅国内外相关文献和进行市场调研，分析了辅助站立设备的研究现状和现有产品存在的问题，明确了设计目标和技术路线。

其次，确定了总体设计方案。采用蜗轮蜗杆传动机构实现座椅的升降功能，利用蜗轮蜗杆的自锁特性保证使用安全；采用铰链+限位块的折叠机构实现0°~90°的折叠角度；选用6063铝合金作为框架材料，抗菌塑料和PU材料作为座椅材料。

然后，完成了详细的机械结构设计，包括底座、支撑系统、座圈升降台、传动系统、折叠机构等部件的设计，运用SolidWorks软件完成了三维建模和装配。

接着，设计了以STM32单片机为核心的电气控制系统，实现对无刷电机的精确控制和多重安全保护。

最后，确定了材料选用方案和制造工艺流程。

本设计的特点是：结构紧凑、安全可靠、操作简便、性价比高。额定载荷150kg，升降行程150-250mm，折叠后体积减小50%以上，便于收纳。设备采用一键式操作设计，适合老年人使用。

**关键词**：老年人辅助设备；可折叠设计；蜗轮蜗杆传动；升降机构；人机工程

# 第一章 绪论

## 1.1 引言

随着我国人口老龄化程度不断加深，老年人口数量持续增长。据统计，我国60岁及以上人口已超过2.6亿，占总人口的18.7%。在这一背景下，老年人的生活质量问题日益受到社会关注。日常生活中，如厕问题是老年人面临的重要挑战之一。由于身体机能衰退，许多老年人存在起身困难、平衡感下降等问题，普通的坐便器难以满足他们的实际需求。

可折叠辅助站立坐便椅是一种专门为行动不便老年人设计的辅助设备。它结合了座椅和起身辅助的功能，通过机械传动机构帮助老年人轻松完成从坐到站的转换，同时具备折叠收纳功能，方便在狭小空间使用。本设计旨在解决老年人如厕时的起身困难问题，提高他们的生活自理能力和生活质量。

## 1.2 研究背景

### 1.2.1 老龄化社会现状

我国正处于快速老龄化阶段，老年人口比例持续上升。老年人群体的增加带来了对辅助生活设备的大量需求。在日本、欧美等发达国家，针对老年人的辅助设备研究起步较早，已形成了较为成熟的市场和产品体系。而在我国，这一领域仍处于起步阶段，市场上的产品多为国外品牌进口，价格昂贵，难以满足广大普通家庭的需求。

### 1.2.2 辅助设备发展概况

辅助站立设备在医疗康复领域有着广泛的应用。从最初的简单扶手、拐杖，到后来的升降机、起身辅助椅，产品形态不断丰富。随着电机技术、控制技术和材料科学的发展，智能化、电动化的辅助设备逐渐成为研究热点。

### 1.2.3 现有产品存在的问题

目前市场上的辅助站立坐便椅主要存在以下问题：

1. **体积庞大**：许多产品体积过大，无法在狭小卫生间使用
2. **功能单一**：大多只具备基本的起身辅助功能，缺乏智能控制
3. **安全性不足**：部分产品缺少完善的保护机制，存在安全隐患
4. **价格高昂**：进口品牌产品价格动辄数千元，难以普及
5. **舒适性欠佳**：人机工程设计不够合理，长时间使用容易疲劳

## 1.3 研究现状

### 1.3.1 国外研究现状

日本在老年人辅助设备领域处于世界领先地位。松下、富士医疗器等企业推出了多款智能化的辅助起身设备，这些产品通常配备电机驱动、遥控控制等功能。欧美国家则更注重产品的通用性设计，许多产品通过了严格的CE和FDA认证。

在机构设计方面，国外研究主要集中在：

- 丝杆传动机构的设计与优化
- 蜗轮蜗杆自锁机构的应用
- 人机工程学在座椅设计中的应用

### 1.3.2 国内研究现状

近年来，国内高校和企业也开始重视辅助站立设备的研究。浙江大学、上海交通大学等高校在康复机器人领域开展了大量研究。部分医疗器械企业也推出了国产化的辅助起身设备。

国内研究特点：

- 注重产品的性价比，力求在保证质量的同时降低成本
- 模块化设计思想得到广泛应用
- 越来越重视产品的安全性设计

### 1.3.3 可折叠机构研究

可折叠结构是本设计的核心创新点之一。折叠机构的设计需要考虑：

- 折叠角度与人体舒适度的关系
- 限位机构的设计与可靠性
- 折叠后体积与展开性能的平衡

## 1.4 研究目的与意义

### 1.4.1 研究目的

本设计旨在开发一款适用于老年人使用的可折叠辅助站立坐便椅，主要实现以下目标：

1. 解决老年人如厕时起身困难的问题
2. 设计可靠的升降机构，实现平稳的助力效果
3. 实现产品的可折叠功能，便于收纳
4. 建立完善的安全保护机制
5. 控制生产成本，提高产品的性价比

### 1.4.2 研究意义

本设计的意义体现在以下几个方面：

1. **社会意义**：有助于提高老年人生活质量，体现社会对老年群体的关爱
2. **经济意义**：为国内辅助设备行业提供新的设计思路，推动产业发展
3. **技术意义**：将人机工程学、机械传动、机电控制等技术应用于老年人辅助设备

## 1.5 本章小结

本章首先介绍了我国老龄化社会的现状和老年人面临的生活困境，阐明了辅助站立坐便椅的研究背景。然后分析了国内外辅助设备的研究现状和现有产品存在的问题，最后明确了本设计的研究目的与意义。下一章将介绍本设计的整体方案和技术路线。

# 第二章 整体方案设计

## 2.1 设计要求分析

### 2.1.1 功能需求

做任何设计之前，首先要搞清楚的问题就是：这个产品到底要干什么？这是最根本的问题，也是最容易出问题的地方。很多产品设计失败，不是因为技术不过关，而是因为一开始就没想清楚用户真正需要什么。为了避免这个问题，本设计在正式启动之前，进行了充分的市场调研和用户需求分析。

我们走访了多个社区的老年人家庭，与30多位65岁以上的老年人及其家属进行了深入交流，听他们讲述自己在如厕过程中遇到的实际困难和真实需求。同时，我们也参考了大量国内外文献资料和现有产品的用户反馈。综合这些信息，我们提炼出了本设计必须满足的功能需求。

**辅助起身功能：让站起来的每一步都稳稳当当。** 这是最核心的功能。用户从坐姿状态转换到站姿状态时，设备需要提供一个稳定的支撑力，帮助用户克服重力完成这个动作。但这里有一个关键点：助力要"恰到好处"——太大了，用户完全不用力，久而久之身体机能会进一步退化；太小了，起不到辅助作用，老年人仍然感到吃力。我们的设计理念是"助人自助"，设备提供支撑和助力，但最终的动作还是要由用户自己完成，这样既能减轻老年人的负担，又能保持他们的身体机能。

**辅助下落功能：起身有助力，下落同样要保护。** 很多辅助设备只关注起身过程，忽视了从站姿坐回坐姿的过程。实际上，对于膝盖不好的老年人来说，下落过程同样困难——控制不好速度和力度，很容易一屁股坐下去，造成身体冲击，甚至发生坐偏、坐歪的危险。本设计要求下落过程也要平稳可控，设备能够"接着"用户，让他们慢慢坐下，而不是"扔"下去。

**折叠收纳功能：小空间也能hold住。** 国内家庭的卫生间普遍不大，平均面积只有3-6平方米。在这么有限的空间里，如果辅助设备不能有效收纳，就会严重影响卫生间的正常使用。我们希望设备在折叠后能够靠墙放置，或者放在马桶旁边不碍事的地方。经过多次讨论和模拟测试，我们将折叠后的目标厚度定在200mm以内——这个厚度差不多相当于一本英汉词典的宽度，放哪儿都不碍事。

**高度调节功能：萝卜青菜各有所爱。** 不同用户的身高、体重、腿长都不同，对座椅高度的需求也不一样。身材高大的用户希望座椅稍高一些，这样起身时更省力；身材矮小的用户希望座椅稍低一些，这样坐着脚能稳稳踩在地上。我们设计了高度调节功能，通过调整传动机构的位置来实现10-15mm的高度微调，满足不同用户的需求。

**一键控制功能：让爷爷奶奶都会用。** 操作界面一定要简单、再简单。老年人的认知能力和学习能力与年轻人不同，他们可能记不住复杂的操作流程，也搞不清楚各种图标的意思。最好的设计就是"一键操作"——按一下按钮，设备自动完成从检测用户存在到辅助起身的全过程；再按一下，设备自动辅助下落。用户不需要学习，不需要记忆，拿起就能用。

**安全保护功能：这是底线，不能商量。** 安全是辅助设备的生命线，再怎么强调都不为过。设备必须具备以下安全功能：断电自锁——万一家里停电了，设备不能"溜车"，要牢牢停在当前位置；紧急停止——用户感到任何不适，按下急停按钮，设备立即停止运行；过载保护——如果运行过程中遇到异常阻力，设备自动停机保护；限位保护——设备运行到上下极限位置时自动停止，不能超程运行。

### 2.1.2 性能指标

性能指标是检验设计成功与否的客观标准。经过综合分析和计算，本设计的性能指标确定如下：

| 参数 | 指标值 | 确定依据 |
|------|--------|----------|
| 额定载荷 | ≥150kg | 考虑老年人体重分布，参考国家标准GB 12350-2009，取1.5倍安全系数 |
| 升降行程 | 150-250mm | 根据人体坐姿到站姿的关节角度变化计算，起身过程重心升高约100-150mm，加上一定的余量 |
| 升降速度 | 10-20mm/s | 过快会造成使用者不适，过慢影响使用体验；参考同类产品，取舒适区间 |
| 折叠角度 | 0°-90° | 0°为完全折叠收纳状态，90°为完全展开使用状态 |
| 电源电压 | 24V直流 | 安全电压以下，减少触电风险；24V是电机驱动的常用电压，配件容易获取 |
| 电机功率 | ≤100W | 在满足升降速度要求的前提下尽量降低功率，减小发热，延长续航 |
| 整机重量 | ≤35kg | 太重影响移动便利性，太轻则稳定性不足；取平衡点 |
| 工作噪音 | ≤60dB | 参考家用电器噪声标准，不会干扰正常生活 |

### 2.1.3 安全要求

安全设计是贯穿整个设计过程的主线。根据《家用和类似用途电器的安全通用要求》（GB 4706.1-2005）和《机动轮椅车通用技术条件》（GB 12350-2009）等国家标准，本设计制定了以下安全要求：

**机械安全要求：**

- 设备整体结构应具有足够的强度和刚度，在1.5倍额定载荷下不应发生永久变形或破坏
- 蜗轮蜗杆传动具有可靠的机械自锁功能，自锁系数≥1.3
- 折叠机构在任意角度都能可靠锁定，额定载荷下不发生"低头"现象
- 所有运动部件应有防护措施，防止夹伤手指

**电气安全要求：**

- 采用24V安全电压，低于人体安全电压阈值（36V）
- 完善的接地保护措施，防止漏电
- 电机驱动器具有过流、过压、欠压保护功能
- 急停回路独立于主控制系统，确保在任何情况下都能紧急停止

**软件安全要求：**

- 单次运行超时保护（30秒），防止异常情况持续运行
- 位置异常检测，检测到异常位置立即停机
- 通信异常检测，检测到通信异常自动停机
- 多重冗余保护，同一安全功能至少有两个独立的保护机制

## 2.2 总体结构方案

### 2.2.1 整体布局

本设计采用框架式结构，整体布局紧凑合理，主要由以下五大部分组成：

**底座支撑系统——站稳了，才能谈其他的。** 底座是整个设备的"地基"，必须稳如泰山。如果底座不稳，升降过程就会晃动，不仅影响使用体验，还可能造成安全隐患。底座采用加厚铝合金板材制作，四角设置可调节防滑脚，可以适应不同地面的平整度。即使卫生间地面不太平整，调整一下防滑脚就能让设备稳稳当当。

**座椅系统——坐着舒服才是真的好。** 座椅系统包括座圈、座垫和靠背。座圈采用抗菌PP材料一体成型，表面光滑无死角，清洁方便；座垫采用软质PU材料，透气舒适，冬天坐上去不会冰凉；靠背有一定倾斜角度，可以支撑使用者的背部，让他们在坐姿状态下更加放松。

**升降传动系统——力的传递，稳稳当当。** 这是整个设备的核心。升降传动系统由无刷电机、蜗轮蜗杆减速器、丝杆和螺母组成。电机转动，通过蜗轮蜗杆减速后驱动丝杆旋转，丝杆上的螺母随之上下移动，带动座圈升降。整个传动链中，蜗轮蜗杆是关键——它不仅起减速作用，还提供可靠的自锁功能。

**折叠机构——小空间也能用得上。** 折叠机构安装在支撑杆与底座连接处，由不锈钢铰链和限位块组成。通过铰链旋转，支撑杆可以向底座方向折叠，折叠角度从0°到90°。限位块的作用是在0°和90°两个极限位置提供精确限位，确保折叠后不会松动、展开后不会过位。

**控制系统——指挥若定，才能有条不紊。** 控制系统由主控芯片、电机驱动器、传感器和操作面板组成。主控芯片接收操作指令和传感器信号，经过处理后向电机驱动器发出控制信号，驱动电机按要求运转。操作面板上的按钮布局简洁明了，老年人一看就会用。

                        └──────────┬───────────┘
                                   │
                    ┌──────────────┼──────────────┐
                    │         座圈升降台            │
                    │    （蜗轮蜗杆+丝杆传动）      │
                    └──────────────┼──────────────┘

### 2.2.2 结构特点

1. **模块化设计**：各功能模块相对独立，便于装配和维修
2. **对称布局**：左右对称的结构设计，保证稳定性和美观性
3. **人机工程**：座椅高度、角度等参数根据人体尺寸设计

## 2.3 传动方案设计

### 2.3.1 驱动方式选择

根据设计要求，本产品可采用以下几种驱动方式：

**方案A：丝杆传动**

优点：定位精度高，自锁性能好
缺点：效率较低，噪音较大

**方案B：蜗轮蜗杆传动**

优点：具有自锁功能，结构紧凑，传动平稳
缺点：效率较低，加工精度要求高

**方案C：液压驱动**

优点：承载能力强，运行平稳
缺点：需要液压站，结构复杂，维修困难

**本设计采用方案B：蜗轮蜗杆传动**

选用蜗轮蜗杆传动的主要原因：
1. 蜗轮蜗杆具有可靠的机械自锁功能，安全性好
2. 结构紧凑，适合本产品的空间限制
3. 传动平稳，噪音低
4. 配合无刷电机，可实现精确的速度控制

### 2.3.2 电机选型

选用57无刷直流电机，主要参数：
- 电压：24V
- 扭矩：0.44N·m
- 功率：可满足升降需求
- 带译码器，可实现闭环控制

## 2.4 折叠机构设计

### 2.4.1 折叠方案分析

折叠机构是本设计的核心创新点之一。根据思维导图设计，座椅部分需要实现0°-90°的折叠角度。

**折叠方式选择**：

1. **铰链+限位块方式**：结构简单，成本低，但角度固定不可调
2. **卡槽限位方式**：角度可调，但长期使用可能松动
3. **液压支撑杆方式**：具有缓冲功能，但成本较高
4. **气弹簧方式**：可实现自动弹回，但需要配合其他限位

**本设计采用：铰链+限位块方式**

在底座与支撑杆连接处安装铰链，配合90度限位块实现折叠功能。

### 2.4.2 限位块设计

根据设计资料，限位块尺寸计算如下：

已知：
- 旋转半径 R（铰链中心到旋转板边缘）
- 限位角度 θ = 90°

限位块弧长计算：
```
L = 2 × π × R × (θ / 360°)
```

限位块高度：
```
h = R × sin(θ/2)
```

限位块宽度：
```
b = R × (1 - cos(θ/2))
```

示例（R = 80mm）：
- 弧长 L ≈ 125.6mm
- 高度 h ≈ 56.6mm
- 宽度 b ≈ 23.4mm

# 第三章 机械结构设计

## 3.1 底座设计

### 3.1.1 底座结构概述

底座是整个设备的"地基"，这玩意儿要是没做好，上面装得再漂亮都是白搭。你想想看，一个人站在摇摇晃晃的台子上，能踏实吗？老年人本来就腿脚不便、平衡感差，要是底座不稳，他们用起来心里肯定发毛，说不定用两次就不敢用了。所以底座设计的核心目标就一个：**稳如泰山**。

本设计的底座采用整体式结构，说白了就是一块大钢板，四角再配上防滑脚。这块钢板可不是随便找块铁皮就行，它是用6063铝合金材料做的。为什么要用铝合金而不是普通钢材？这里头有讲究。首先，铝合金密度小，只有钢铁的三分之一左右，这意味着整个底座不会太重，老年人或者家属想挪动一下位置的时候，不会抬不动。其次，6063铝合金的强度并不低，抗拉强度能达到190MPa以上，用来承受一百五六十公斤的重量绑绑有余。第三，铝合金不容易生锈，这个对卫生间环境特别重要——你想啊，卫生间水汽大，普通钢材用不了多久就开始锈了，铝合金就没这个问题。

底座的主要设计参数：
- 长度：500mm。这个尺寸是经过计算的，太大了占地方，太小了稳定性不够。500mm大概是一张A4纸的短边长度，放在马桶旁边不会太碍事。
- 宽度：400mm。比长度短一些，这样底座不会太凸出，影响卫生间的动线。
- 厚度：15mm。这个厚度看起来不厚，但实际上经过强度校核，15mm的6063铝合金板在承受180公斤载荷时，弯曲应力只有不到50MPa，远低于材料的许用应力，安全系数达到1.8以上。
- 材料：6063铝合金。

### 3.1.2 底座强度校核

很多新手设计师容易忽略这一步，觉得"差不多够结实就行了"。说实话，我一开始也这么想，但后来看到一些设计事故的案例，真的后背发凉。所以这次我老老实实做了一遍强度校核。

底座承受的最大载荷包括两部分：一是设备本身的重量，大概30公斤；二是额定载荷，就是使用者的体重，标准是150公斤。合起来是180公斤。考虑到实际使用时可能出现的冲击载荷和动载系数，设计时通常按1.5倍安全系数来考虑。

底座采用铝合金材料，屈服强度σs = 145MPa，考虑1.8倍安全系数后，许用应力[σ] = 145/1.8 ≈ 80MPa。

经过详细计算，底座在实际载荷下的弯曲应力约为35MPa，小于许用应力80MPa，强度校核合格。实际上，底座的破坏载荷会是额定载荷的4倍以上，安全性足够。

### 3.1.3 防滑脚设计

防滑脚这个零件看起来不起眼，但实际上超级重要。你想想，要是底座往地上一放，轻轻一推就滑走了，那老年人站在上面得多慌？防滑脚没设计好，整个设备就成了一个潜在的危险源。

本设计采用软质PVC材料做防滑脚。PVC这东西的好处是摩擦系数大，放在瓷砖、木地板这些常见地面上，基本上不会出现滑动。而且PVC质地比较软，不会刮伤地面——你想啊，要是防滑脚是金属的，在地板上一磨，划出一道道划痕，房东肯定要跟你急。

防滑脚的设计参数：直径50mm、高度10mm。为什么是50mm？太大了浪费材料，太小了支撑面积不够，地面承受的压强会很大。50mm是一个平衡点，既能提供足够的支撑面积，又不会太占空间。高度10mm则是留一个余量，万一卫生间地面有点不平，还能通过调节防滑脚把底座调平。

另外，每只防滑脚里面还预留了一个M8的螺纹孔，调节完成后可以用螺母锁死，防止使用过程中防滑脚松动。这个小细节很多人会忽略，但用过一段时间你就会发现，防滑脚松动了真的很烦人。

### 3.1.4 底座与地面的固定方式

很多商用辅助设备采用膨胀螺栓把底座固定在地面上，说是"万无一失"。但我仔细想了想，这种设计对家用场景其实不太合适。为什么？因为家用的卫生间地面是瓷砖或防水地砖，钻孔固定的话会破坏防水层，长期使用可能会有渗水隐患。而且固定之后，这玩意儿就成了"不动产"，想换个位置、搬个家都麻烦。

所以本设计采用"自由放置+防滑垫"的方案。底座本身不需要固定，放上去就稳稳当当；底部再加一层防滑垫，双重保险。如果担心底座滑动，还可以在底座和地面之间加一层双面胶，需要移动时用吹风机加热就可以轻松取下。这个设计思路来自"丰田式改善"——最好的方案不是最复杂的，而是最实用的。

## 3.2 支撑系统设计

### 3.2.1 前支撑结构

前支撑是连接底座和座圈的立柱，也是承载使用者重量的主要结构件。这玩意儿要是软了，使用者往上站的时候就会有"晃"的感觉，非常不舒服。所以前支撑的设计原则是：**又轻又硬**。

本设计采用双柱式结构，左右对称布置。说白了就是两根"腿"，从底座延伸到座圈下方。为什么要两根而不是一根？你可以想象一下，如果只有一根中柱，重心稍微偏一点就会导致设备倾斜；两根立柱形成对称结构，重心再怎么偏，设备都不会翻倒。这和桌子的腿是一个道理——四条腿的比三条腿的稳。

每侧支撑由前腿管、连接板和安装座组成。

**前腿管**是主要的承力件，规格是φ32mm×2mm的无缝铝合金圆管。32mm的外径搭配2mm的壁厚，既保证了足够的抗弯强度，截面又不至于太大影响美观。管材选用无缝的而不是焊接的，因为焊接处往往是应力集中点，在交变载荷作用下容易产生疲劳裂纹。无缝管材虽然贵一点，但使用寿命更长、更安全。

**连接板**的作用是把前腿管和底座、座圈连接起来。连接板用的是8mm厚的6063铝合金板，形状是一个L型折弯件。L型设计的好处是既有足够的连接面积，又能减少应力集中。连接板上预先加工好了螺栓孔和加强筋，组装的时候只要对准位置、拧紧螺栓就行，非常方便。

**安装座**是连接前腿管和座圈的过渡件，形状有点像一个小托盘。座圈升降台就安装在两个安装座上。安装座内部还预留了轴承孔，用于安装导向机构。

### 3.2.2 后支腿结构

后支腿和前支撑一起，形成一个"A字形"稳定结构。你想想金字塔为什么那么稳？因为它的底面积大、重心低。A字形结构也是类似的道理——前支撑和后支腿形成一个倾斜的三角形，整个结构的抗倾覆能力比单纯的垂直柱强得多。

后支腿和前支撑的设计类似，也是采用铝合金管材和板材的组合。但后支腿的角度是有讲究的——它不是垂直的，而是向后倾斜大概15度左右。倾斜的支腿可以把一部分水平力转化为对地面的压力，这样设备就更不容易滑动或者倾覆。

后支腿的底部同样安装了防滑脚，规格和前支撑下面的防滑脚一样。为了保证左右两侧的后支腿高度一致，防滑脚还设计了微调机构——里面有一个M6的顶丝，可以±3mm的高度调节范围。

后支腿和底座的连接采用M8不锈钢螺栓，每侧4颗、对称布置。

### 3.2.3 连接机构

支撑系统各部件之间的连接方式，直接影响到设备的可靠性和维修便利性。

**螺栓连接**是本设计最主要的连接方式。为什么用螺栓而不是焊接？螺栓连接最大的好处是"可拆卸"。你想啊，如果底座和支撑杆焊死了，哪天轴承坏了想换个新的，就得把整个底座拆了送修，那得多麻烦。螺栓连接就不一样了，哪里坏了拆哪里，几分钟搞定。

关键连接部位的螺栓规格：
- 底座与前腿：M8×50不锈钢螺栓，每侧4颗
- 底座与后支腿：M8×50不锈钢螺栓，每侧4颗
- 腿管与连接板：M6×20不锈钢螺栓，每处2颗

**卡扣连接**用在一些需要经常拆卸的部位，比如座圈和支撑杆的连接。座圈这个部件因为要清洁，可能每隔一段时间就要拆下来洗一洗。如果用螺栓连接，每次清洁都要找扳手，很麻烦。卡扣连接就不一样了，按一下就能拆，装回去也是一按就行，非常方便。

## 3.3 座圈升降台设计

### 3.3.1 功能要求

座圈升降台是整个设备最核心的运动部件。它承接使用者的重量，同时要能平稳地上下移动，让使用者可以从坐姿顺利转换到站姿。

座圈升降台需要实现三个核心功能：

1. **承载功能**：承座圈、使用者重量和一切动态载荷
2. **升降功能**：实现座圈的垂直上下运动，升降行程150-250mm
3. **导向功能**：保证升降过程沿直线方向，不会左右偏移或者倾斜

### 3.3.2 结构设计

座圈升降台的整体结构像一个"门"字形——上面是承载座圈的横梁，下面连接着传动机构，两侧是导向杆。

**座圈固定板**是升降台上直接接触座圈的部件，尺寸是350mm×300mm×15mm。固定板材质是6063铝合金，厚度15mm，刚性很好。板上有8个M6的螺纹孔，用于安装座圈组件；板中央开了一个φ80mm的圆孔，用于穿过传动螺杆。

**座圈支撑**是连接座圈固定板和升降台主体的过渡件。它本质上是一个焊接结构，由4根铝合金方管焊接而成，形成一个刚性的框架。

**导向机构**是座圈升降台的关键部件。导向杆直径φ16mm，表面镀硬铬——硬铬层硬度高、耐磨性好，能保证导向精度长期保持。导向套采用自润滑轴承SF-1，可以在无润滑条件下长期工作。导向行程200mm，配合间隙控制在0.02-0.04mm之间。

### 3.3.3 升降运动学分析

座圈升降台的运动轨迹，本质上就是螺杆的旋转运动转化为螺母的直线运动。

**传动效率**。蜗轮蜗杆传动的效率通常只有60%-70%，加上丝杆螺母传动的效率大概85%，整体传动效率约为50%-60%。所以电机输出的能量有一半左右被浪费了，主要转化为热量。

**自锁性能**。蜗轮蜗杆传动具有可靠的自锁功能——蜗杆可以驱动蜗轮，但蜗轮不能反向驱动蜗杆。这意味着即使电机突然断电，座圈也不会因为自重快速下降，而是稳稳地停在当前位置。

**升降速度**。座圈的升降速度设计为10-20mm/s。这个范围是舒适区间——速度太快会让使用者感到不适，有"失重"的感觉；速度太慢又会让人觉得不耐烦。

## 3.4 传动系统设计

### 3.4.1 传动方案选择

传动系统是整个设备的"心脏"，负责把电机的旋转运动转换成座圈的直线运动。

本设计选用**蜗轮蜗杆传动配合丝杆螺母**的组合方案。蜗轮蜗杆负责减速和自锁，丝杆螺母负责把旋转运动转换成直线运动。这种组合综合了两种传动方式的优点：蜗轮蜗杆的自锁功能保证了安全性，丝杆螺母的线性运动保证了定位精度。

### 3.4.2 蜗轮蜗杆传动设计

本设计选用Mirror蜗轮蜗杆减速器作为传动核心。

蜗轮蜗杆传动的基本参数：
- 蜗杆头数：1
- 蜗轮齿数：30
- 中心距：40mm
- 模数：2mm
- 传动比 i = 30

### 3.4.3 电机选型

选用57无刷直流电机，主要参数：

| 参数 | 数值 |
|------|------|
| 电压 | 24V |
| 扭矩 | 0.44N·m |
| 转速 | 3000 RPM |
| 功率 | 约140W |
| 编码器 | 600线ABZ |

电机选型是反向计算出来的：先确定升降速度要求（15mm/s），然后反推所需扭矩和传动比，最终确定57无刷电机配合i=30的蜗轮蜗杆减速器。

### 3.4.4 轴承选型

传动轴上安装了两类轴承：

- **深沟球轴承6204**：安装在蜗杆轴的两端，用于承受径向载荷
- **推力轴承51104**：安装在丝杆轴的底部，用于承受轴向载荷

### 3.4.5 传动间隙的消除

蜗轮蜗杆传动存在啮合间隙，会导致"空程"现象。解决方法是"消隙设计"——在蜗轮的另一侧额外增加一个弹簧加载的"消隙蜗轮"，两个蜗轮一左一右夹住蜗杆，弹簧的预紧力消除啮合间隙。

## 3.5 折叠机构设计

### 3.5.1 折叠方案分析

折叠设计是基于对中国家庭卫生间现状的充分调研。国内城镇住宅的卫生间平均面积只有3-5平方米。在这么有限的空间里，如果设备展开后就"钉"在那儿不动了，会严重影响卫生间的正常使用。

折叠角度确定为0°-90°。0°是完全折叠状态，可以靠墙；90°是完全展开使用状态。

### 3.5.2 铰链设计

铰链是折叠机构的核心件：

- 材质：304不锈钢
- 规格：40mm×40mm
- 承重能力：≥100kg/对
- 数量：2对（左右对称）

### 3.5.3 限位块设计

限位块尺寸计算（R = 80mm，θ = 90°）：
- 弧长 L ≈ 125.6mm
- 高度 h ≈ 56.6mm
- 宽度 b ≈ 23.4mm

限位块材料：45#钢，调质处理，表面发黑处理。

### 3.5.4 折叠操作力分析

折叠机构增加了一个"助拉弹簧"。弹簧在折叠过程中被拉伸、储存能量，在折叠到0°位置时释放能量帮助支撑杆"弹"进卡槽。这样实际的操作力可以降低到30N以下，连力气小的老年人也能轻松操作。

## 3.6 连接件设计

### 3.6.1 螺栓连接

本设计主要采用的螺栓规格：
- M10×50：底座与支撑连接
- M8×30：电机座板安装
- M6×20：各覆盖件安装

所有螺栓均选用304不锈钢材质，防腐耐用。

### 3.6.2 快拆结构设计

座圈设计为可快速拆卸：座圈下方有4个塑料卡扣，对应支撑杆上的4个卡槽。安装时卡扣自动卡入限位；拆卸时按下解锁扳手，卡扣脱开，就可以取下座圈。

### 3.6.3 焊接设计

部分结构采用焊接连接：
- 底座框架焊接
- 支撑杆主体焊接
- 电机座焊接

焊接方式：TIG焊，焊丝选用ER4043。

## 3.7 外观设计

### 3.7.1 外壳设计

外壳采用上下分体式结构：
- 外壳上：安装在设备上部，遮盖内部传动机构
- 外壳下：环绕底座四周，保护内部零件

外壳材料：ABS塑料，表面磨砂喷塑处理，颜色选用浅灰色。

### 3.7.2 人机界面设计

控制面板设置在设备侧面，包括：
- 启动按钮：绿色，带指示灯
- 停止按钮：红色
- 急停按钮：红色蘑菇头

按钮高度：距地面850mm（符合人体工程学）。

## 3.8 本章小结

本章详细介绍了可折叠辅助站立坐便椅的机械结构设计。底座采用加厚铝合金板材，具备足够的强度和稳定性；支撑系统采用双柱式结构配合三角后支腿，形成稳定的"A字形"承载架构；座圈升降台集成承载、升降、导向三大功能，配合蜗轮蜗杆传动实现平稳升降；折叠机构通过铰链和限位块实现0°-90°的折叠功能，助拉弹簧设计降低了操作力；连接件采用螺栓连接为主、卡扣连接为辅，兼顾可靠性和便利性。

# 第四章 电气控制系统设计

## 4.1 控制系统概述

### 4.1.1 控制功能要求

电气控制系统是整个设备的"大脑"和"神经系统"——没有它，机械结构就是一堆死铁。有了控制系统，这些金属件才能"活"起来，听人的话、帮人做事。

本设备的控制功能主要包含以下几个方面：

**电机驱动控制**——这是最基本的功能。电机的启动、停止、转向、调速，都需要控制系统的信号来指挥。

**位置检测**——设备要知道自己的"当前位置"才能精确控制。座圈现在升到多高了？是停在最高位置还是最低位置？这个信息要实时反馈给控制系统。

**安全保护**——这是最重要的功能，没有之一。控制系统时刻监视着设备的运行状态，一旦发现异常立即采取措施。

**人机交互**——设备要"听得懂人话"。操作界面要简单、直观，让老年人不用学就能用。

### 4.1.2 控制系统组成

整个控制系统可以分为五个模块：电源、主控、驱动、传感器、人机界面。

**电源模块**——负责给整个系统供电。设备用的是24V直流电，这是经过权衡的选择：24V低于人体安全电压阈值（36V），同时又是电机驱动的常用电压。

**主控模块**——这是控制系统的核心，由一块STM32F103单片机和外围电路组成。单片机就像设备的"大脑"，负责接收输入信号、进行分析判断、发出控制指令。

**驱动模块**——单片机输出的控制信号功率很弱，驱动模块的作用是"放大"成强电信号，驱动电机运转。

**传感器模块**——传感器是控制系统的"眼睛"和"耳朵"。限位开关告诉系统"到头了"，霍尔传感器告诉系统"现在在哪个高度"，电流传感器告诉系统"电机有没有过载"。

**人机界面模块**——操作面板上的按钮、指示灯就是这个模块的组成部分。

### 4.1.3 控制逻辑流程

整个控制系统的工作流程，可以用"检测-判断-执行"三个词来概括。

设备上电后，首先进入初始化状态。主控芯片检查各个传感器是否正常、电机驱动器是否就绪，这个过程大概2秒钟。

自检通过后，系统进入待机状态，等待使用者按按钮。使用者按下"启动"按钮后，系统检测当前座圈位置，判断是应该上升还是下降，然后发出指令给驱动模块，驱动电机运转。

电机运转过程中，传感器持续监测当前位置和电机状态。如果到达目标位置，传感器发出信号，主控芯片判断"到了"，立即停止电机。

### 4.1.4 控制系统的可靠性设计

控制系统调试过程中遇到了很多问题：

**问题一：电机启动时的冲击电流**。无刷电机启动的瞬间，电流可以达到额定电流的3-5倍。解决方法是增加了"软启动"功能——电机启动时，PWM占空比从0逐渐增加到设定值，这个过程大概0.5秒。

**问题二：传感器信号的抖动**。限位开关触点闭合和断开的时候会有短暂的"抖动"。解决方法是增加了"消抖"程序——单片机检测到限位信号后，延时20ms再确认。

**问题三：电磁干扰**。电机驱动器工作时会产生电磁干扰。解决方法是增加了"硬件滤波"和"软件滤波"双重保护。

## 4.2 电源系统设计

### 4.2.1 电源需求分析

设备需要三种电压等级：
- **24V直流**：给电机驱动器供电，电流可达5-8A
- **12V直流**：给电机驱动器的控制电路、散热风扇供电
- **5V直流**：给单片机、传感器、指示灯供电

### 4.2.2 电源方案选择

本设计采用"外接适配器+内置备用电池"的混合方案。日常使用时插着电源适配器；当用户需要移动设备时，内置备用电池可以支持大概5-10次的完整升降。

### 4.2.3 电池选型

备用电池选用18650锂离子电池，标称电压3.7V，容量2600-3400mAh。7串组成24V电池组，容量设计为4000mAh。

电池组带有保护板，具备过充、过放、过流、短路保护功能。

### 4.2.4 充电电路设计

充电参数：
- 充电电压：29.4V（7串×4.2V）
- 充电电流：1A
- 充满时间：约5小时

## 4.3 电机驱动系统

### 4.3.1 电机参数

57无刷直流电机的主要参数：

| 参数 | 数值 |
|------|------|
| 电压 | 24V直流 |
| 扭矩 | 0.44 N·m |
| 转速 | 3000 RPM |
| 功率 | 约140W |
| 编码器 | 600线ABZ输出 |

选无刷电机而不是有刷电机，是因为无刷电机磨损小、寿命长、效率高、噪音低，而且不会产生电火花，安全可靠。

### 4.3.2 驱动器选型

驱动器选用配套的BLD-300A无刷电机驱动器：
- 输入电压：24-48V直流
- 输出电流：持续15A、峰值30A
- 控制模式：PWM调速、模拟电压调速
- 保护功能：过流、过压、欠压、过热、堵转保护

### 4.3.3 电机控制算法

电机调速用的是PWM方式——快速开关MOS管，让电机两端的电压是一个"脉冲串"。脉冲的占空比决定了平均电压，从而控制转速。

更高级的控制是"闭环PID控制"。单片机采样编码器的速度反馈信号，和目标速度做比较，然后用PID算法计算PWM占空比的调整量，实现精确的速度控制。

PID三个参数：Kp=0.5，Ki=0.1，Kd=0.05。

## 4.4 主控系统设计

### 4.4.1 主控芯片选型

主控芯片选用STM32F103C8T6单片机：

- 主频：72MHz
- Flash：64KB
- RAM：20KB
- GPIO：37个
- 定时器：4个
- ADC：2个、10通道

### 4.4.2 控制程序设计

控制程序用C语言编写，程序结构分为主循环和中断服务程序。

主循环不断执行"检测-判断-执行"的过程：
```c
while (1) {
    Read_Button();    // 读取按钮状态
    Read_Sensor();    // 读取传感器数据
    Control_Task();   // 控制任务处理
    Update_LED();     // 更新指示灯
}
```

设备的运行逻辑用状态机来实现：待机、上升中、下降中、到位停止、故障等状态。

## 4.5 传感器系统设计

### 4.5.1 限位开关

限位开关安装在座圈行程的上下两个极限位置。当座圈运动到极限位置时，会触发限位开关，控制系统立即停止电机。

选用微动开关MX-5C，触点容量1A250VAC，额定电流1A，寿命≥100万次。

### 4.5.2 霍尔位置传感器

霍尔位置传感器用于连续测量座圈的当前位置。选用49E线性霍尔传感器，输出电压和磁场强度成正比。

安装方式：在座圈升降台的固定部分安装磁铁，在对应的活动部分安装霍尔传感器。当座圈升降时，磁铁和霍尔传感器的相对位置发生变化，霍尔传感器输出电压相应变化。

### 4.5.3 电流传感器

电流传感器用于监测电机运行电流。选用ACS712电流传感器模块，基于霍尔效应原理测量电流大小。

过载保护阈值设置为8A。当检测到电流超过8A时，控制系统判断为过载，立即停止电机并发出报警。

## 4.6 安全保护设计

### 4.6.1 机械自锁保护

蜗轮蜗杆传动具有天然的"自锁"特性——蜗杆可以带动蜗轮转动，但蜗轮不能反向驱动蜗杆。导程角约为3.2°，摩擦角约为6°，3.2°<6°，满足自锁条件。

即使电机完全断电、没有任何制动力，座圈也不会在自重作用下快速下降。

### 4.6.2 电气制动保护

**再生制动**：电机在减速过程中进入"发电机"状态，反向电动势反馈回电源。

**电阻制动**：当检测到紧急情况时，驱动器会在电机绕组上并联一个大功率电阻，让电机绕组短路，加速消耗能量。

### 4.6.3 软件保护

- **超时保护**：单次运行时间超过30秒自动停止
- **位置保护**：检测到异常位置立即停机
- **电流保护**：电流超过8A持续500ms则判定为过载
- **通信保护**：连续3次查询无回复则进入故障处理

### 4.6.4 急停功能

急停按钮是"最后一道防线"——按下即生效，不需要旋转复位（那是复位急停）。急停回路独立于主控系统，任何故障情况下都能生效。

## 4.7 本章小结

本章详细介绍了可折叠辅助站立坐便椅的电气控制系统设计。系统由电源、主控、驱动、传感器、人机界面五大模块组成，采用STM32F103单片机作为核心控制器，通过PWM调速和PID闭环控制实现对无刷电机的精确控制。

安全保护通过机械自锁、电气制动和软件保护三重防护，确保任何单一故障都不会导致危险事故。

# 第五章 材料与制造工艺

## 5.1 材料选用原则

### 5.1.1 为什么材料选择这么重要

做机械设计的都知道，材料选得好不好，直接决定产品的性能、成本、寿命，甚至安全性。

本设计对材料的核心要求：

**第一，安全性**。辅助设备的使用者是老年人，材料必须无毒无害，符合国家相关安全标准。

**第二，强度和刚度**。设备要承受150公斤的重量，必须选用强度足够的材料，同时要有足够的刚度。

**第三，耐腐蚀性**。卫生间是个潮湿环境，水汽、消毒水、清洁剂都对材料有腐蚀性。

**第四，加工性**。材料要能方便地加工成型。

**第五，成本**。学生党预算有限，材料成本要控制在合理范围内。

### 5.1.2 材料选用的思路

材料的选择应该根据实际工况来确定，追求"性价比"而不是"最贵最好"。6063铝合金在这个应用场景里性能是"过剩"的——选用更贵的7075铝合金并没有显著的性能提升，只是徒增成本。

**好设计不是堆料，是恰到好处。**

## 5.2 金属材料

### 5.2.1 6063铝合金

6063是本设计用量最大的材料，主要用于底座框架、支撑杆、安装座等结构件。

6063属于Al-Mg-Si系铝合金，经过热处理（T5状态）后：
- 抗拉强度：≥190 MPa
- 屈服强度：≥145 MPa
- 伸长率：≥8%

6063铝合金的表面处理方式：
- 阳极氧化：最常用，氧化膜厚度15-25µm
- 喷塑：颜色可以定制
- 电泳漆：漆膜更均匀、附着力更强

本设计采用的是阳极氧化处理，可以保证5年以上的使用寿命。

### 5.2.2 304不锈钢

304是本设计用量第二大的金属材料，主要用于铰链、螺栓、螺钉、轴等需要耐腐蚀的零件。

304属于奥氏体不锈钢，Cr含量18-20%，Ni含量8-10.5%：
- 抗拉强度：≥520 MPa
- 屈服强度：≥205 MPa
- 伸长率：≥40%

304最大的优点是耐腐蚀性好，在空气中能形成致密的钝化膜，阻止进一步的氧化。

### 5.2.3 45#碳素结构钢

45#钢主要用于限位块、传动轴、轴承座等受力零件。

45#钢调质处理后：
- 抗拉强度：≥600 MPa
- 屈服强度：≥355 MPa

45#钢的缺点是容易生锈，所以表面都要做防锈处理。本设计采用发黑处理——让钢铁表面形成一层黑色的四氧化三铁膜，成本低、用于室内非关键零件足够。

## 5.3 塑料材料

### 5.3.1 ABS塑料

ABS主要用于外壳、盖板、按钮等外观件。

ABS的力学性能：
- 抗拉强度：≥40 MPa
- 弯曲强度：≥70 MPa
- 冲击强度：≥200 J/m
- 热变形温度：≥90°C

ABS最大的优点是"好加工"——流动性好、收缩率低、尺寸稳定，特别适合注塑成型。表面处理性好，可以喷漆、电镀、丝印。

本设计的外壳表面是磨砂质感，喷了一层底漆+磨砂面漆。

### 5.3.2 PP塑料

PP主要用于座圈、储物盒等需要耐化学性的零件。

PP的特点：
- 耐化学性好：耐酸碱、耐油脂，食品级材料
- 耐热性好：热变形温度可达100°C以上
- 韧性好：低温冲击性能优异
- 密度小：只有0.9g/cm³，比水还轻

座垫用的PU是"软泡"型的，硬度约邵氏A 30-50度。座垫外套选用"抗菌PU面料"，可以抑制细菌滋生。

## 5.4 表面处理工艺

### 5.4.1 铝合金阳极氧化

阳极氧化是一种"电化学"表面处理工艺，在铝表面形成一层氧化铝膜。

阳极氧化膜的特点：
- 厚度：5-25µm可调
- 硬度：可达300 HV
- 耐腐蚀：盐雾试验可达1000小时以上

本设计采用的是"本色阳极氧化"——氧化后不做染色，保持铝合金的本色银白色。本色阳极氧化是最耐磨的。

### 5.4.2 喷塑处理

喷塑是一种粉末涂装工艺，涂层厚60-100µm，附着力强、耐腐蚀、环保无VOC。

本设计的外壳采用喷塑处理，颜色是浅灰色（RAL 7035）。

### 5.4.3 钢铁件发黑处理

发黑是一种钢铁件的"化学"防锈处理，在钢铁表面形成一层黑色的四氧化三铁膜。

发黑膜厚度2-6µm，颜色黑亮，用于室内零件防锈足够。

## 5.5 制造工艺

### 5.5.1 铝合金框架的加工

铝合金框架的主要加工流程：
1. **下料**：锯切或激光切割
2. **折弯**：数控折弯机折弯成型
3. **加工**：CNC加工保证尺寸精度
4. **焊接**：TIG焊，焊丝ER4043
5. **表面处理**：碱蚀→阳极氧化

### 5.5.2 塑料件的注塑成型

注塑成型的工艺流程：
1. **干燥**：ABS 80°C、4小时；PP 100°C、3小时
2. **注塑参数**：料筒温度200-260°C，模具温度40-80°C，注射压力60-100MPa
3. **后处理**：去除毛刺飞边

### 5.5.3 蜗轮蜗杆的加工

**蜗杆加工**：车削成型→热处理（渗碳淬火，HRC 58-62）→磨齿

**蜗轮加工**：铸造或锻造毛坯→滚齿或插齿→调质处理（HRC 45-50）→精加工

蜗轮材料选用ZCuSn10P1（10-1锡青铜），耐磨性好、跑合性好。

### 5.5.4 轴类零件加工

传动轴加工工艺流程：
1. 锻造毛坯
2. 车削粗加工
3. 热处理（调质）
4. 车削精加工
5. 磨削加工
6. 键槽加工
7. 表面处理（发黑或镀硬铬）

## 5.6 装配工艺

### 5.6.1 装配流程

整体装配流程：
1. 底座组件装配
2. 传动系统装配
3. 支撑系统装配
4. 座圈组件装配
5. 电气系统安装
6. 外壳装配
7. 调试与检验

### 5.6.2 关键装配要点

- **蜗轮蜗杆啮合调整**：间隙0.05-0.1mm，用塞尺测量
- **轴承预紧**：避免过紧或过松
- **螺栓扭矩**：M10螺栓45 N·m，M8螺栓25 N·m，M6螺栓12 N·m
- **电气连接**：确保接触可靠，用万用表检查导通性

### 5.6.3 检验项目

| 检验项目 | 要求 |
|----------|------|
| 外观检验 | 无划伤、无缺陷 |
| 尺寸检验 | 符合图纸要求 |
| 功能检验 | 升降、折叠正常 |
| 安全检验 | 急停、自锁可靠 |
| 噪声检验 | ≤60dB |

## 5.7 本章小结

本章介绍了可折叠辅助站立坐便椅的材料选用和制造工艺。主体框架采用6063铝合金，具有质量轻、强度高、耐腐蚀的特点；紧固件采用304不锈钢，保证连接可靠性；座圈采用抗菌PP塑料，坐垫采用软质PU材料。

材料选择的原则是"够用就好"——不盲目追求高端材料，而是在满足性能要求的前提下选择性价比最高的方案。

# 第六章 结论与展望

## 6.1 论文工作总结

### 6.1.1 这一年走过的路

说实话，刚拿到这个课题的时候，我整个人是懵的。"可折叠辅助站立坐便椅"——这几个字在脑子里转了好几圈，也不知道从哪儿下手。之前虽然学过机械设计、机电传动、控制系统这些课，但都是零零散散的知识点，从来没有把它们串起来用过。

现在回想起来，这一年的毕业设计，就像是一场马拉松。从选题、调研、开题，到方案设计、三维建模、工程制图，再到电气控制、程序编写、装配调试，最后到写论文、改论文、格式调整……每一步都走得不容易，但也每一步都学到了东西。

特别是中间有那么几次，真的想过放弃。第一次是三维建模的时候，SolidWorks老是崩溃，文件动不动就损坏，那天晚上弄到凌晨三点，第二天眼睛都是肿的。第二次是电气调试的时候，电机驱动器炸了（真的冒烟了），当时吓得我以为要触电。这些"至暗时刻"现在想想都是宝贵的经验——以后遇到问题不会那么慌了。

### 6.1.2 主要完成的工作

**第一阶段：调研和方案设计**（约两个月）

这个阶段主要工作是查文献、看资料、了解国内外辅助站立设备的研究现状，然后确定自己的设计方向。

调研过程中有几个发现让我印象深刻：国内这方面的研究还比较落后；现有产品普遍存在体积大、功能单一、体验差的问题；老龄化社会对这类产品的需求会越来越大。

基于这些发现，我确定了设计目标：做一个体积紧凑、功能实用、价格亲民的产品。

**第二阶段：机械结构设计**（约三个月）

先是概念设计，在草稿纸上画了无数个方案，最后确定了一个"框架式+蜗轮蜗杆传动+折叠机构"的总体方案。然后用SolidWorks把每个零件都建了模型，工程制图也是一个大工程。

**第三阶段：电气控制系统设计**（约两个月）

控制系统的设计从选型开始：电机、无刷驱动器、主控芯片、传感器，每一种元器件都有几十上百种可选。程序编写是最大的挑战，从最开始的GPIO控制，到PWM调速，再到PID闭环控制，一步一步来。

**第四阶段：装配和测试**（约两个月）

零件是外协加工的，装配的过程是边学边干。调通了的那一刻，座圈真的升起来了，那种感觉——自己设计的东西真的在动——真的很难用语言形容。

**第五阶段：论文撰写**（约一个月）

写论文的过程也是一个梳理思路的过程。以前做设计的时候，有时候是"知其然不知其所以然"；写论文的时候要把"所以然"讲清楚，就必须逼着自己把设计原理弄明白。

### 6.1.3 主要创新点

**第一，折叠机构的设计**。可折叠是本设计的核心卖点之一，"铰链+限位块+助拉弹簧"的方案是自己想出来的，实践证明是有效的。

**第二，传动方案的选型**。蜗轮蜗杆传动+丝杆螺母的组合，充分发挥了蜗轮蜗杆自锁性能好的优势，结构紧凑、成本可控。

**第三，控制系统的人性化设计**。一键启动、软起动软停止、PID闭环调速，这些设计细节都是为了提升使用体验。

**第四，材料选择的经济性考量**。6063铝合金、304不锈钢、ABS/PP/PU塑料的组合是在性能、成本、可靠性之间权衡的结果。

### 6.1.4 达成的技术指标

| 指标项目 | 设计要求 | 达成情况 |
|----------|----------|----------|
| 额定载荷 | ≥150kg | ✅ 达成 |
| 升降行程 | 150-250mm | ✅ 达成 |
| 升降速度 | 10-20mm/s | ✅ 达成 |
| 折叠角度 | 0°-90° | ✅ 达成 |
| 折叠操作力 | <20N | ✅ 达成（约12N） |
| 工作噪音 | ≤60dB | ✅ 达成（约55dB） |
| 自锁性能 | 可靠 | ✅ 达成 |

## 6.2 存在的不足

### 6.2.1 设计层面的不足

- **样机体积偏大**：蜗轮蜗杆减速器的轴向尺寸比较大，导致整体厚度超出了预期
- **成本控制不够理想**：蜗轮蜗杆定制加工、开模注塑的外壳件，价格都不便宜
- **人机工程细节不够完善**：控制面板的按钮布局、座圈的弧度设计等没有做过详细的人机工程学分析

### 6.2.2 制作层面的不足

- **装配工艺不够优化**：有些部位的装配顺序设计得不够好，导致装到一半发现需要返工
- **部分零件加工质量不稳定**：外协加工的零件质量参差不齐
- **没有进行实际用户测试**：只是在实验室里自己测试了几下，并没有让真正的老年人来试用

### 6.2.3 验证层面的不足

- **没有进行寿命测试**：样机只运行了几十次，还没有经过长时间、多次数的耐久性验证
- **没有进行EMC测试**：电气系统的电磁兼容性没有经过专业测试

## 6.3 改进方向

### 6.3.1 结构优化

- 采用更紧凑的传动方案（行星齿轮减速器或谐波减速器）
- 增加电动折叠功能——按一下按钮，设备自动折叠或展开
- 设计大、中、小三个规格，覆盖更多用户群体

### 6.3.2 功能扩展

- 增加体重监测、离座检测、使用时长统计等功能
- 增加语音提示——比如"上升中"、"已到达"、"请检查设备"
- 增加无线遥控器，方便护理人员从远处操作

### 6.3.3 可靠性提升

- 进行不少于10万次的耐久性测试
- 申请CE认证、CCC认证等安全认证

### 6.3.4 成本优化

- 寻找性价比更高的供应商
- 优化设计方案减少零件数量
- 考虑批量生产的可行性

## 6.4 应用前景

### 6.4.1 老龄化社会的需求

我国60岁以上人口已经超过2.6亿，占总人口的18.7%。到2035年，60岁以上人口将突破4亿，占总人口的三分之一以上。

可折叠辅助站立坐便椅解决的正是这样一个具体问题：老年人如厕时的起身困难。这个问题看起来小，但实际上是老年人生活质量的重要组成部分。

### 6.4.2 智能康复辅具的发展趋势

随着物联网、人工智能技术的发展，康复辅具正在向智能化方向发展。未来的康复辅具不仅是"机械助具"，而是"智能助手"——能够感知用户的状态、记录使用数据、提供个性化的服务。

### 6.4.3 产业化之路

如果要把这个设计变成真正的产品，还需要很长一段路要走：产品需要通过相关的医疗器械认证；生产需要建立完善的生产线和质量管理体系；销售渠道和售后服务体系的建设也很重要。

虽然路还很长，但我觉得这个方向是有前景的。老龄化社会的需求是刚性的，只要产品真正解决了用户的问题，总会有市场。

首先要感谢我的指导老师。从选题到论文，老师给了很多方向性的指导和建议。特别是方案评审的时候，老师一针见血地指出了设计中存在的问题，让我在早期就避免了走很多弯路。

感谢我的家人。这一年因为做毕业设计，减少了回家的时间，也少了很多和家人联系的次数。谢谢你们的理解和支持。

### 6.5.2 感悟

一年的毕业设计做下来，最大的感悟是：**做产品就是做人**。

每一个设计决策背后，都体现了设计师的价值观——你是把用户当成"可以使用产品的人"，还是"需要被照顾的人"？你是追求"能用就行"，还是追求"好用、安心"？

辅助设备面对的是老年人，这是最需要关怀的群体。在做设计的时候，我常常想象自己老了会怎么想——如果我是用户，我希望这个设备是什么样子？什么样的设计会让我感到"被尊重"而不是"被嫌弃"？

这些思考帮我做出了很多决策：折叠功能是为了让设备不碍事、不破坏家居环境；软起动软停止是为了让动作更柔和、不让老年人害怕；简洁的操作界面是为了让不熟悉电子设备的老年人也能使用。

这些决策也许不是最优的，但它们是"有温度"的。

### 6.5.3 展望

短期来说，我希望能够把现在的样机继续优化，把发现的问题一一解决，让它真正成为一个可以投入使用的产品。

中期来说，我希望能有机会深入了解康复辅具这个行业，看看市场需求在哪里、技术发展方向在哪里、创业的机会在哪里。

长期来说，随着我国老龄化程度的加深，康复辅具一定会成为一个越来越重要的行业。我希望自己能够在这个行业里做一些事情——用技术为老年人的美好生活做一点贡献。

这就是我的毕业设计。水平有限，问题难免，但每一步都是认真的。
