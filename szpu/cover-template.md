# 深圳职业技术大学毕业设计封面与声明模板

## 一、封面模板

### 标准格式
```
深圳职业技术大学
SHENZHEN POLYTECHNIC UNIVERSITY

机械设计与制造专业毕业设计（论文）

题  目：_______________________________________________
英文题目：_______________________________________________

学  号：___________________________
姓  名：___________________________
专  业：机械设计与制造
学  院：智能制造与装备学院
指导教师：___________________（校内）
合作企业导师：_____________（校外）
完成日期：______年____月____日
```

### 填写说明

#### 1. 中文题目要求
- **字数**：一般不超过25个字
- **格式**：应准确反映设计内容，避免使用"浅析"、"初探"等词汇
- **示例**：
  - ✅ 智能仓储搬运机器人的结构设计与运动控制研究
  - ✅ 新能源汽车电池箱体轻量化设计与碰撞安全性分析
  - ❌ 关于机器人的一些研究

#### 2. 英文题目要求
- **格式**：除冠词、介词外，实词首字母大写
- **示例**：
  - Structural Design and Motion Control Research of Intelligent Warehouse Handling Robot
  - Lightweight Design and Crash Safety Analysis of New Energy Vehicle Battery Box

#### 3. 信息填写规范
- **学号**：完整学号，如：2021123456
- **姓名**：与身份证一致
- **专业**：机械设计与制造（完整专业名称）
- **学院**：智能制造与装备学院
- **指导教师**：校内导师姓名 + 职称（教授/副教授/高级工程师）
- **企业导师**：企业导师姓名 + 职务（高级工程师/技术总监等）
- **日期**：论文完成日期，格式：2024年6月10日

### 封面排版要求
- **纸张**：A4白色铜版纸或高质量打印纸
- **字体**：中文宋体，英文Times New Roman
- **字号**：学校名称三号，其他信息小四
- **对齐**：所有信息居中对齐
- **间距**：行距1.5倍，段落间距适当

## 二、原创性声明与使用授权

### 标准格式
```
深圳职业技术大学
毕业设计（论文）原创性声明

本人郑重声明：所呈交的毕业设计（论文）是本人在导师的指导下，独立进行研究工作所取得的成果。除文中已经注明引用的内容外，本设计（论文）不包含任何其他个人或集体已经发表或撰写过的作品成果。对本文的研究做出重要贡献的个人和集体，均已在文中以明确方式标明。本人完全意识到本声明的法律结果由本人承担。

作者签名：___________________
日  期：______年____月____日

使用授权声明

本人同意深圳职业技术大学有关保留、使用毕业设计（论文）的规定，即：学校有权保留送交设计（论文）的复印件，允许设计（论文）被查阅和借阅；学校可以公布设计（论文）的全部或部分内容，可以采用影印、缩印或其他复制手段保存设计（论文）。

作者签名：___________________  导师签名：___________________
日  期：______年____月____日    日  期：______年____月____日
```

### 填写说明

#### 1. 签名要求
- **作者签名**：必须本人亲笔签名，与学籍信息一致
- **导师签名**：校内导师亲笔签名
- **日期**：作者签名日期 ≤ 导师签名日期 ≤ 提交日期

#### 2. 打印要求
- **纸张**：与封面相同纸张
- **位置**：紧接封面之后，单独一页
- **签名**：必须手写签名，不可打印或盖章代替

## 三、中英文摘要页

### 中文摘要模板
```
摘要

（宋体小四，1.5倍行距，300-500字）

[在此处撰写中文摘要，内容应包括：
1. 研究背景：简要说明选题的行业背景和企业需求
2. 研究目的：明确设计要解决的具体问题
3. 研究方法：简述采用的设计方法和技术路线
4. 主要结果：总结设计的主要成果和数据
5. 结论：得出主要结论，说明应用价值]

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

### 英文摘要模板
```
Abstract

（Times New Roman 12pt, 1.5 line spacing）

[Write the English abstract here, corresponding to the Chinese version. It should include: background, purpose, methods, main results, conclusions.]

Keywords: keyword1; keyword2; keyword3; keyword4; keyword5
```

### 摘要撰写要求

#### 内容要求
- **完整性**：包含背景、目的、方法、结果、结论五要素
- **准确性**：与正文内容一致，数据准确
- **简洁性**：语言精炼，避免重复
- **独立性**：无需阅读全文即可了解主要内容

#### 关键词要求
- **数量**：3-5个，用分号分隔
- **选择**：从题目、摘要、正文中选取
- **顺序**：重要程度递减
- **示例**：智能仓储；搬运机器人；结构设计；运动控制；有限元分析

## 四、目录页

### 目录格式要求
- **标题**："目录"二字，黑体三号，居中
- **内容**：显示到三级标题
- **页码**：右对齐，使用省略号连接
- **字体**：宋体小四，1.5倍行距
- **间距**：章节间适当留白

### 自动生成目录方法（Word）

#### 步骤1：设置样式
1. 选中章标题 → 样式 → 标题1
2. 选中级标题 → 样式 → 标题2  
3. 选中小节标题 → 样式 → 标题3

#### 步骤2：插入目录
1. 光标定位到插入位置
2. 引用 → 目录 → 自动目录
3. 更新目录：右键目录 → 更新域

#### 步骤3：格式调整
1. 修改目录字体、字号
2. 调整缩进、行距
3. 检查页码准确性

## 五、页码设置

### 位置要求
- **封面**：无页码
- **声明页**：无页码
- **摘要页**：罗马数字（Ⅰ, Ⅱ, ...）
- **目录页**：罗马数字延续
- **正文页**：阿拉伯数字（1, 2, 3, ...）

### 设置方法（Word）

#### 分节设置
1. 光标定位到摘要前
2. 布局 → 分隔符 → 下一页
3. 光标定位到目录后
4. 布局 → 分隔符 → 下一页

#### 页码设置
1. 双击摘要页脚 → 设计 → 页码 → 设置页码格式
2. 编号格式：Ⅰ, Ⅱ, Ⅲ, ...
3. 起始页码：Ⅰ
4. 双击正文页脚 → 设计 → 页码 → 设置页码格式
5. 编号格式：1, 2, 3, ...
6. 起始页码：1

## 六、页眉页脚

### 页眉设置
- **内容**：各章标题
- **字体**：宋体五号，居中
- **位置**：距上边界1.5cm

### 页脚设置
- **内容**：页码
- **字体**：Times New Roman 五号，居中
- **位置**：距下边界1.75cm

## 七、装订要求

### 装订顺序
1. 封面
2. 原创性声明与使用授权
3. 中文摘要
4. 英文摘要  
5. 目录
6. 正文（含参考文献、致谢、附录）
7. 封底（空白页）

### 装订方式
- **方式**：胶装或线装
- **颜色**：封面颜色按学院要求
- **书脊**：如有书脊，标注题目、姓名、年份

## 八、电子版提交要求

### 文件格式
- **论文**：PDF格式（兼容Word 2016）
- **图纸**：DWG格式（AutoCAD）+ PDF格式
- **三维模型**：SLDPRT/STEP/IGS格式
- **程序代码**：压缩包格式

### 文件命名
```
学号_姓名_毕业设计论文.pdf
学号_姓名_设计图纸.zip
学号_姓名_三维模型.zip
学号_姓名_程序代码.zip
```

### 提交内容
1. 论文正文（含封面、摘要、目录）
2. 设计图纸（二维+三维）
3. 仿真分析文件
4. 实验数据文件
5. 程序代码文件
6. 答辩PPT

## 九、常见问题解答

### Q1：封面信息填错了怎么办？
A：重新打印封面，确保信息准确无误。签名必须手写。

### Q2：摘要超过500字怎么办？
A：精简语言，删除冗余描述，保留核心内容。

### Q3：目录页码不对怎么办？
A：检查分节符设置，更新目录域，调整标题样式。

### Q4：如何保证格式统一？
A：使用样式功能，先设置好样式再撰写内容。

### Q5：电子版和纸质版不一致怎么办？
A：提交前仔细核对，确保完全一致。
