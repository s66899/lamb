## 五、正文格式规范

### 5.1 页面设置
- **纸张**：A4（210mm×297mm）
- **页边距**：上3.5cm，下2.5cm，左2.5cm，右2.5cm
- **页眉**：1.5cm，页脚：1.75cm
- **行距**：正文1.5倍，图表、公式等单倍

### 5.2 字体字号
- **章标题**：黑体三号，居中，段前段后各1行
- **节标题**：黑体四号，左对齐，段前段后各0.5行
- **小节标题**：黑体小四，左对齐
- **正文**：宋体小四
- **英文、数字**：Times New Roman

### 5.3 图表公式规范
- **图**：图序（如"图3.1"）+图题，宋体五号，置于图下方
- **表**：表序（如"表4.2"）+表题，黑体五号，置于表上方
- **公式**：右端编号，如"(3.1)"，用公式编辑器编写

### 5.4 章节内容模板

#### 第1章 绪论
```
1.1 研究背景与意义
（1）行业背景分析：结合国家战略（如"中国制造2025"、"工业4.0"）
（2）企业发展需求：深圳地区制造业转型升级的实际需求
（3）技术发展趋势：智能制造、数字化设计等新技术应用
（4）研究意义：理论意义和实际应用价值

1.2 国内外研究现状
（1）国外研究现状：欧美日等发达国家相关技术发展
（2）国内研究现状：高校、科研院所、企业研究进展
（3）文献评述：现有研究的优点与不足
（4）研究空白：本设计拟解决的问题

1.3 企业实际需求分析
（1）合作企业介绍：[企业名称]、所属行业、企业规模
（2）实际问题描述：生产过程中遇到的具体技术问题
（3）技术要求：企业提出的具体性能指标
（4）经济性要求：成本控制、投资回报等

1.4 研究内容与技术路线
（1）主要研究内容：设计目标、关键技术
（2）技术路线：用流程图展示设计过程
（3）预期成果：图纸、实物、专利等
（4）创新点：技术、工艺、应用等方面的创新

1.5 本章小结
（对本章内容进行总结）
```

#### 第4章 详细设计与计算
```
4.1 机械结构设计
4.1.1 关键部件设计
（1）设计依据：功能要求、空间限制、成本约束
（2）设计计算：尺寸计算、材料选择、公差配合
（3）三维建模：SolidWorks/UG/CATIA等软件建模
（4）二维工程图：按照GB标准绘制

4.1.2 装配关系设计
（1）装配顺序：合理的装配工艺流程
（2）配合关系：间隙配合、过盈配合等
（3）定位方式：面定位、销定位、键定位等
（4）拆卸维修：考虑后期维护的便利性

4.2 强度计算与校核
4.2.1 载荷分析
（1）工况分析：正常工作、极限工作、冲击载荷
（2）受力计算：静力学、动力学分析
（3）安全系数：根据使用条件确定安全系数
（4）计算公式：
    F_max = [公式]
    σ_max = [公式]
    n = σ_s / σ_max ≥ [安全系数]

4.2.2 有限元分析
（1）模型简化：去除倒角、圆角等非关键特征
（2）网格划分：网格大小、类型选择
（3）边界条件：约束条件、载荷施加
（4）结果分析：应力云图、变形云图、安全系数云图

4.3 控制系统设计（如涉及）
（1）控制要求：精度、响应速度、稳定性
（2）硬件选型：PLC、传感器、执行器等
（3）程序设计：控制逻辑、人机界面
（4）安全保护：急停、限位、报警等

4.4 经济性初步分析
（1）材料成本：主要材料用量与价格
（2）加工成本：机加工、热处理、表面处理
（3）外购件成本：标准件、外协件
（4）总成本估算：制造成本、使用维护成本
```

## 九、图纸规范要求

1. **标题栏**：完整填写图名、图号、材料、比例、设计者、审核者等

6. **明细栏**：零件序号、名称、数量、材料、备注

## 十、深圳职业技术大学特色要求

### 10.1 产教融合要求
- **企业需求导向**：必须基于真实企业需求，提供企业盖章的需求确认函
- **双导师制**：校内导师（副教授以上）和企业导师（工程师以上）联合指导

### 10.2 创新性要求
- **技术创新**：在传统机械设计中融入智能控制、传感器技术、物联网技术
- **工艺创新**：优化制造工艺，提高加工效率，降低生产成本
- **应用创新**：开拓新的应用场景，解决企业实际问题

### 10.3 规范性要求
- **查重率**：≤15%（以学校当年最新要求为准）
- **参考文献**：近5年文献≥50%，其中外文文献≥20%
- **图纸数量**：总图纸量≥6张A3或同等面积
- **论文字数**：正文1.5-2万字（不含图表、附录）
- **提交材料**：纸质论文2份+电子版（含图纸源文件）

## 十四、常见问题解答

### Q1：如何选择合适的合作企业？
A：优先选择学院合作企业、实习基地企业、校友企业。企业规模适中，有实际技术需求，愿意提供技术支持。

### Q2：设计题目如何确定？
A：题目应体现"设计"性质，如"XX设备的设计与仿真"、"XX系统的设计与实现"。避免纯理论研究题目。

### Q3：图纸数量不够怎么办？
A：可以增加零件图、局部放大图、三维爆炸图、电气原理图等。确保总图纸面积满足要求。

### Q4：如何提高查重通过率？
A：避免大段引用他人成果，设计计算、仿真分析、实验数据必须原创。合理引用并规范标注参考文献。

### Q5：答辩注意事项？
A：熟悉自己的设计内容，准备可能的问题。控制陈述时间，突出重点。仪表整洁，表达清晰。
