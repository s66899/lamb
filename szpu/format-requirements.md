## 二、章节格式规范

### 2.1 标题级别与格式
```
第1章 绪论（黑体三号，居中，段前段后各1行）
    1.1 研究背景与意义（黑体四号，左对齐，段前段后各0.5行）
        1.1.1 行业背景分析（黑体小四，左对齐，段前段后各0.25行）
            （1）国家战略支持（宋体小四，左对齐，无特殊间距）
                ① 具体内容（宋体小四，缩进2字符）
```

### 2.2 章节编号规则
- **一级标题**：第1章、第2章...（阿拉伯数字+"章"）
- **二级标题**：1.1、1.2...（章号+点+序号）
- **三级标题**：1.1.1、1.1.2...（章号+点+二级序号+点+序号）
- **四级标题**：（1）、（2）...（中文括号+数字）
- **五级标题**：①、②...（带圈数字）

### 2.3 章节内容要求
| 章节 | 最小字数 | 建议字数 | 必备内容 |
|------|----------|----------|----------|
| 第1章 绪论 | 1500 | 2000-3000 | 背景、意义、现状、需求、内容 |
| 第2章 理论基础 | 1000 | 1500-2500 | 理论、技术、应用场景 |
| 第3章 方案设计 | 1500 | 2000-3000 | 需求、指标、方案、可行性 |
| 第4章 详细设计 | 2000 | 3000-4000 | 结构、计算、经济性 |
| 第5章 仿真分析 | 1500 | 2000-3000 | 建模、仿真、优化、验证 |
| 第6章 实验验证 | 1000 | 1500-2500 | 制作、实验、数据、对比 |
| 第7章 结论展望 | 800 | 1000-2000 | 成果、创新、不足、展望 |
| **总计** | **9300** | **13000-20000** | **-** |

## 三、图表公式规范

### 3.1 插图规范
#### 3.1.1 图的位置与编号
- **位置**：紧跟文字说明之后，尽量在同一页
- **编号**：按章编号，如"图3.1"（第3章第1图）
- **图题**：置于图下方，格式"图3.1 系统总体框图"
- **字体**：宋体五号，居中
- **间距**：图与上文空1行，与图题空0.5行

#### 3.1.2 图的内容要求
- **清晰度**：分辨率≥300dpi，线条清晰
- **比例**：大小适中，占页面宽度70%-90%
- **标注**：图内文字清晰，标注完整
- **来源**：引用他人图表需注明来源

#### 3.1.3 常见图表类型
| 图表类型 | 适用场景 | 软件推荐 |
|----------|----------|----------|
| 框图 | 系统结构、流程 | Visio、PPT |
| 曲线图 | 性能变化、趋势 | Excel、Origin |
| 三维图 | 结构展示、装配 | SolidWorks、UG |
| 照片 | 实物展示、实验 | 相机、手机 |
| 云图 | 仿真结果 | ANSYS、ABAQUS |

### 3.2 表格规范
#### 3.2.1 表的位置与编号
- **位置**：紧跟文字说明之后，尽量在同一页
- **编号**：按章编号，如"表4.2"（第4章第2表）
- **表题**：置于表上方，格式"表4.2 材料性能参数"
- **字体**：表题黑体五号，表内容宋体五号
- **对齐**：表题居中，表内容根据内容对齐

#### 3.2.2 表格格式要求
- **线型**：三线表（顶线、底线、栏目线）
- **线粗**：顶线底线1.5pt，栏目线0.75pt
- **对齐**：数字右对齐，文字左对齐
- **单位**：在表头或备注中注明单位
- **备注**：必要时添加表注说明

#### 3.2.3 三线表示例
```
表3.1 主要技术指标对比
┌─────────┬──────────┬──────────┬──────────┐
│ 指标项目 │ 企业要求 │ 设计目标 │ 实测结果 │
├─────────┼──────────┼──────────┼──────────┤
│ 生产效率 │ ≥95%     │ 96%       │ 95.5%     │
├─────────┼──────────┼──────────┼──────────┤
│ 定位精度 │ ±0.1mm   │ ±0.08mm   │ ±0.09mm   │
└─────────┴──────────┴──────────┴──────────┘
注：测试条件为室温25℃，湿度60%。
```

### 3.3 公式规范
#### 3.3.1 公式格式
- **编号**：按章编号，右对齐，如"(3.1)"
- **位置**：居中显示，与上下文各空1行
- **字体**：公式主体Times New Roman，变量斜体
- **大小**：公式字号与正文一致或稍大

#### 3.3.2 公式示例
```
最大弯曲应力计算公式为：
             M_max
    σ_max = ──────                     (4.1)
              W_z
式中：
    σ_max —— 最大弯曲应力，MPa；
    M_max —— 最大弯矩，N·mm；
    W_z —— 抗弯截面系数，mm³。
```

#### 3.3.3 公式编辑要求
- **使用工具**：MathType或Word公式编辑器
- **符号规范**：使用标准数学符号
- **单位统一**：使用国际单位制
- **解释完整**：对公式中每个符号进行解释

## 四、参考文献规范

### 4.1 基本要求
- **数量**：≥20篇（其中近5年文献≥50%）
- **类型**：期刊、专著、学位论文、专利等
- **质量**：核心期刊、重要会议、权威著作
- **语言**：中文文献为主，外文文献≥20%

### 4.2 著录格式（GB/T 7714-2015）

#### 4.2.1 期刊文章
```
[序号] 作者. 题名[J]. 期刊名, 年, 卷(期): 起止页码.
示例：
[1] 张明, 李华. 智能制造技术发展趋势研究[J]. 机械工程学报, 2023, 59(5): 1-10.
[2] Smith J, Brown K. Advanced manufacturing technologies review[J]. International Journal of Machine Tools and Manufacture, 2022, 178: 103456.
```

#### 4.2.2 专著
```
[序号] 作者. 书名[M]. 版本. 出版地: 出版社, 出版年: 引文页码.
示例：
[3] 王建国. 现代机械设计方法[M]. 2版. 北京: 机械工业出版社, 2022: 45-50.
[4] Shigley J E. Mechanical engineering design[M]. 10th ed. New York: McGraw-Hill, 2015: 120-135.
```

#### 4.2.3 学位论文
```
[序号] 作者. 题名[D]. 保存地点: 保存单位, 年份.
示例：
[5] 刘涛. 工业机器人轨迹规划算法研究[D]. 深圳: 深圳职业技术大学, 2023.
[6] Zhang L. Research on optimization of CNC machining parameters[D]. Harbin: Harbin Institute of Technology, 2021.
```

#### 4.2.4 专利
```
[序号] 专利所有者. 专利题名: 专利号[P]. 公告日期.
示例：
[7] 华为技术有限公司. 一种机械臂控制系统: CN202310123456.7[P]. 2023-05-10.
[8] Siemens AG. Robotic arm control system: US2023123456A1[P]. 2023-04-15.
```

#### 4.2.5 技术标准
```
[序号] 标准编号 标准名称[S].
示例：
[9] GB/T 1800.1-2020 产品几何技术规范(GPS)极限与配合[S].
[10] ISO 2768-1:1989 General tolerances[S].
```

#### 4.2.6 会议论文
```
[序号] 作者. 题名[C]//会议名称. 出版地: 出版社, 出版年: 起止页码.
示例：
[11] 陈晓, 赵强. 基于数字孪生的智能制造系统研究[C]//2022中国机械工程学会年会论文集. 北京: 机械工业出版社, 2022: 123-128.
```

#### 4.2.7 电子文献
```
[序号] 作者. 题名[EB/OL]. (更新日期)[引用日期]. 获取和访问路径.
示例：
[12] 中国制造2025[EB/OL]. (2015-05-19)[2023-12-10]. http://www.gov.cn/zhengce/content/2015-05/19/content_9784.htm.
```

### 4.3 参考文献排版
- **标题**："参考文献"黑体三号，居中
- **内容**：宋体小四，1.5倍行距
- **序号**：方括号，如[1]、[2]，左对齐
- **悬挂**：第二行起缩进2字符
- **排序**：按文中出现顺序编号

## 五、图纸规范

### 5.1 图纸基本要求
| 项目 | 要求 | 说明 |
|------|------|------|
| 图纸数量 | ≥6张A3 | 总装图+部件图+零件图 |
| 图幅比例 | 适当 | 1:1、1:2、1:5、2:1等 |
| 图纸幅面 | A0-A4 | 根据复杂程度选择 |
| 线条粗细 | 分明 | 粗实线0.5mm，细实线0.25mm |
| 字体高度 | 3.5mm | 汉字高度，字母数字2.5mm |

### 5.2 标题栏规范
#### 5.2.1 标题栏内容
```
┌─────────────────────────────────────────────┐
│                 (图名)                        │
├─────┬─────┬─────┬─────┬─────┬─────┬─────┤
│ 材料 │ 比例 │ 图号 │ 数量 │ 重量 │ 共张 │ 第张 │
├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
│ 45钢 │ 1:2  │ ZT-01│  1   │ 5.2kg│  8   │  1   │
├─────┴─────┴─────┴─────┴─────┴─────┴─────┤
│ 设计 │ 张三        │ 日期 │ 2024.03.15     │
├─────────┼──────────────┼─────┼──────────────┤
│ 审核 │ 李四        │ 日期 │ 2024.03.20     │
├─────────┼──────────────┼─────┼──────────────┤
│ 工艺 │ 王五        │ 日期 │ 2024.03.25     │
└─────────┴──────────────┴─────┴──────────────┘
```

#### 5.2.2 填写要求
- **图名**：准确反映图纸内容
- **图号**：按装配关系编号，如ZT-00（总装），ZT-01（部件）
- **材料**：完整材料牌号，如45钢、Q235-A
- **比例**：优先选用1:1、1:2、1:5、2:1
- **签名**：设计、审核、工艺人员亲笔签名

### 5.3 视图选择与表达
#### 5.3.1 基本视图
- **主视图**：反映主要形状特征
- **俯视图**：从上向下投影
- **左视图**：从左向右投影
- **其他视图**：根据需要增加右、仰、后视图

#### 5.3.2 剖视图
- **全剖**：完全剖切，表达内部结构
- **半剖**：一半剖切，兼顾内外形状
- **局部剖**：局部剖切，表达局部结构
- **阶梯剖**：多个平行剖切面

#### 5.3.3 其他表达方法
- **局部放大图**：表达细小结构
- **向视图**：倾斜部分的真实形状
- **简化画法**：标准件、常用件的简化
- **三维图**：轴测图、爆炸图辅助理解

### 5.4 尺寸标注
#### 5.4.1 标注原则
- **完整**：不多标、不漏标
- **清晰**：不交叉、不重叠
- **合理**：符合加工、测量习惯
- **集中**：相关尺寸集中标注

#### 5.4.2 标注内容
- **定形尺寸**：确定形状大小的尺寸
- **定位尺寸**：确定相对位置的尺寸
- **总体尺寸**：总长、总宽、总高
- **参考尺寸**：供参考的尺寸，加括号

#### 5.4.3 公差配合
- **尺寸公差**：如φ50H7、φ50f6
- **形位公差**：平行度、垂直度、圆度等
- **表面粗糙度**：Ra1.6、Ra3.2、Ra6.3等
- **技术要求**：热处理、表面处理等

## 七、常见格式问题

### 7.1 排版问题
- **问题**：页眉页脚设置错误
- **解决**：使用分节符，分别设置页码格式

- **问题**：目录页码不对
- **解决**：更新目录域，检查标题样式

- **问题**：图表编号混乱
- **解决**：使用题注功能自动编号

### 7.2 内容问题
- **问题**：章节字数不均衡
- **解决**：调整内容分布，突出重点章节

- **问题**：图表与文字脱节
- **解决**：图表紧跟文字说明，文中引用

- **问题**：参考文献格式不统一
- **解决**：使用文献管理软件，如EndNote

### 7.3 图纸问题
- **问题**：图纸比例不当
- **解决**：选择合适的图幅和比例

- **问题**：尺寸标注不全
- **解决**：按照加工要求完整标注

- **问题**：线型粗细不分
- **解决**：设置不同图层，区分线型
