# 第三章 机械结构设计

## 3.1 底座设计

### 3.1.1 底座结构概述

底座是整个设备的支撑基础，需要承受全部载荷并将其传递到地面。本设计的底座采用整体式结构，由底板、加强筋和防滑脚组成。

底座主要设计参数：
- 长度：500mm
- 宽度：400mm
- 厚度：15mm
- 材料：6063铝合金

### 3.1.2 底座强度校核

底座承受的最大载荷为设备自重加额定载荷：
```
F = (设备自重 + 额定载荷) × g
  = (30kg + 150kg) × 9.8N/kg
  = 1764N
```

底座采用铝合金材料，屈服强度σs = 145MPa，许用应力[σ] = 80MPa（安全系数1.8）

弯曲强度校核：
```
σ = M/W ≤ [σ]
```

经计算，底座强度满足要求。

### 3.1.3 防滑脚设计

防滑脚采用软质PVC材料，具有以下特点：
- 摩擦系数大，防滑效果好
- 质地柔软，不损伤地面
- 耐磨性好，使用寿命长

防滑脚直径：50mm，高度：10mm

## 3.2 支撑系统设计

### 3.2.1 前支撑结构

前支撑采用双柱式结构，左右对称布置。每侧支撑由以下零件组成：
- 前腿管（铝合金圆管）
- 连接板（铝合金板材）
- 脚轮（带刹车功能）

前腿管规格：φ32mm × 2mm（壁厚）

### 3.2.2 后支腿结构

后支腿采用三角形稳定结构，增强整体稳定性。后支腿组件包括：
- 后支腿主体（铝合金板材折弯）
- 加强筋
- 防滑脚

### 3.2.3 连接机构

支撑系统各部件之间采用螺栓连接，便于拆卸和维修。关键连接部位：
- 底座与前腿：M8螺栓 × 4
- 底座与后支腿：M8螺栓 × 4
- 腿管与连接板：M6螺栓 × 2

## 3.3 座圈升降台设计

### 3.3.1 功能要求

座圈升降台是本设备的核心运动部件，需要实现：
1. 承载使用者重量
2. 上下升降运动
3. 传递驱动力

### 3.3.2 结构设计

座圈升降台采用框架式结构，由以下零件组成：
- 座圈（座圈固定板 + 座圈支撑）
- 升降台主体
- 导向机构

座圈固定板尺寸：350mm × 300mm × 15mm

### 3.3.3 导向机构设计

为保证升降运动沿直线方向，设置导向机构：
- 导向杆：φ16mm，表面镀硬铬
- 导向套：自润滑轴承，无需额外润滑

导向杆有效行程：200mm

## 3.4 传动系统设计

### 3.4.1 蜗轮蜗杆传动设计

本设计选用Mirror蜗轮蜗杆减速器作为传动核心，具有以下特点：
- 传动比大：i = 10:1 ~ 30:1
- 自锁性能可靠
- 噪音低，运转平稳
- 寿命长

**蜗轮蜗杆基本参数**：
- 蜗杆头数：1
- 蜗轮齿数：30
- 中心距：40mm
- 模数：2mm

### 3.4.2 传动计算

已知：电机扭矩 T_motor = 0.44N·m，传动比 i = 20

输出扭矩：
```
T_output = T_motor × i × η
          = 0.44 × 20 × 0.65
          = 5.72 N·m
```

其中η为蜗轮蜗杆传动效率，约65%。

升降力计算：
```
F = T_output / r
```

其中r为传动半径，根据实际结构确定。

### 3.4.3 轴承选型

传动轴选用滚动轴承支撑：
- 主传动轴承：深沟球轴承 6204
- 蜗杆支撑轴承：推力轴承 51104

### 3.4.4 电机座板设计

电机座板用于安装57无刷电机，材料为6063铝合金，厚度8mm。电机座板与底座通过螺栓连接，便于调整电机位置以保证蜗轮蜗杆啮合间隙。

## 3.5 折叠机构设计

### 3.5.1 铰链设计

铰链是实现折叠功能的关键零件。本设计采用专用折叠铰链：
- 材质：304不锈钢
- 规格：40mm × 40mm
- 承重：≥100kg/对
- 数量：2对（左右对称）

铰链安装在支撑杆与底座连接处。

### 3.5.2 限位块设计

为实现90度精确限位，在铰链处设置限位块：

**限位块尺寸计算**：
```
已知：
- 旋转半径 R = 80mm
- 限位角度 θ = 90°

限位块弧长：L = 2πR(θ/360°) ≈ 125.6mm
限位块高度：h = R × sin(θ/2) ≈ 56.6mm
限位块宽度：b = R × (1 - cos(θ/2)) ≈ 23.4mm
```

限位块材料：45#钢，表面发黑处理

### 3.5.3 折叠操作力分析

折叠操作力应小于20N，以保证老年人可轻松操作：
```
F_fold = (G × L) / (2 × η)
```

其中G为部件重量，L为力臂长度，η为机构效率。

## 3.6 连接件设计

### 3.6.1 螺栓连接

本设计主要采用以下螺栓规格：
- M10-50：底座与支撑连接
- M8-30：电机座板安装
- M6-20：各覆盖件安装

所有螺栓均采用不锈钢材质，防腐耐用。

### 3.6.2 快拆结构设计

为方便日常清洁和维护，座圈等部件设计为可快速拆卸：
- 座圈与支撑杆：卡扣连接
- 覆盖件与底座：磁吸或螺纹连接

### 3.6.3 焊接设计

部分结构采用焊接连接，主要包括：
- 底座框架焊接
- 支撑杆主体焊接
- 电机座焊接

焊接方式：TIG焊，焊丝选用ER4043。

## 3.7 外观设计

### 3.7.1 外壳设计

外壳采用上下分体式结构：
- 外壳上：安装在设备上部，遮盖内部机构
- 外壳下：安装在底座周围，保护传动系统

外壳材料：ABS塑料，表面磨砂处理

### 3.7.2 小盖子设计

设备侧面设置检修盖，便于日常维护。盖子采用螺丝固定，拆装方便。

### 3.7.3 人机界面设计

控制面板设置在设备侧面，包括：
- 启动按钮（带指示灯）
- 急停按钮（红色）
- 充电接口

按钮高度：距地面850mm（符合人体工程学）

## 3.8 本章小结

本章详细介绍了可折叠辅助站立坐便椅的机械结构设计。主要包括底座设计、支撑系统设计、座圈升降台设计、传动系统设计、折叠机构设计等。各部件设计均进行了强度校核，确保结构安全可靠。下一章将介绍电气控制系统的设计。
