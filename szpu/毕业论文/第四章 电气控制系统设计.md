# 第四章 电气控制系统设计

## 4.1 控制系统概述

### 4.1.1 控制功能要求

本设备的电气控制系统需要实现以下功能：
1. **电机驱动控制**：控制无刷电机的启动、停止、转向和调速
2. **位置检测**：检测座椅的当前位置，实现精确控制
3. **安全保护**：实现过载保护、限位保护等安全功能
4. **人机交互**：提供简单的操作界面

### 4.1.2 控制系统组成

电气控制系统主要由以下部分组成：
- 电源模块
- 主控芯片
- 电机驱动模块
- 传感器模块
- 人机界面模块

```
                    ┌─────────────┐
                    │   电源模块   │
```

## 4.2 电源系统设计

### 4.2.1 电源需求分析

根据电气元件需求，电源系统需要提供：
- 24V直流：电机驱动
- 12V直流：控制电路
- 5V直流：传感器、单片机

### 4.2.2 电池选型

考虑到设备需要移动使用，选用锂电池供电：
- 电池类型：18650锂离子电池
- 额定电压：24V
- 容量：4000mAh
- 保护功能：过充、过放、过流、短路保护

### 4.2.3 充电电路设计

充电接口采用DC圆头，规格：
- 充电电压：29.4V
- 充电电流：1A
- 充满时间：约5小时

## 4.3 电机驱动系统

### 4.3.1 电机参数

57无刷直流电机主要参数：
| 参数 | 数值 |
|------|------|
| 电压 | 24V |
| 扭矩 | 0.44N·m |
| 转速 | 3000RPM |
| 功率 | 138W |
| 编码器 | 600线ABZ |

### 4.3.2 驱动器选型

选用米思米无刷电机驱动器（型号：E-57ESTM02+EDR57A+3），该驱动器：
- 内置译码器接口
- 支持速度/位置控制模式
- 具有制动功能
- 保护功能完善

### 4.3.3 驱动电路设计

电机驱动器接线说明：
- U/V/W：电机三相输出
- A/B/Z：编码器信号
- +24V/GND：电源输入
- PWM/DIR：速度/方向控制信号

## 4.4 主控系统设计

### 4.4.1 主控芯片选型

选用STM32F103单片机作为主控芯片，具有以下特点：
- 32位ARM Cortex-M3内核
- 主频72MHz
- 丰富的外设接口
- 低功耗设计

### 4.4.2 控制算法

采用PID控制算法实现电机速度控制：
```
u(t) = Kp·e(t) + Ki·∫e(t)dt + Kd·de(t)/dt
```

参数整定：
- Kp = 0.5
- Ki = 0.1
- Kd = 0.05

### 4.4.3 程序流程设计

主程序流程：
1. 系统初始化
2. 自检（传感器、驱动器状态）
3. 等待按键输入
4. 根据指令执行相应动作
5. 循环检测安全状态

## 4.5 传感器系统设计

### 4.5.1 限位开关

在座椅行程的上下极限位置安装限位开关：
- 类型：机械微动开关
- 额定电流：1A
- 寿命：≥100万次

限位开关安装位置：
- 上限位：升降行程最高点下方10mm
- 下限位：升降行程最低点上方10mm

### 4.5.2 位置传感器

选用霍尔传感器进行位置检测：
- 类型：线性霍尔传感器
- 输出信号：0-5V模拟电压
- 精度：±1mm

### 4.5.3 过载传感器

采用电流传感器监测电机运行状态：
- 类型：霍尔电流传感器
- 额定电流：10A
- 过载保护阈值：8A

## 4.6 安全保护设计

### 4.6.1 机械自锁保护

蜗轮蜗杆传动具有天然的自锁功能：
- 蜗杆可带动蜗轮转动
- 蜗轮无法反向驱动蜗杆
- 自锁系数：≥1.3

### 4.6.2 电气制动保护

在电机驱动器中设置制动功能：
- 再生制动：电机减速时将能量反馈回电源
- 电阻制动：紧急情况下接入制动电阻
- 抱闸功能：断电时锁定电机输出轴

### 4.6.3 软件保护

程序中设置多重保护：
- 超时保护：单次运行时间超过30秒自动停止
- 位置保护：检测到异常位置立即停机
- 通信保护：检测到通信异常自动停机

### 4.6.4 急停功能

设置独立的急停回路：
- 急停按钮：红色蘑菇头按钮
- 动作：立即切断电机电源
- 复位：手动旋转复位
- 位置：设备侧面，距地面1m

## 4.7 人机界面设计

### 4.7.1 控制面板设计

控制面板设置在设备侧面，集成以下元件：
- 启动按钮：绿色，带指示灯
- 停止按钮：红色
- 急停按钮：红色蘑菇头
- 状态指示灯：电源、运行、故障

### 4.7.2 遥控功能设计（可选）

可选配遥控器功能：
- 遥控距离：≥5m
- 按键：上升、下降、停止
- 采用红外或无线方式

### 4.7.3 语音提示功能

设备可集成语音提示功能：
- 开机提示："设备已启动"
- 运行提示："正在上升/下降"
- 到达提示："已到达位置"
- 故障提示："请检查设备"

## 4.8 本章小结

本章详细介绍了可折叠辅助站立坐便椅的电气控制系统设计。包括电源系统、电机驱动系统、主控系统、传感器系统、安全保护系统和人机界面设计。系统采用STM32单片机作为主控，通过无刷电机驱动器实现电机的精确控制。安全保护方面，机械自锁、电气制动和软件保护三重保护确保设备运行安全可靠。
