## 📝 模板特点

### 1. 产教融合特色
- **企业需求导向**：强调基于真实企业问题的设计
- **双导师制度**：校内导师+企业导师联合指导
- **实践验证**：鼓励实物制作与现场测试

### 2. 规范性要求
- **格式规范**：符合深职大论文格式标准
- **参考文献**：GB/T 7714-2015标准
- **图纸要求**：符合机械制图国家标准

### 3. 创新性要求
- **技术创新**：融入智能控制、数字化技术
- **工艺创新**：优化制造工艺，提高效率
- **应用创新**：解决企业实际问题

## 🔧 使用说明

### 快速开始
1. 下载本仓库所有文件
2. 阅读 `szpu-template.md` 了解完整要求
3. 根据 `cover-template.md` 制作封面
4. 按照 `structure-template.md` 组织论文结构
5. 参考 `format-requirements.md` 设置格式

### 分步指南
1. **选题阶段**：确定企业需求，完成开题报告
2. **设计阶段**：完成方案设计、计算、仿真
3. **制作阶段**：实物加工、实验测试
4. **撰写阶段**：论文撰写、图纸绘制
5. **答辩阶段**：PPT制作、答辩准备

## ⏰ 时间安排（16周）

| 周次 | 主要任务 | 产出成果 |
|------|----------|----------|
| 1-2 | 选题与企业对接 | 开题报告、企业确认函 |
| 3-4 | 文献调研与需求分析 | 文献综述、技术指标 |
| 5-7 | 方案设计与计算 | 总体方案、详细设计 |
| 8-10 | 仿真分析与优化 | 有限元分析、优化方案 |
| 11-13 | 实物制作与实验 | 实物样机、实验数据 |
| 14-15 | 论文撰写 | 论文初稿、完整图纸 |
| 16 | 答辩准备 | 定稿、PPT、预答辩 |

## 📖 参考文献要求

### 数量要求
- 总参考文献 ≥ 20篇
- 近5年文献 ≥ 50%
- 外文文献 ≥ 20%

### 格式要求
```
[1] 作者. 题名[J]. 期刊名, 年, 卷(期): 起止页码.
[2] 作者. 书名[M]. 出版地: 出版社, 出版年: 页码.
[3] 作者. 题名[D]. 保存地点: 保存单位, 年份.
```

## 🖼️ 图纸要求

### 图纸数量
- 总装图：1张（A0/A1）
- 部件图：1-2张（A2/A3）
- 零件图：4-6张（A3/A4）
- 三维图：1张（彩色爆炸图）

### 软件要求
- 三维设计：SolidWorks/UG/CATIA
- 二维图纸：AutoCAD/CAXA
- 分析软件：ANSYS/ABAQUS

## 🎯 答辩准备

### PPT结构（20页以内）
1. 封面（1页）
2. 选题背景与意义（1-2页）
3. 企业需求分析（1-2页）
4. 总体方案（2-3页）
5. 关键技术设计（3-4页）
6. 仿真分析（2-3页）
7. 实验验证（2-3页）
8. 创新点与成果（1-2页）
9. 致谢（1页）

### 常见问题准备
1. 你的设计创新点在哪里？
2. 如何解决设计中的技术难点？
3. 设计的经济性和可行性如何？
4. 与实际应用的差距有哪些？
