青羽教务系统 - 图标生成

请按以下步骤创建APP图标：

方法1: 使用在线工具

  1. 访问 favicon.cc 或 RealFaviconGenerator
  2. 设计或上传图标
  3. 下载 192x192 和 512x512 的 PNG 图标
  4. 将图标保存为 icon-192.png 和 icon-512.png

方法2: 使用截图工具

  1. 保存下方图标到本地
  2. 使用截图工具调整大小
🏸

图标要求

  • icon-192.png: 192 x 192 像素
  • icon-512.png: 512 x 512 像素
  • 格式: PNG (支持透明背景)

提示: 图标是可选的，没有图标时浏览器会使用默认图标。
