# 青羽教务系统 - 手机APP

## 简介

这是青羽教务系统的手机端应用，基于PWA（渐进式网页应用）技术开发。

## 安装方法

### Android

1. 用手机浏览器（推荐Chrome）打开网址
2. 点击右上角菜单，选择"添加至主屏幕"或"安装"
3. 确认安装后，桌面会出现APP图标

### iOS (iPhone/iPad)

1. 用Safari打开网址
2. 点击底部分享按钮
3. 向下滚动，点击"添加到主屏幕"
4. 点击右上角"添加"
5. 桌面会出现APP图标

## 功能

- 学员管理
- 消课点名（支持批量旷课）
- 请假管理
- 课表查看
- 临时插班生登记
- 消课记录、请假记录、旷课记录查看

## 注意事项

- 手机必须和电脑在同一网络下
- 电脑端服务器必须保持运行
- 首次使用需要等待服务器启动

## 图标设置

如需自定义图标：
1. 创建 192x192 和 512x512 的PNG图标
2. 命名为 icon-192.png 和 icon-512.png
3. 替换本目录下的图标文件
