# 青羽教务系统

## 简介

青羽教务系统是一款专为体育培训机构设计的教务管理系统，支持学员管理、消课点名、请假管理、课表编排等功能。

## 功能特点

- **三端同步**：桌面端、网页端、手机端数据实时同步
- **学员管理**：添加、编辑、删除、导入导出学员信息
- **消课点名**：支持批量消课、批量旷课
- **请假管理**：记录学员请假信息
- **课表编排**：按星期、时间段、教练排课
- **统计报表**：查看学员课时消耗情况
- **临时插班**：支持临时学员快速登记消课

## 快速开始

### 方式一：使用启动器（推荐）

1. 双击运行 `安装依赖.bat` 安装Python依赖
2. 双击运行 `青羽教务系统.bat`，选择启动模式：
   - **桌面端**：启动 tkinter 图形界面
   - **网页端**：启动浏览器访问
   - **双端同时**：同时启动桌面和网页端

### 方式二：直接运行

```bash
# 桌面端
python main.py

# 网页端
python app.py
```

## 编译独立exe（可选）

如需生成独立运行的exe文件：

1. 双击运行 `编译exe.bat`
2. 等待编译完成
3. exe文件位于 `dist\青羽教务系统_网页端\` 目录

注意：exe编译需要较长时间，且文件较大（约100MB+）

## 访问地址

### 本地访问
- 网页端：http://localhost:5000
- 手机端：http://localhost:5000/m

### 局域网访问（需在同一WiFi下）

1. 查询电脑IP：在CMD输入 `ipconfig`
2. 替换下方IP为你的电脑IP

- 网页端：http://192.168.x.x:5000
- 手机端：http://192.168.x.x:5000/m

## 目录结构

```

├── 青羽教务系统.bat      # 启动器
├── 安装依赖.bat         # 安装Python依赖
├── 编译exe.bat          # 编译独立exe（可选）
├── main.py              # 桌面端主程序
├── app.py               # 网页端服务器
├── requirements.txt     # Python依赖列表

│   └── js/              # JavaScript文件
├── 手机APP/             # 手机端PWA应用
│   ├── index.html       # 手机端入口
│   └── manifest.json    # PWA配置
└── README.txt           # 本说明文件
```

## 手机APP安装

### Android

1. 用手机浏览器（推荐Chrome）打开网页端地址
2. 点击右上角菜单，选择"添加至主屏幕"
3. 确认安装

### iOS (iPhone/iPad)

1. 用Safari打开网页端地址
2. 点击底部分享按钮
3. 点击"添加到主屏幕"
4. 确认添加
