# 第一章：TDEE每日总能耗计算

## 什么是TDEE？

**TDEE（Total Daily Energy Expenditure）** 是人体每日总能量消耗，包括：
- 基础代谢率（BMR）
- 食物热效应（TEF）
- 运动热消耗（EAT）
- 非运动活动产热（NEAT）

## 羽毛球运动员的TDEE特点

羽毛球是一项**高强度间歇性运动**，一场比赛能耗约400-500千卡，但训练课可达800-1000千卡。

### 典型消耗估算

| 活动类型 | 小时耗能(千卡) |
|---------|--------------|
| 日常活动 | 200-300 |
| 技术训练 | 400-500 |
| 对抗比赛 | 500-700 |
| 体能训练 | 600-900 |

## TDEE计算公式

### 方法一：Mifflin-St Jeor公式（推荐）

**男性：**
```
BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 + 5
```

**女性：**
```
BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 - 161
```

### 方法二：活动系数法

| 活动水平 | 系数 | 适用人群 |
|---------|------|---------|
| 久坐 | 1.2 | 几乎不运动 |
| 轻度 | 1.375 | 每周1-3次轻运动 |
| 中度 | 1.55 | 每周3-5次中等强度 |
| 重度 | 1.725 | 每周6-7次高强度 |
| 极重 | 1.9 | 运动员/体力劳动者 |

**TDEE = BMR × 活动系数**

## 羽毛球运动员的TDEE估算

### 示例：25岁男性，75kg，175cm，高强度训练

```
BMR = 10×75 + 6.25×175 - 5×25 + 5 = 750 + 1093.75 - 125 + 5 = 1723.75
TDEE = 1723.75 × 1.725 = 2975 千卡
```

### 训练周期调整

| 周期 | TDEE系数 |
|------|---------|
| 准备期 | 1.4-1.5 |
| 基础期 | 1.5-1.6 |
| 强化期 | 1.7-1.8 |
| 比赛期 | 1.6-1.7 |
| 恢复期 | 1.3-1.4 |

## 实际应用

### 体重目标调整

| 目标 | 每日热量调整 |
|------|------------|
| 减脂 | TDEE - 300~500千卡 |
| 维持 | TDEE ± 100千卡 |
| 增肌 | TDEE + 200~400千卡 |

### 营养素分配建议

对于羽毛球运动员，推荐：
- **蛋白质**：1.6-2.2g/kg体重
- **碳水**：5-8g/kg体重
- **脂肪**：0.8-1g/kg体重

## 注意事项

1. **个体差异**：代谢率有15-20%的个体差异
2. **周期调整**：根据训练周期动态调整
3. **体重监测**：每周固定时间称重，调整摄入
4. **饥饿信号**：不要长期低于BMR，否则代谢下降
