# 第六章：运动补剂速查

## 运动补剂概述

补剂是"膳食补充剂"的简称，不能替代正常饮食。在科学饮食基础上，补剂可以锦上添花。

## 补剂分级体系

```
┌─────────────────────────────────────────────┐
│  证据等级金字塔                             │
├─────────────────────────────────────────────┤
│  A级：强证据支持   ✓ 明确有效              │
│  B级：中等证据     ○ 可能有效              │
│  C级：弱证据       △ 效果存疑              │
│  D级：无证据       ✗ 不推荐                │
└─────────────────────────────────────────────┘
```

## A级推荐补剂

### 1. 乳清蛋白

| 项目 | 说明 |
|------|------|
| 作用 | 快速补充蛋白，促进肌肉修复 |
| 证据 | A级（大量研究支持） |
| 剂量 | 20-40g/次，按需 |
| 时机 | 训练后、晨起、睡前 |
| 建议 | 饮食不够时补充，首选 |

### 2. 肌酸

| 项目 | 说明 |
|------|------|
| 作用 | 增加力量、提高爆发力、改善恢复 |
| 证据 | A级（最强证据补剂之一） |
| 剂量 | 维持期：3-5g/天 |
| 周期 | 可长期使用 |
| 建议 | 必选，训练前或后均可 |

### 3. 咖啡因

| 项目 | 说明 |
|------|------|
| 作用 | 提高专注力、耐力、反应速度 |
| 证据 | A级 |
| 剂量 | 3-6mg/kg体重 |
| 时机 | 训练/比赛前30-60分钟 |
| 注意 | 敏感人群避免晚上使用 |

### 4. 维生素D

| 项目 | 说明 |
|------|------|
| 作用 | 骨骼健康、免疫、肌肉功能 |
| 证据 | A级（缺乏时） |
| 剂量 | 1000-4000IU/天 |
| 建议 | 尤其冬季/室内运动员 |

## B级可能有效的补剂

### 5. 谷氨酰胺

| 项目 | 说明 |
|------|------|
| 作用 | 免疫支持、肠道健康 |
| 证据 | B级 |
| 剂量 | 5-10g/天 |
| 建议 | 大强度训练期使用 |

### 6. 鱼油/Omega-3

| 项目 | 说明 |
|------|------|
| 作用 | 抗炎、心血管健康 |
| 证据 | B级 |
| 剂量 | EPA+DHA 1-3g/天 |
| 建议 | 每周吃2次深海鱼可替代 |

### 7. 复合维生素

| 项目 | 说明 |
|------|------|
| 作用 | 弥补饮食不足 |
| 证据 | B级（饮食不均衡时） |
| 剂量 | 按包装说明 |
| 建议 | 饮食单调时补充 |

### 8. 锌

| 项目 | 说明 |
|------|------|
| 作用 | 免疫、睾酮合成 |
| 证据 | B级（缺乏时） |
| 剂量 | 15-30mg/天 |
| 注意 | 不要过量 |

### 9. 镁

| 项目 | 说明 |
|------|------|
| 作用 | 肌肉放松、睡眠质量 |
| 证据 | B级 |
| 剂量 | 200-400mg/天 |
| 建议 | 睡前服用有助于睡眠 |

## C级效果存疑的补剂

### 10. 支链氨基酸(BCAA)

- 证据：C级
- 结论：蛋白摄入足够时无需额外补充

### 11. 氮泵(Citrulline)

- 证据：C级
- 结论：可能提升泵感，但非必需

### 12. 左旋肉碱

- 证据：C级
- 结论：减脂效果不明确

## 不推荐的补剂

### ❌ 合成类固醇

- 违法
- 严重健康危害

### ❌ 生长激素

- 违法
- 严重副作用

### ❌ 麻黄类

- 多个国家禁用
- 心脏风险

## 补剂使用原则

### 1. 优先饮食

```
补剂优先级：
正常饮食 > 基础补剂（蛋白） > 进阶补剂（肌酸） > 特殊补剂
```

### 2. 看成分而非品牌

- 关注有效成分和剂量
- 不买"神秘配方"
- 选择透明配方产品

### 3. 避免叠加

- 同时使用多种补剂风险增加
- 如需使用，先咨询专业人士

### 4. 关注来源

- 选择正规渠道
- 查看第三方检测
- 避免三无产品

## 常见问题

### Q：补剂有副作用吗？

```
答：正确剂量下，常规补剂安全性高
• 乳清蛋白：安全
• 肌酸：安全（多喝水）
• 咖啡因：敏感人群有影响
```

### Q：需要 cycling 吗？

```
• 肌酸：无需 cycling
• 咖啡因：可偶尔停用保持敏感
• 其他：看具体产品
```

### Q：国产还是进口？

```
• 正规品牌都可以
• 看成分和剂量
• 不盲目崇洋
```
