# 第三章：训练前后营养窗口

## 什么是营养窗口？

**营养窗口期（Nutrient Timing Window）** 是指训练后一段时间内，身体对营养素吸收和利用效率特别高的时段。

### 窗口期时间

| 窗口类型 | 时间范围 | 关键营养素 |
|---------|---------|-----------|
| 合成窗口 | 训练后0-30分钟 | 快速吸收蛋白+碳水 |
| 补充窗口 | 训练后30-60分钟 | 完整正餐 |
| 恢复窗口 | 训练后2-4小时 | 均衡营养 |

## 训练前营养

### 训练前饮食原则

1. **充足碳水**：保证肌糖原储备
2. **适量蛋白**：避免消化负担
3. **低脂低纤维**：减少消化时间
4. **避免新食物**：防止肠胃不适

### 训练前饮食时间表

```
训练前 3-4小时：完整正餐
├── 碳水：150-200g（米饭、面条）
├── 蛋白：20-30g（鸡胸、鱼）
├── 脂肪：少量（橄榄油）
└── 蔬菜：适量

训练前 1-2小时：轻食
├── 碳水：50-100g（香蕉、面包）
├── 蛋白：10-15g（蛋白棒）
└── 避免：脂肪、纤维

训练前 30分钟：仅补水
└── 运动饮料或水
```

### 训练前食谱示例

**场景：下午4点训练**

```
午餐（12:00）：
米饭200g + 清蒸鸡胸150g + 清炒蔬菜 + 水果

训练前加餐（15:30）：
香蕉1根 + 酸奶100g

训练前（16:00）：
水200ml
```

## 训练中营养

### 训练中补液原则

| 训练时长 | 补液策略 |
|---------|---------|
| <60分钟 | 纯水即可 |
| 60-90分钟 | 运动饮料 |
| >90分钟 | 运动饮料 + 碳水 |

### 补液量计算

```
每小时补液量 = 体重(kg) × 10-15ml
例：75kg运动员 = 750-1125ml/小时
```

### 训练中碳水补充

- 每15-20分钟补充50-100ml运动饮料
- 长时间训练可摄入能量胶或香蕉
- 避免一次性大量摄入

## 训练后营养——最关键窗口

### 为什么训练后营养最重要？

1. **糖原恢复**：补充训练消耗的肌糖原
2. **蛋白合成**：启动肌肉修复
3. **激素环境**：创造合成代谢优势
4. **免疫支持**：减少训练后免疫下降

### 训练后即时补充（0-30分钟）

**快速吸收蛋白 + 高升糖碳水**

| 营养素 | 摄入量 | 食物示例 |
|--------|--------|---------|
| 蛋白 | 20-40g | 乳清蛋白粉、蛋清、牛奶 |
| 碳水 | 0.5-1g/kg | 香蕉、面包、果汁 |

**快速修复方案：**
```
方案1：乳清蛋白粉30g + 香蕉2根
方案2：300ml牛奶 + 面包2片
方案3：酸奶200g + 水果
```

### 训练后正餐（30-60分钟）

**均衡营养素补充**

```
训练后45分钟正餐示例：

• 碳水：150-200g
  米饭200g + 土豆100g

• 蛋白：30-40g
  鸡胸200g 或 鱼250g

• 脂肪：15-20g
  橄榄油、坚果

• 蔬菜：不限量
  清炒绿叶菜
```

### 训练后餐时间线

```
时间线（以18:00训练为例）：

18:00 训练结束
  ↓
18:05 即时补充：蛋白粉+香蕉
  ↓
18:45 正式晚餐：米饭+鸡胸+蔬菜
  ↓
21:00 睡前加餐：酸奶或酪蛋白
```

## 不同训练目标的窗口期策略

### 增肌目标

- 训练后蛋白：30-40g
- 训练后碳水：1-1.5g/kg（较高）
- 总蛋白日摄入：1.8-2.2g/kg

### 减脂目标

- 训练后蛋白：30-40g（保肌）
- 训练后碳水：0.5g/kg（控制）
- 训练前避免高碳水

### 耐力目标

- 训练中持续补碳水
- 训练后高碳水：1.5-2g/kg
- 训练后适量蛋白：1.2-1.5g/kg

## 常见问题

### Q：晨练怎么吃？

```
晨练前：
• 喝一杯水
• 简单水果（如香蕉）
• 或空腹训练（<60分钟）

晨练后：
• 正式早餐（丰富碳水+蛋白）
```

### Q：晚上训练怎么吃？

```
训练前2小时：
• 正常晚餐（减量）

训练后：
• 蛋白粉 + 水果
• 或简单加餐（避免太撑影响睡眠）
```

### Q：没胃口怎么办？

```
• 喝液态（奶昔、果汁）
• 少量多餐
• 选择易消化的食物
• 不要强迫进食，但保证基本补充
```
