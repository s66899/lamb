# 第七章：体重管理与减脂策略

## 羽毛球运动员的体重管理

体重管理对羽毛球运动员尤为重要：
- 移动速度与体重直接相关
- 跳跃高度受体重影响
- 体脂过高影响耐力和灵活

## 体脂率与运动表现

### 羽毛球运动员理想体脂

| 性别 | 竞技水平 | 理想体脂率 |
|------|---------|-----------|
| 男性 | 专业 | 8-12% |
| 男性 | 业余 | 12-16% |
| 女性 | 专业 | 14-18% |
| 女性 | 业余 | 18-22% |

### 体脂率自测

```
目测法：
• 腹肌可见 = 15%以下
• 肋骨隐约可见 = 12-15%
• 血管清晰可见 = 8-12%
• 赛季比赛状态 = 专业级别
```

## 减脂原则

### 安全减脂速度

```
每月减重：0.5-1kg（每周0.1-0.25kg）
├─ 过快影响运动表现
├─ 肌肉流失风险
└─ 代谢下降风险
```

### 热量赤字

```
减脂热量公式：
TDEE - 300~500千卡 = 每日摄入

不推荐：
• < TDEE - 500（影响太大）
• < BMR（代谢损伤）
```

## 减脂期营养策略

### 碳水循环法

| 训练日 | 碳水摄入 | 策略 |
|--------|---------|------|
| 大强度日 | 5-6g/kg | 高碳水，维持表现 |
| 休息日 | 3-4g/kg | 低碳水，促进脂肪燃烧 |

### 蛋白质保底

```
减脂期蛋白质建议：
• 1.8-2.2g/kg（保肌）
• 高蛋白增加饱腹感
• 食物热效应高
```

### 脂肪摄入

```
减脂期脂肪：0.6-0.8g/kg
• 过低影响激素水平
• 不要完全戒脂
```

## 减脂饮食示例

### 75kg男性运动员减脂期

```
目标：-500千卡/天
基础TDEE：3000千卡 → 目标2500千卡

蛋白质：150g（600千卡）
碳水：250g（1000千卡）
脂肪：60g（540千卡）
总热量：2140千卡
```

### 一天食谱示例

```
早餐：鸡蛋3个 + 燕麦80g + 香蕉1根
午餐：鸡胸200g + 米饭150g + 蔬菜
加餐：酸奶150g
训练后：蛋白粉30g + 香蕉1根
晚餐：鱼200g + 红薯150g + 蔬菜
睡前：奶酪50g
```

## 增肌期体重管理

### 增肌不增脂

```
• 每日热量盈余：200-400千卡
• 蛋白质：1.8-2.2g/kg
• 碳水：训练日6g/kg，休息日4g/kg
• 脂肪：0.8-1g/kg
• 增重速度：每月0.5kg
```

### 干净增肌 vs 脏增肌

| 类型 | 热量 | 增肌速度 | 脂肪增长 |
|------|------|---------|---------|
| 干净增肌 | +200-300 | 慢 | 少 |
| 激进增肌 | +500+ | 快 | 多 |

**建议：** 干净增肌，赛季前减脂

## 体重称量与分析

### 称重时间

```
• 固定时间：晨起排便后
• 固定衣服：内衣或裸体
• 每周记录趋势
```

### 体重波动原因

| 原因 | 波动范围 |
|------|---------|
| 水分 | ±1kg/天 |
| 碳水 | ±0.5-1kg |
| 食物 | ±0.5kg |
| 真正脂肪变化 | 每周0.25-0.5kg |

### 趋势分析

```
一周数据：
周一：75.0kg
周二：75.2kg（外食）
周三：74.8kg
周四：74.9kg
周五：75.1kg（外食）
周六：74.7kg
周日：74.6kg

趋势：-0.4kg/周 ✓ 正常
```

## 特殊情况处理

### 赛前减重

```
赛前1周策略：
• 减少碳水摄入
• 增加排水（低碳水+高钾）
• 赛前1天：少盐+多水+碳水loading

注意：只适合有经验的运动员
```

### 体重停滞

```
平台期突破：
• 检查热量是否真正控制
• 调整碳水循环
• 增加NEAT（非运动消耗）
• 考虑欺骗餐
• 复查训练强度
```
