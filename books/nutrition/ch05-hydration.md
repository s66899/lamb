# 第五章：水合与电解质平衡

## 水合——被忽视的运动表现因素

水是生命之源，对运动员尤为关键：
- 体温调节
- 营养运输
- 关节润滑
- 代谢反应
- 认知功能

## 脱水的影响

### 脱水程度与表现下降

| 体重下降 | 症状 | 表现影响 |
|---------|------|---------|
| 1% | 轻微口渴 | 可忽略 |
| 2% | 口渴、尿深 | 力量耐力下降5-10% |
| 3% | 疲劳、头晕 | 有氧下降10-15% |
| 4% | 严重疲劳 | 协调性下降30% |
| 5%+ | 危险 | 热射病风险 |

### 羽毛球运动的水分流失

一场羽毛球比赛（60-90分钟）：
- 出汗量：500-1500ml
- 快速移动+高强度间歇 → 散热需求大

## 每日水需求计算

### 基本公式

```
每日水需求 = 体重(kg) × 30-35ml
例：75kg运动员 = 2250-2625ml
```

### 训练额外补充

```
训练中补液 = 训练时长(小时) × 500-1000ml
根据强度调整：
├─ 低强度：500ml/小时
├─ 中等强度：750ml/小时
└─ 高强度：1000ml/小时
```

## 电解质——维持平衡的关键

### 关键电解质功能

| 电解质 | 主要功能 | 流失症状 |
|--------|---------|---------|
| 钠 | 水分平衡、神经传导 | 肌肉痉挛、头晕 |
| 钾 | 肌肉收缩、心率 | 疲劳、抽筋 |
| 镁 | 能量代谢、肌肉放松 | 抽筋、心悸 |
| 氯 | 消化液、酸碱平衡 | 乏力、恶心 |

### 运动员电解质需求

| 电解质 | 每日需求 | 训练中额外 |
|--------|---------|-----------|
| 钠 | 1500-2300mg | 500-1000mg/小时 |
| 钾 | 2600-3400mg | 200-400mg/小时 |
| 镁 | 400-420mg | 额外补充 |
| 氯 | 1800-2300mg | 随钠补充 |

## 训练中的补液策略

### 补液原则

```
┌──────────────────────────────────────┐
│  预防性补液 > 感到口渴再补液        │
│  口渴时已脱水2%                     │
└──────────────────────────────────────┘
```

### 补液量计算

**训练前：**
- 训练前2小时：500-600ml
- 训练前15分钟：200-300ml

**训练中：**
- 每15-20分钟：150-250ml
- 长时间训练（>60分钟）：补充电解质

**训练后：**
- 体重每减轻1kg：补充1.5L液体
- 包含电解质（尤其是钠）

### 不同场景的补液

| 场景 | 推荐饮品 | 配方 |
|------|---------|------|
| <60分钟训练 | 纯水 | - |
| 60-90分钟 | 运动饮料 | 低糖+电解质 |
| >90分钟 | 运动饮料+水 | 按需补充 |
| 高温环境 | 冷运动饮料 | 冰镇 |

## 运动饮料DIY

### 基础运动饮料配方

```
原料：
• 水：1000ml
• 盐：1/4茶匙（约1g）
• 糖：2汤匙（30g）
• 柠檬汁：少许

制作：溶解即可
成本：约1元/升
```

### 高强度训练配方

```
原料：
• 水：1000ml
• 盐：1g
• 钾（可选）：香蕉1根
• 糖：40g
• 柠檬汁：少许
```

## 监测水合状态

### 尿液颜色法

```
颜色对比：
⚪ 透明或淡黄 ✓ 良好水合
🟡 深黄色 ⚠️ 轻度脱水
🟠 橙色 ❌ 脱水
🔴 棕色  🚨 严重脱水
```

### 尿量监测

- 每日尿量：1-2L
- 排尿次数：4-6次/天
- 每次排尿量：200-300ml

### 体重监测

- 训练前后称重
- 每减轻1kg体重 = 1L水分流失
- 及时补充

## 特殊情况处理

### 高温天气

- 增加50%补液量
- 降低训练强度
- 增加休息次数
- 穿着透气服装

### 赛前水合

```
赛前24小时：
• 保持正常饮水
• 避免咖啡因（利尿）

赛前2小时：
• 喝水500-600ml

赛前30分钟：
• 少量喝水（100-200ml）

赛中：
• 每15分钟补液
```

### 赛后恢复

```
训练后2小时内：
• 补充流失的150%水分
• 包含电解质（尤其是钠）
• 包含碳水（帮助吸收）
```

## 常见误区

### ❌ 运动中大量喝水

- 胃部不适
- 可能导致低钠血症
- 正确：少量多次

### ❌ 只喝白开水

- 电解质流失
- 影响运动表现
- 正确：长时间运动加电解质

### ❌ 感到口渴才喝水

- 口渴时已脱水
- 正确：预防性补液

### ❌ 运动后喝冰水

- 刺激胃肠道
- 正确：常温或微凉
