# 第二章：三大营养素科学分配

## 羽毛球运动员的营养素框架

运动员营养的核心是**三大营养素**的合理配比：
- 碳水化合物（Carbohydrates）
- 蛋白质（Protein）
- 脂肪（Fat）

## 一、碳水化合物——能量主力

### 为什么碳水是羽毛球运动员的首要营养素？

羽毛球是**高糖原依赖**运动：
- 比赛时肌肉糖原储备直接供能
- 快速供能满足高强度爆发需求
- 维持血糖稳定保证专注力

### 碳水摄入量

| 训练强度 | 碳水(g/kg体重) | 75kg运动员示例 |
|---------|--------------|---------------|
| 休息日 | 3-4 | 225-300g |
| 轻训练 | 4-5 | 300-375g |
| 中等训练 | 5-6 | 375-450g |
| 大强度/比赛 | 6-10 | 450-750g |

### 碳水质量分级

```
┌─────────────────────────────────────────┐
│           碳水选择金字塔               │
├─────────────────────────────────────────┤
│  顶端：精制糖    ❌ 限制摄入           │
│  饮料、甜点、糖果                      │
├─────────────────────────────────────────┤
│  中层：全谷物    ✓ 适量               │
│  糙米、燕麦、全麦面包                  │
├─────────────────────────────────────────┤
│  底层：蔬菜水果   ✓✓ 鼓励             │
│  香蕉、苹果、浆果、根茎类               │
└─────────────────────────────────────────┘
```

### 训练日碳水时机

| 时间点 | 碳水策略 |
|--------|---------|
| 早餐 | 复合碳水为主，稳定血糖 |
| 训练前2-3h | 中等升糖指数，200-300g |
| 训练中 | 快速碳水，每15min补50-100ml |
| 训练后 | 高升糖指数，0.5-1g/kg |

## 二、蛋白质——修复与建设

### 羽毛球运动员蛋白质需求

研究表明，运动员蛋白质需求高于普通人：

| 目标 | 蛋白质(g/kg体重) | 75kg运动员 |
|------|-----------------|-----------|
| 维持 | 1.2-1.4 | 90-105g |
| 增肌 | 1.6-2.2 | 120-165g |
| 减脂保肌 | 1.8-2.4 | 135-180g |

### 蛋白质来源选择

**优质蛋白（必需氨基酸完整）：**
- 🐟 鱼类：三文鱼、金枪鱼（富含Omega-3）
- 🍗 禽类：鸡胸、火鸡
- 🥩 瘦肉：牛腱、猪里脊
- 🥚 蛋类：全蛋、蛋清
- 🥛 乳制品：希腊酸奶、奶酪
- 🫘 植物：豆腐、豆类（需搭配）

### 蛋白质时机

```
训练后窗口期：训练后30-60分钟补充20-40g优质蛋白
              （乳清蛋白或鸡胸+米饭）
              
每日分布：每3-4小时补充一次，单次不超过40g
          吸收效率最高
```

### 常见误区

❌ 只吃蛋白粉 → 天然食物更全面
❌ 蛋白质越多越好 → 超过2.4g/kg增加肾脏负担
❌ 只吃动物蛋白 → 植物蛋白含膳食纤维和抗氧化剂

## 三、脂肪——被误解的重要营养素

### 脂肪的生理作用

- **激素合成**：睾酮、皮质醇等激素的原料
- **维生素吸收**：脂溶性维生素A、D、E、K需要脂肪
- **能量储备**：长时间低强度活动的燃料
- **细胞膜健康**：维持神经系统和大脑功能

### 羽毛球运动员脂肪摄入

| 类型 | 摄入建议 | 来源 |
|------|---------|------|
| 饱和脂肪 | <10%总热量 | 肥肉、动物油 |
| 单不饱和 | 10-15% | 橄榄油、牛油果 |
| 多不饱和 | 5-10% | 深海鱼、坚果 |

### Omega-3对运动员的特殊价值

- 减轻训练后的肌肉炎症
- 促进肌肉恢复
- 改善心血管健康
- 支持大脑功能

**推荐来源：** 三文鱼、鲭鱼、亚麻籽、核桃

## 四、营养素配比示例

### 增肌期（75kg运动员，3000千卡/天）

| 营养素 | 热量占比 | 克数 | 食物示例 |
|--------|---------|------|---------|
| 碳水 | 50% | 375g | 米饭500g+香蕉3根+燕麦100g |
| 蛋白 | 25% | 188g | 鸡胸300g+三文鱼200g+蛋4个 |
| 脂肪 | 25% | 83g | 橄榄油30g+牛油果1个+坚果50g |

### 减脂期（75kg运动员，2200千卡/天）

| 营养素 | 热量占比 | 克数 | 食物示例 |
|--------|---------|------|---------|
| 碳水 | 40% | 220g | 米饭300g+红薯200g+蔬菜不限 |
| 蛋白 | 35% | 193g | 鸡胸400g+蛋4个+鱼200g |
| 脂肪 | 25% | 61g | 橄榄油20g+牛油果半个+坚果30g |

## 五、实用技巧

### 1. 估算食物营养

```
• 1拳蛋白质 ≈ 20-25g
• 1捧碳水 ≈ 25-30g  
• 1拇指脂肪 ≈ 7-10g
```

### 2. 一天三餐示例（训练日）

```
早餐：燕麦100g + 蛋3个 + 牛奶250ml + 香蕉1根
午餐：米饭200g + 鸡胸200g + 蔬菜沙拉 + 橄榄油
加餐：酸奶200g + 坚果30g
训练后：蛋白粉30g + 香蕉2根 + 面包100g
晚餐：鱼肉300g + 红薯200g + 蔬菜 + 橄榄油
```

### 3. 外出就餐选择

| 场景 | 推荐选择 | 避免 |
|------|---------|------|
| 中餐 | 清蒸、白切 | 油炸、红烧 |
| 西餐 | 烤鸡鱼、沙拉 | 牛排、奶油酱 |
| 日料 | 刺身、寿司 | 天妇罗 |
