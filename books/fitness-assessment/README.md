## 🎯 为什么需要这本书

NSCA-CPT ch08「评估 / 测试 / 处方周期」讲了**专业测试**与计划周期；但**业余选手每天看手环屏幕**，那一屏的"心率 68 / 步数 8420 / 睡眠 7h12m / 静息 HR 56 / VO₂max 48 / HRV 65 / 训练负荷 320 / 压力 38"——**单独看都没意义**，只有和"个人基线 + 周环比"对比才有训练决策价值。

这就是本书要做的事。

## 📝 设计原则

1. **数据本地**——所有数据存浏览器 LocalStorage，不上传服务器
2. **趋势优先**——折线图让"今天数字异常"立刻显现
3. **30 天/90 天滚动窗口**——只保留最近 90 天数据，避免 LocalStorage 膨胀
4. **基线参考表**——每项指标给成年人基线区间，辅助用户解读
