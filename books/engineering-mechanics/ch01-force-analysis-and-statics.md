# 第一章：受力分析与静力学基础——一切力学的起点

> 力是什么？
> 如果你不能准确地说出"什么是力"，你就没有资格说"我懂力学"。
> 力学不是背公式，而是理解物体为什么会运动（或不运动）。

**主题**：用动机心理学克服工程力学学习中的拖延懒惰

## 本章导言

工程力学是所有机械、土木、航空等专业的基础课。它的核心问题只有一个：**物体在力的作用下如何运动或保持静止**。

静力学是工程力学的起点——研究物体在力的作用下保持平衡的条件。如果一个建筑物的结构不满足静力学条件，它就会倒塌。

这一章，我们从**力学专业角度**学习受力分析和静力学基础，同时用**动机心理学**分析：为什么你总是"看到公式就头疼"，如何克服对力学的恐惧。

---

## 一、力的基本概念

### 1.1 什么是力（Force）？

**定义**：力是物体之间的相互作用，会使物体产生加速度或发生形变。

**力的三要素**：
- **大小**：力的数量值（单位：牛顿N，千牛顿kN）
- **方向**：力作用的方向（同一大小不同方向的力，效果完全不同）
- **作用点**：力作用在物体上的位置（作用点不同，力产生的转动效果不同）

**两个力的合力**（平行四边形法则）：
两个力可以合成为一个合力，合力的大小和方向由平行四边形对角线确定。

**motivation分析**：为什么你总觉得力学"太抽象"？

因为力是一个"看不见摸不着"的概念，不像温度、长度那样直观。

克服方法：
- 把"力"想象成"推"或"拉"的动作——你推桌子，桌子就动
- 从生活中找力的例子：风吹旗帜（风力）、水坝挡水（水压力）、绳子拉车（拉力）

### 1.2 力的单位

**国际单位制（SI）**：
- 基本单位：千克·米/秒² = 牛顿（N）
- 1 N ≈ 举起一个苹果所需的力
- 1 kN = 1000 N（工程中常用千牛顿）

**重力与质量的区别**：
- 质量：物体含物质的量（kg），是固有属性
- 重力：地球对物体的吸引力（N），G = mg（g ≈ 9.8 m/s²）
- 质量50kg的人，重力约490 N

**常见错误**：把"kg"当成力的单位——这是错的，kg是质量单位。

## 二、力的分类与常见力

### 2.1 常见力类型

**重力（W）**：地球对物体的吸引力，方向竖直向下，大小 W = mg

**弹力（N）**：两个物体接触并发生形变时产生的力，方向垂直于接触面

**摩擦力（f）**：两个物体相对滑动或有滑动趋势时产生的力
- 静摩擦力：两个物体相对静止但有滑动趋势
- 滑动摩擦力：f = μN（μ为摩擦系数）

**拉力/压力**：通过绳索或杆件传递的力

### 2.2 约束与约束反力

**约束**：限制物体运动的物体（如地面、墙壁、铰链）

**约束反力**：约束对物体的反作用力

**常见约束类型**：
- **柔索约束**：只能承受拉力（如绳索、链条），反力沿绳索方向
- **光滑接触面约束**：只能承受压力，反力垂直于接触面
- **固定铰支座**：反力通过铰链中心，方向未知，通常分解为水平和竖直两个分力
- **可动铰支座**：反力垂直于支撑面
- **固定端约束**：产生反力和反力偶

**motivation分析**：为什么你"知道约束类型，但不会画受力图"？

因为你把"记忆约束类型"当成了"理解约束"。但约束反力是"被动的"——约束不主动施力，只在被其他物体推动时产生反作用。

关键理解：**约束反力的方向取决于主动力的方向**，不是固定不变的。

## 三、受力图——工程力学的"地基"

### 3.1 什么是受力图（Free Body Diagram）？

受力图是把研究对象从周围物体中"隔离"出来，单独画出它受到的所有力的图示。

**受力图是解题的第一步，也是最重要的一步**——如果受力图画错了，后面的计算全部白费。

### 3.2 画受力图的步骤

1. **确定研究对象**：明确要分析哪个物体（或物体系统）
2. **画出所有主动力**：重力、已知外力、已知力偶
3. **画出所有约束反力**：根据约束类型，画出对应的反力
4. **检查**：每个接触处是否有反力？每个力都有施力物体吗？

**常见错误**：
- 漏画某个力（尤其是约束反力）
- 多画了不存在的力
- 把反作用力当成主动力画上去

### 3.3 实例分析

**例子**：水平梁AB，左端A为固定铰支座，右端B为可动铰支座，梁上受集中力F（竖直向下，作用点距A为a）和均布载荷q（kN/m）。

**受力图分析**：
- 梁受到主动力：集中力F（向下）、均布载荷q（向下）
- A点约束反力：水平分力RAx、竖直分力RAy（方向假设向上）
- B点约束反力：RB（方向竖直向上）

**motivation分析**：为什么"受力图一看就会，一画就错"？

因为你只是在"看"解题过程，而不是"自己画"。看懂了不等于会画——受力图需要空间想象力，需要大量练习才能熟练。

克服方法：
- 每道题都自己画受力图，不要看答案
- 画完后和答案对照，检查哪里画错了
- 准备一个"受力图检查清单"：主动力✓ 约束反力✓ 方向✓ 大小✓

## 四、静力学基础——平衡条件

### 4.1 平衡的定义

**平衡**：物体在力系作用下保持静止或匀速直线运动的状态。

在工程中，我们主要研究的是**静止平衡**。

### 4.2 平面力系的平衡条件

**平面力系**：所有力都在同一平面内的力系。

**平衡条件**：
∑Fx = 0（所有水平分力的代数和为0）
∑Fy = 0（所有竖直分力的代数和为0）
∑M = 0（所有力对任一点的力矩代数和为0）

**三个方程，三个未知数**——这是静力学解题的基本模式。

### 4.3 力矩

**力矩的定义**：力对物体转动效应的度量。

**力矩公式**：M = F × d

其中d为力臂（力的作用线到转动中心的垂直距离）

**正负约定**：
- 逆时针为正（使物体逆时针转动）
- 顺时针为负（使物体顺时针转动）

**力矩平衡**：∑M = 0 意味着物体不发生转动。

**motivation分析**：为什么"公式记得住，但力矩计算总是错"？

因为你把"力臂"和"力的作用线到转动点的距离"混淆了。力臂是**垂直距离**，不是几何距离。

关键：力臂 = 力作用线到转动中心的垂直距离，不是两点连线的距离。

---

## 五、平面力系平衡问题的解题步骤

### 5.1 标准解题流程

1. **选取研究对象**：选择合适的物体或物体系统
2. **画受力图**：正确画出所有主动力和约束反力
3. **建立坐标系**：选择便于计算的x、y轴方向
4. **列平衡方程**：
   - ∑Fx = 0
   - ∑Fy = 0
   - ∑M = 0（通常对未知力最多的点取矩，消去不需要的未知数）
5. **求解方程**：代入已知数据，求解未知量
6. **校核结果**：检查计算是否满足所有平衡条件

### 5.2 典型例题

**例题**：水平梁AB，长度L=4m，A端固定铰支，B端可动铰支。梁上距A点1m处受集中力F=10kN（竖直向下）。

求：支座反力RA和RB。

**解题**：
1. 研究对象：梁AB
2. 受力图：A点有RAx和RAy，B点有RB（竖直向上）
3. 建立坐标：x轴水平，y轴竖直
4. 列平衡方程：
   - ∑Fx = 0 → RAx = 0
   - ∑Fy = 0 → RAy + RB - 10 = 0
   - ∑MA = 0 → RB × 4 - 10 × 1 = 0 → RB = 2.5 kN
5. 代入得：RAy = 10 - 2.5 = 7.5 kN
6. 校核：∑Fy = 7.5 + 2.5 - 10 = 0 ✓

**motivation分析**：为什么"看答案懂了，自己做又不会"？

因为你跳过了"自己思考"的过程，直接看答案。答案告诉你的是"是什么"，但没有告诉你"怎么想到"。

正确方法：
- 先自己思考5-10分钟，实在做不出来再看答案
- 看懂答案后，合上答案，**重新做一遍**
- 重点关注："我卡在哪一步？答案从哪一步开始和我想的不一样？"

## 六、本章小结

1. **力是矢量，有大小、方向和作用点**——三要素缺一不可
2. **约束反力是被动力，方向取决于主动力**——约束不主动施力
3. **受力图是解题的地基**——画错受力图，后面的计算全部白费
4. **平衡条件：∑Fx=0, ∑Fy=0, ∑M=0**——三个方程解三个未知数
5. **力臂是垂直距离，不是几何距离**——力矩计算中的常见错误
6. **看懂答案不等于会做题**——必须合上答案重新做一遍
