## 3.1 轴向拉压的基本概念与工程实例

### 3.1.1 轴向拉压的定义

在工程结构中，当作用于杆件的外力合力作用线与杆件轴线重合时，杆件将发生沿轴线方向的伸长或缩短。这种变形形式称为**轴向拉伸**（axial tension）或**轴向压缩**（axial compression），统称为**轴向拉压**。

轴向拉压的力学特征可概括为：

1. **外力特征**：作用于杆端的外力合力作用线与杆的轴线重合。
2. **变形特征**：杆件沿轴线方向均匀伸长（拉伸）或缩短（压缩），横截面发生相应的减小（拉伸时）或增大（压缩时）。
3. **内力特征**：横截面上仅存在沿轴线方向的内力——**轴力**（axial force），记为 $F_N$（或 $N$）。无弯矩、无扭矩、无剪力。

### 3.1.2 典型工程实例

**实例一：桁架结构中的拉压杆**

桁架（truss）是由直杆通过铰接节点连接而成的结构体系。在节点荷载作用下，桁架中各杆件仅承受轴向拉力或轴向压力。例如，屋架中的上弦杆通常受压，下弦杆通常受拉，腹杆则根据受力方向或拉或压。桁架桥、输电塔、起重机臂架等均广泛采用这种结构形式。

**实例二：起重钢丝绳**

吊车起吊重物时，钢丝绳承受轴向拉力。钢丝绳的直径、材质和缠绕方式必须根据最大起重量进行设计，以确保其拉伸强度满足安全要求。安全系数通常取 $5\sim10$，视使用场合而定。

**实例三：混凝土柱与钢柱**

建筑物中的柱子承受上部结构传来的竖向荷载，属于典型的轴向压缩构件。短柱的承载力由材料抗压强度控制；细长柱则可能因失稳（屈曲）而破坏，这属于稳定性问题，将在后续章节讨论。

**实例四：螺栓连接**

机械连接中广泛使用的螺栓，在预紧力和工作载荷作用下主要承受轴向拉力。螺栓的强度计算需要同时考虑静载强度和疲劳强度。

**实例五：液压缸活塞杆**

液压缸中的活塞杆在工作时承受轴向压力或拉力，其截面尺寸由最大轴向力和材料许用应力共同确定。

### 3.1.3 基本假设

在轴向拉压分析中，采用以下基本假设：

1. **连续性假设**：材料内部无空隙，力学量可表示为坐标的连续函数。
2. **均匀性假设**：材料各处的力学性质相同。
3. **各向同性假设**：材料沿各方向的力学性质相同（适用于金属等各向同性材料）。
4. **小变形假设**：变形相对于构件原始尺寸很小，平衡方程可按变形前构形建立。
5. **平截面假设**：变形前为平面的横截面，变形后仍保持为平面，且仍垂直于变形后的杆轴线。

## 3.2 轴力与轴力图

### 3.2.1 截面法与轴力

确定杆件横截面上内力的基本方法是**截面法**（method of sections），其步骤为：

1. **截开**：在待求内力截面处，用一个假想的平面将杆件截分为两部分。
2. **代替**：任取其中一部分为研究对象，用内力代替移去部分对该部分的作用。
3. **平衡**：对所取部分建立平衡方程，解出内力。

对于轴向拉压杆，截面上的内力即轴力 $F_N$。通常规定：
- **拉力**（tension）：轴力方向离开截面，$F_N > 0$，杆件受拉伸长。
- **压力**（compression）：轴力方向指向截面，$F_N < 0$，杆件受压缩短。

### 3.2.2 轴力图

当杆件沿轴线方向作用多个外力时，不同截面上的轴力各不相同。用图形表示轴力沿杆轴线变化规律的图线称为**轴力图**（axial force diagram）。

绘制轴力图的步骤：

1. 根据外力作用点将杆件分段。
2. 在各段内任取一截面，用截面法求得该段内的轴力表达式。
3. 以杆轴线为横坐标、轴力值为纵坐标，绘制轴力变化曲线。
4. 在轴力图上标注各特征点的轴力值及正负号。

**例题 3-1**：一等截面直杆受力如图 3-1 所示。$F_1 = 40\,\text{kN}$（←），$F_2 = 25\,\text{kN}$（→），$F_3 = 55\,\text{kN}$（→），$F_4 = 20\,\text{kN}$（←）。杆件分为 AB、BC、CD 三段。试求各段轴力并绘制轴力图。

**解**：

采用截面法，自左向右逐段分析。

（1）**AB 段**（截面 1-1）：

取截面 1-1 左侧为研究对象。设轴力 $F_{N1}$ 为拉力（方向向右）。

$$\sum F_x = 0: \quad -F_1 + F_{N1} = 0$$

$$F_{N1} = F_1 = 40\,\text{kN}\quad (\text{拉})$$

（2）**BC 段**（截面 2-2）：

取截面 2-2 左侧为研究对象。

$$\sum F_x = 0: \quad -F_1 + F_2 + F_{N2} = 0$$

$$F_{N2} = F_1 - F_2 = 40 - 25 = 15\,\text{kN}\quad (\text{拉})$$

（3）**CD 段**（截面 3-3）：

取截面 3-3 右侧为研究对象。

$$\sum F_x = 0: \quad -F_{N3} - F_4 = 0$$

$$F_{N3} = -F_4 = -20\,\text{kN}\quad (\text{压})$$

**轴力图**：

- AB 段：$F_N = +40\,\text{kN}$（正值，画在基线上方）
- BC 段：$F_N = +15\,\text{kN}$（正值，画在基线上方）
- CD 段：$F_N = -20\,\text{kN}$（负值，画在基线下方）

在集中外力作用点处，轴力图发生突变，突变量等于该集中外力的大小。

## 3.3 应力分析

### 3.3.1 正应力的概念

内力是截面上分布内力的合力。要判断构件是否发生破坏，必须知道截面上各点的受力强度——**应力**（stress）。

轴向拉压杆横截面上的内力为轴力 $F_N$，内力方向垂直于横截面。因此，横截面上各点处的应力方向也垂直于横截面，称为**正应力**（normal stress），用 $\sigma$ 表示。

### 3.3.2 横截面上的正应力

根据**平截面假设**，轴向拉压杆变形前为平面的横截面变形后仍为平面。由此可以推断：横截面上各点的纵向线应变相同。对于均匀材料，由应力-应变关系可知，横截面上各点的正应力也相同，即正应力在横截面上均匀分布。

由此得出轴向拉压杆横截面正应力公式：

$$\sigma = \frac{F_N}{A}$$

其中：
- $\sigma$ —— 横截面上的正应力（Pa 或 MPa）
- $F_N$ —— 该截面上的轴力（N）
- $A$ —— 横截面面积（m² 或 mm²）

正应力的符号规定与轴力一致：拉应力为正（$\sigma > 0$），压应力为负（$\sigma < 0$）。

**注意**：上述均匀分布结论仅适用于等截面直杆承受轴向荷载且离开力作用点足够远处。在集中力作用点附近的局部区域，应力分布不均匀，此即**圣维南原理**（Saint-Venant's principle）所描述的现象。圣维南原理指出：在距离荷载作用区域约等于截面特征尺寸（如直径）处，应力分布趋于均匀。

### 3.3.3 斜截面上的应力

取一与横截面成 $\alpha$ 角的斜截面。设横截面面积为 $A$，则斜截面面积 $A_\alpha = A / \cos\alpha$。斜截面上的轴力仍为 $F_N$。

斜截面上的总应力（均匀分布）为：

$$p_\alpha = \frac{F_N}{A_\alpha} = \frac{F_N}{A / \cos\alpha} = \sigma_0 \cos\alpha$$

其中 $\sigma_0 = F_N / A$ 为横截面上的正应力。

将 $p_\alpha$ 分解为垂直于斜截面的**正应力** $\sigma_\alpha$ 和平行于斜截面的**切应力** $\tau_\alpha$：

$$\sigma_\alpha = p_\alpha \cos\alpha = \sigma_0 \cos^2\alpha = \frac{\sigma_0}{2}(1 + \cos2\alpha)$$

$$\tau_\alpha = p_\alpha \sin\alpha = \sigma_0 \sin\alpha \cos\alpha = \frac{\sigma_0}{2}\sin2\alpha$$

分析：

- 当 $\alpha = 0°$（横截面）：$\sigma_{\max} = \sigma_0$，$\tau = 0$。横截面上正应力最大。
- 当 $\alpha = 45°$：$\tau_{\max} = \sigma_0 / 2$，$\sigma = \sigma_0 / 2$。45° 斜截面上切应力最大。
- 当 $\alpha = 90°$（纵截面）：$\sigma = 0$，$\tau = 0$。

这一分析说明：轴向拉压杆中不仅存在正应力，在斜截面上还存在切应力。低碳钢拉伸试件表面出现的约 45° 方向的滑移线，正是最大切应力所致。

## 3.4 应变分析

### 3.4.1 正应变（线应变）

杆件受轴向拉力作用时，沿轴线方向伸长，横向尺寸减小。为描述变形的程度，引入**正应变**（normal strain，也称线应变）的概念。

设杆件原长为 $l$，变形后的长度为 $l + \Delta l$，其中 $\Delta l$ 为轴向伸长量（拉伸时 $\Delta l > 0$，压缩时 $\Delta l < 0$）。则**轴向线应变**（工程应变）定义为：

$$\varepsilon = \frac{\Delta l}{l}$$

线应变为无量纲量，常用 $\mu\varepsilon$（微应变，$1\mu\varepsilon = 10^{-6}$）表示。

在小变形条件下，杆件各处应变均匀，$\varepsilon$ 为常数。

### 3.4.2 泊松比（横向变形系数）

轴向拉伸时，杆件在垂直于轴线方向（横向）发生收缩。设杆件原始横向尺寸为 $b$，变形后变化量为 $\Delta b$（收缩时 $\Delta b < 0$），则横向线应变为：

$$\varepsilon' = \frac{\Delta b}{b}$$

在弹性范围内，横向应变与轴向应变之比的绝对值是一个常数，称为**泊松比**（Poisson's ratio），记为 $\mu$（或 $\nu$）：

$$\mu = \left| \frac{\varepsilon'}{\varepsilon} \right| = -\frac{\varepsilon'}{\varepsilon}$$

于是横向应变可表示为：

$$\varepsilon' = -\mu\varepsilon$$

泊松比是材料固有的弹性常数。常见材料的泊松比范围：
- 钢材：$\mu \approx 0.25 \sim 0.33$
- 铝合金：$\mu \approx 0.31 \sim 0.34$
- 混凝土：$\mu \approx 0.16 \sim 0.20$
- 橡胶：$\mu \approx 0.47 \sim 0.50$（接近不可压缩材料）
- 软木：$\mu \approx 0$（几乎无横向变形）

泊松比的取值范围：对各向同性线弹性材料，理论上 $-1 < \mu < 0.5$。常见工程材料的 $\mu$ 均为正值，一般在 $0.2 \sim 0.4$ 之间。

### 3.4.3 体积应变

轴向拉压杆在变形过程中体积也发生变化。设杆件原始体积 $V = Al$，变形后体积为：

$$V' = A(1 + \varepsilon')^2 \cdot l(1 + \varepsilon) = Al (1 + \varepsilon)(1 - \mu\varepsilon)^2$$

略去高阶微量，体积应变（单位体积的体积变化）为：

$$\theta = \frac{\Delta V}{V} = \frac{V' - V}{V} \approx \varepsilon(1 - 2\mu)$$

分析：
- 当 $\mu = 0.5$ 时，$\theta = 0$，材料不可压缩。
- 当 $\mu < 0.5$ 时，拉伸时 $\theta > 0$（体积增大），压缩时 $\theta < 0$（体积减小）。
- 当 $\mu > 0.5$ 时（理论上不可实现），拉伸反而使体积减小。

多数金属材料 $\mu \approx 0.3$，在弹性范围内拉伸时体积略微增大。

## 3.5 胡克定律与弹性模量

### 3.5.1 胡克定律

实验表明：在弹性范围内，杆件的轴向变形 $\Delta l$ 与轴力 $F_N$ 及杆长 $l$ 成正比，与截面面积 $A$ 成反比。这一关系称为**胡克定律**（Hooke's law），其数学表达式为：

$$\Delta l = \frac{F_N l}{EA}$$

其中 $E$ 为**弹性模量**（elastic modulus，也称杨氏模量 Young's modulus），单位为 Pa 或 GPa。乘积 $EA$ 称为杆件的**抗拉（压）刚度**，它反映了杆件抵抗轴向变形的能力：$EA$ 越大，在相同轴力下变形越小。

将 $\sigma = F_N / A$ 与 $\varepsilon = \Delta l / l$ 代入上式，得到胡克定律的应力-应变形式：

$$\sigma = E\varepsilon$$

这是材料力学中最基本、最重要的本构关系之一。它表明：在弹性范围内，正应力与线应变成正比，比例常数为弹性模量 $E$。

### 3.5.2 弹性模量

弹性模量 $E$ 是材料固有的力学性能参数，反映了材料抵抗弹性变形的能力。常见材料的弹性模量：

| 材料 | 弹性模量 $E$（GPa） |
|------|---------------------|
| 低碳钢 | 200 ~ 210 |
| 合金钢 | 190 ~ 220 |
| 铸铁 | 100 ~ 160 |
| 铝合金 | 69 ~ 79 |
| 铜合金 | 100 ~ 130 |
| 钛合金 | 105 ~ 120 |
| 混凝土（C30） | 约 30 |
| 木材（顺纹） | 8 ~ 12 |
| 玻璃纤维复合材料 | 30 ~ 50 |
| 碳纤维复合材料 | 200 ~ 600 |

$E$ 值越大，材料越"刚硬"，在相同应力下产生的应变越小。

### 3.5.3 剪切胡克定律

与正应力-正应变关系类似，在弹性范围内，切应力 $\tau$ 与切应变 $\gamma$ 也成正比，即**剪切胡克定律**：

$$\tau = G\gamma$$

其中 $G$ 为**剪切弹性模量**（shear modulus），也称切变模量。

对各向同性线弹性材料，$E$、$G$ 和 $\mu$ 之间存在如下关系：

$$G = \frac{E}{2(1 + \mu)}$$

三个弹性常数中仅有两个是独立的。已知任意两个即可求出第三个。

## 3.6 拉压杆的变形计算

### 3.6.1 等截面直杆、常轴力情况

当杆件为等截面且轴力沿杆长不变时，直接应用胡克定律：

$$\Delta l = \frac{F_N l}{EA}$$

若轴力为拉力，$\Delta l > 0$（伸长）；若轴力为压力，$\Delta l < 0$（缩短）。

### 3.6.2 变轴力或变截面情况

当轴力沿杆长分段变化或截面尺寸沿杆长变化时，需分段计算或积分：

**分段计算法**（轴力分段变化）：

$$\Delta l = \sum_{i=1}^{n} \frac{F_{Ni} l_i}{E_i A_i}$$

其中 $F_{Ni}$、$l_i$、$E_i$、$A_i$ 分别为第 $i$ 段的轴力、长度、弹性模量和截面面积。

**积分法**（轴力或截面沿杆长连续变化）：

$$\Delta l = \int_0^l \frac{F_N(x)}{EA(x)} \, dx$$

### 3.6.3 例题：变截面阶梯杆的变形

**例题 3-2**：一阶梯形圆杆受力如图所示。AB 段直径 $d_1 = 30\,\text{mm}$，BC 段直径 $d_2 = 20\,\text{mm}$，CD 段直径 $d_3 = 25\,\text{mm}$。各杆段长度分别为 $l_{\text{AB}} = 300\,\text{mm}$，$l_{\text{BC}} = 400\,\text{mm}$，$l_{\text{CD}} = 200\,\text{mm}$。所受外力：$F_B = 40\,\text{kN}$（→），$F_C = 20\,\text{kN}$（←）。弹性模量 $E = 200\,\text{GPa}$。试求杆端 D 的总位移。

**解**：

首先计算各段截面面积：

$$A_{\text{AB}} = \frac{\pi d_1^2}{4} = \frac{\pi \times 30^2}{4} = 706.86\,\text{mm}^2$$

$$A_{\text{BC}} = \frac{\pi d_2^2}{4} = \frac{\pi \times 20^2}{4} = 314.16\,\text{mm}^2$$

$$A_{\text{CD}} = \frac{\pi d_3^2}{4} = \frac{\pi \times 25^2}{4} = 490.87\,\text{mm}^2$$

用截面法求各段轴力：

- **AB 段**：取 1-1 截面左侧，$\sum F_x = 0$，$F_{N\text{AB}} = 40\,\text{kN}$（拉）
- **BC 段**：取 2-2 截面左侧，$F_{N\text{BC}} = 40 - 20 = 20\,\text{kN}$（拉）
- **CD 段**：取 3-3 截面左侧，$F_{N\text{CD}} = 40 - 20 = 20\,\text{kN}$（拉）

各段变形：

$$\Delta l_{\text{AB}} = \frac{F_{N\text{AB}} l_{\text{AB}}}{E A_{\text{AB}}} = \frac{40 \times 10^3 \times 300}{200 \times 10^3 \times 706.86} = 0.0849\,\text{mm}$$

$$\Delta l_{\text{BC}} = \frac{F_{N\text{BC}} l_{\text{BC}}}{E A_{\text{BC}}} = \frac{20 \times 10^3 \times 400}{200 \times 10^3 \times 314.16} = 0.1273\,\text{mm}$$

$$\Delta l_{\text{CD}} = \frac{F_{N\text{CD}} l_{\text{CD}}}{E A_{\text{CD}}} = \frac{20 \times 10^3 \times 200}{200 \times 10^3 \times 490.87} = 0.0407\,\text{mm}$$

D 端总位移：

$$\delta_D = \Delta l_{\text{AB}} + \Delta l_{\text{BC}} + \Delta l_{\text{CD}} = 0.0849 + 0.1273 + 0.0407 = 0.253\,\text{mm} \rightarrow$$

### 3.6.4 温度变形与装配应力简介

当温度变化 $\Delta T$ 时，杆件将发生自由热胀冷缩：

$$\Delta l_T = \alpha \cdot l \cdot \Delta T$$

其中 $\alpha$ 为材料的**线膨胀系数**（$^\circ\text{C}^{-1}$ 或 $\text{K}^{-1}$）。

常见材料的线膨胀系数：
- 钢：$\alpha \approx 1.2 \times 10^{-5} / ^\circ\text{C}$
- 铝：$\alpha \approx 2.3 \times 10^{-5} / ^\circ\text{C}$
- 铜：$\alpha \approx 1.7 \times 10^{-5} / ^\circ\text{C}$
- 混凝土：$\alpha \approx 1.0 \times 10^{-5} / ^\circ\text{C}$

若杆件的热变形受到外部约束，则杆件内将产生**温度应力**：

$$\sigma_T = E\alpha\Delta T$$

## 3.7 材料的力学性能

### 3.7.1 拉伸试验与应力-应变曲线

材料的力学性能通过标准试验测定。最常用的是**常温静载拉伸试验**。将标准试件（常用圆截面比例试件，标距 $l_0 = 5d$ 或 $10d$）在万能试验机上进行缓慢拉伸，记录荷载 $F$ 与伸长量 $\Delta l$ 的关系，经换算得到**应力-应变曲线**（$\sigma$-$\varepsilon$ 曲线）。

根据应力-应变曲线的特征，工程材料大致分为两类：

1. **塑性材料**（ductile materials）：破坏前发生显著的塑性变形，如低碳钢、铝合金等。
2. **脆性材料**（brittle materials）：破坏前塑性变形很小，突然断裂，如铸铁、混凝土、玻璃等。

### 3.7.2 低碳钢拉伸的力学性能

低碳钢是典型的塑性材料，其拉伸应力-应变曲线可分为四个阶段：

**（1）弹性阶段（OA 段）**

- OA 段为直线，应力与应变成正比，服从胡克定律：$\sigma = E\varepsilon$。
- A 点对应的应力称为**比例极限**（proportional limit），记为 $\sigma_p$。
- 低碳钢的 $\sigma_p \approx 200\,\text{MPa}$。
- 弹性模量 $E = \tan\alpha$，即 OA 段的斜率。低碳钢 $E \approx 200 \sim 210\,\text{GPa}$。

超过比例极限后，应力-应变关系不再保持线性，但若在 B 点（弹性极限 $\sigma_e$）以下卸载，变形仍可完全恢复。比例极限与弹性极限数值接近，工程上通常不加区分。

**（2）屈服阶段（BC 段）**

- 当应力达到一定值后，应力不再增加甚至略有下降而应变持续增长，曲线上出现水平波动段（屈服平台）。这一现象称为**屈服**（yielding）。
- 屈服阶段的最小应力称为**屈服极限**或**屈服强度**（yield strength），记为 $\sigma_s$（或 $R_{eL}$）。
- 低碳钢的 $\sigma_s \approx 235\,\text{MPa}$（Q235 钢）。
- 屈服时试件表面出现约 45° 方向的滑移线，这是材料内部晶格沿最大切应力方向滑移所致。
- 工程中将屈服强度作为塑性材料强度设计的主要依据。当应力达到 $\sigma_s$ 时，构件将产生显著的塑性变形，影响正常使用。

有些材料（如铝合金、高强钢）无明显屈服平台，则以产生 $0.2\%$ 塑性应变时的应力作为**条件屈服强度**，记为 $\sigma_{0.2}$（或 $R_{p0.2}$）。

**（3）强化阶段（CD 段）**

- 屈服阶段之后，材料重新表现出抵抗变形的能力，应力随应变增大而增大，称为**强化**（strain hardening）。
- 曲线最高点 D 对应的应力称为**抗拉强度**（tensile strength）或**强度极限**，记为 $\sigma_b$（或 $R_m$）。
- 低碳钢的 $\sigma_b \approx 370 \sim 460\,\text{MPa}$。
- 抗拉强度是材料所能承受的最大名义应力。

**（4）颈缩与断裂阶段（DE 段）**

- 应力达到 $\sigma_b$ 后，试件某一局部区域的截面急剧缩小，形成**颈缩**（necking）。
- 由于截面面积减小，承载能力下降，直至 E 点断裂。
- 记断裂后标距长度 $l_1$ 和最小截面面积 $A_1$，定义：

  **伸长率**（elongation）：

  $$\delta = \frac{l_1 - l_0}{l_0} \times 100\%$$

  **断面收缩率**（reduction of area）：

  $$\psi = \frac{A_0 - A_1}{A_0} \times 100\%$$

  低碳钢的 $\delta \approx 20\% \sim 30\%$，$\psi \approx 60\% \sim 70\%$。

### 3.7.3 材料塑性的衡量指标

工程上通常规定：$\delta \geq 5\%$ 的材料为**塑性材料**，$\delta < 5\%$ 的材料为**脆性材料**。

冷作硬化：若在强化阶段某点卸载，再重新加载，材料的比例极限和屈服强度将提高，而塑性降低。这种现象称为**冷作硬化**（cold working／work hardening）。工程上可利用冷作硬化提高钢筋、钢丝绳等的强度，但会降低塑性。

### 3.7.4 铸铁等脆性材料的拉伸与压缩力学性能

**铸铁拉伸**：
- 应力-应变曲线无明显的直线段，无屈服阶段和颈缩现象。
- 断裂突然发生，断口平齐，垂直于轴线（正应力引起的脆性断裂）。
- 抗拉强度 $\sigma_b \approx 100 \sim 300\,\text{MPa}$（与牌号有关）。
- 铸铁拉伸的伸长率极小（通常 $< 1\%$），属于典型的脆性材料。

**铸铁压缩**：
- 抗压强度远高于抗拉强度（约为抗拉强度的 $3 \sim 5$ 倍）。
- 断裂面与轴线约成 $45°\sim 55°$ 角（最大切应力所致）。
- 压缩时表现出一定的塑性变形。

**混凝土**：
- 受压强度远大于受拉强度（抗拉强度约为抗压强度的 $1/10 \sim 1/20$）。
- 应力-应变关系非线弹性，弹性模量随应力变化。
- 受拉时几乎无塑性变形，突然脆断。

### 3.7.5 许用应力与安全系数

将材料的极限应力（塑性材料的 $\sigma_s$ 或 $\sigma_{0.2}$，脆性材料的 $\sigma_b$）除以大于 1 的**安全系数**（factor of safety）$n$，得到**许用应力**（allowable stress）：

$$[\sigma] = \frac{\sigma_u}{n}$$

其中 $\sigma_u$ 为极限应力（塑性材料取 $\sigma_s$，脆性材料取 $\sigma_b$）。

安全系数的选取需综合考虑材料性质的离散性、荷载估计的准确性、计算模型的近似性、构件的重要性以及工作环境等因素。一般取值范围：
- 塑性材料静载：$n_s = 1.5 \sim 2.5$
- 脆性材料静载：$n_b = 2.0 \sim 3.5$

## 3.8 拉压杆的强度设计

### 3.8.1 强度条件

轴向拉压杆的强度条件为：杆件最大工作应力不得超过材料的许用应力。

$$\sigma_{\max} = \frac{F_{N\max}}{A} \leq [\sigma]$$

### 3.8.2 三类强度计算问题

**（1）强度校核**：已知荷载、截面尺寸和材料许用应力，验算 $\sigma_{\max} \leq [\sigma]$ 是否满足。

**（2）截面设计**：已知荷载和材料许用应力，确定最小截面尺寸：

$$A \geq \frac{F_{N\max}}{[\sigma]}$$

**（3）确定许可荷载**：已知截面尺寸和材料许用应力，确定构件所能承受的许可轴力：

$$F_{N\text{allow}} \leq [\sigma] A$$

进而反推许可外荷载。

### 3.8.3 例题：强度校核与截面设计

**例题 3-3**：一圆截面钢拉杆承受轴向拉力 $F = 180\,\text{kN}$。钢材的屈服强度 $\sigma_s = 235\,\text{MPa}$，取安全系数 $n_s = 1.5$。（1）试设计所需最小直径；（2）若杆件直径 $d = 36\,\text{mm}$，试校核其强度。

**解**：

（1）**截面设计**：

许用应力：

$$[\sigma] = \frac{\sigma_s}{n_s} = \frac{235}{1.5} = 156.7\,\text{MPa}$$

所需最小截面面积：

$$A_{\min} = \frac{F}{[\sigma]} = \frac{180 \times 10^3}{156.7} = 1148.7\,\text{mm}^2$$

最小直径：

$$d_{\min} = \sqrt{\frac{4A_{\min}}{\pi}} = \sqrt{\frac{4 \times 1148.7}{\pi}} = 38.3\,\text{mm}$$

选用直径 $d = 39\,\text{mm}$。

（2）**强度校核**（$d = 36\,\text{mm}$）：

截面面积：

$$A = \frac{\pi \times 36^2}{4} = 1017.9\,\text{mm}^2$$

工作应力：

$$\sigma = \frac{F}{A} = \frac{180 \times 10^3}{1017.9} = 176.8\,\text{MPa}$$

由于 $\sigma = 176.8\,\text{MPa} > [\sigma] = 156.7\,\text{MPa}$，不满足强度要求。

### 3.8.4 应力集中的概念

在截面尺寸突变处（如开孔、切槽、台阶、螺纹根部等），局部应力远大于按均匀分布计算的名义应力，这一现象称为**应力集中**（stress concentration）。应力集中的严重程度用**理论应力集中系数** $K_t$ 衡量：

$$K_t = \frac{\sigma_{\max}}{\sigma_{\text{nom}}}$$

其中 $\sigma_{\max}$ 为局部最大应力，$\sigma_{\text{nom}}$ 为按净截面面积计算的名义应力。

应力集中对塑性材料和脆性材料的影响不同：
- **塑性材料**：当局部应力达到屈服强度时，该区域材料屈服，应力重新分布，使峰值下降，故静载下应力集中对塑性材料的强度影响不大。
- **脆性材料**：无屈服阶段，局部高应力可直接导致开裂，故应力集中对脆性材料的强度影响显著，设计时应特别注意避免截面突变。

## 3.9 超静定问题简介

### 3.9.1 静定与超静定的概念

若未知约束反力（或内力）的数目等于独立的静力平衡方程数目，则所有未知力均可由平衡方程唯一确定，这类问题称为**静定问题**（statically determinate problem）。

若未知力的数目多于独立平衡方程数目，则仅靠平衡方程无法求解全部未知力，这类问题称为**超静定问题**（statically indeterminate problem，也称静不定问题）。超静定问题必须补充**变形协调条件**（compatibility condition）才能求解。

超静定次数 $= $ 未知力总数 $-$ 独立平衡方程数。

### 3.9.2 超静定拉压问题的解法

求解超静定拉压问题的基本步骤：

1. **建立静力平衡方程**：列出所有独立的平衡方程。
2. **建立变形协调方程**：根据结构的几何约束条件，确定各杆件变形之间的关系。
3. **建立物理方程**：利用胡克定理，将变形与内力联系起来。
4. **联立求解**：将物理方程代入变形协调方程，与平衡方程联立，解出全部未知力。

### 3.9.3 例题：装配应力问题

**例题 3-4**：两根材料相同（$E$ 相同）、截面面积均为 $A$ 的等长拉杆，分别连接刚性梁两端和一个固定支座上（形成对称结构）。若中间杆的制造长度比理论长度短了 $\Delta$（制造误差），试求装配后各杆的内力。

**解**：

设装配后两侧斜杆受拉力 $F_{N1}$，中间竖杆受拉力 $F_{N2}$（或压力，取决于变形协调结果）。

该结构为一次超静定问题（3 个内力未知数，2 个节点平衡方程）。

（1）**平衡方程**（由节点平衡）：

两侧斜杆内力相等，记为 $F_{N1}$。设斜杆与竖直方向夹角为 $\theta$。

$$\sum F_y = 0: \quad 2F_{N1}\cos\theta + F_{N2} = 0$$

（2）**变形协调关系**：

设节点位移为 $\delta$，则斜杆伸长量：

$$\Delta l_1 = \delta \cos\theta + \Delta$$

中杆伸长量：

$$\Delta l_2 = \delta - \Delta$$

其中 $\Delta$ 为制造误差（中杆偏短）。

（3）**物理方程**：

$$\Delta l_1 = \frac{F_{N1} l_1}{EA}, \quad \Delta l_2 = \frac{F_{N2} l_2}{EA}$$

此处 $l_1$、$l_2$ 分别为斜杆和中杆长度。

（4）**联立求解**：

将物理方程代入变形协调关系，消去 $\delta$，得到 $F_{N1}$ 与 $F_{N2}$ 的关系。再与平衡方程联立，解出各自内力。

装配应力随制造误差 $\Delta$ 增大而增大。在工程中，装配应力可能大到使构件提前破坏或影响正常使用，因此在设计和施工中应严格控制制造公差。

### 3.9.4 温度应力的超静定特征

当温度变化时，超静定结构中因温度变形受约束而产生的温度应力远大于静定结构。例如，两端固定的等截面直杆温度升高 $\Delta T$，固定端约束限制其自由膨胀，杆内产生压力：

$$\sigma_T = -E\alpha\Delta T$$

对于钢杆，温度仅升高 $50^\circ\text{C}$，温度应力可达：

$$\sigma_T = 200 \times 10^3 \times 1.2 \times 10^{-5} \times 50 = 120\,\text{MPa}$$

可见，温度应力能达到相当大的数值，在工程设计中不可忽略。工程中常在长管道中设置伸缩节（补偿器）、在桥梁中设置伸缩缝以释放温度变形。

## 3.10 典型综合例题

### 例题 3-5：多层变截面杆

一等截面钢柱高度 $H = 3\,\text{m}$，截面为圆环形，外径 $D = 200\,\text{mm}$，内径 $d = 160\,\text{mm}$。柱顶承受轴向压力 $F = 800\,\text{kN}$，同时柱自重不可忽略（钢材容重 $\gamma = 78\,\text{kN}/\text{m}^3$）。$E = 200\,\text{GPa}$。求：
（1）柱底截面最大正应力；
（2）柱的轴向缩短量。

**解**：

环截面面积：

$$A = \frac{\pi}{4}(D^2 - d^2) = \frac{\pi}{4}(200^2 - 160^2) = 11309.7\,\text{mm}^2$$

（1）**柱底截面最大正应力**：

柱底截面轴力为柱顶荷载加上全柱自重：

$$F_{N\text{max}} = F + \gamma A H = 800 + 78 \times 11309.7 \times 10^{-6} \times 3 = 800 + 2.65 = 802.65\,\text{kN}$$

$$\sigma_{\max} = \frac{F_{N\text{max}}}{A} = \frac{802.65 \times 10^3}{11309.7} = 71.0\,\text{MPa}\ (\text{压})$$

（2）**柱的轴向缩短量**：

距柱顶 $x$ 处的轴力：

$$F_N(x) = F + \gamma A x$$

总变形积分：

$$\Delta l = \int_0^H \frac{F_N(x)}{EA} \, dx = \frac{1}{EA}\int_0^H (F + \gamma A x) \, dx$$

$$= \frac{1}{EA} \left( F H + \frac{\gamma A H^2}{2} \right)$$

$$= \frac{1}{200 \times 10^3 \times 11309.7} \left( 800 \times 10^3 \times 3000 + \frac{78 \times 10^{-6} \times 11309.7 \times 3000^2}{2} \right)$$

$$= \frac{1}{2.262 \times 10^9} \left( 2.4 \times 10^9 + 3.97 \times 10^6 \right)$$

$$= \frac{2.404 \times 10^9}{2.262 \times 10^9} = 1.06\,\text{mm}$$

柱顶荷载引起的变形占绝对主导，自重影响约为 $0.18\%$，在短柱中通常可忽略。但对于高度极大的结构（如高塔、深井钻杆），自重引起的变形和应力不可忽略。

### 例题 3-6：超静定杆系

三根弹性模量均为 $E$ 的钢杆铰接于节点 A，构成对称平面杆系。两侧杆长度均为 $l_1$，截面积均为 $A_1$，与竖直方向夹角 $\theta = 30°$。中杆长度为 $l_2$，截面积为 $A_2$。节点 A 处作用一竖直向下的荷载 $F = 100\,\text{kN}$。已知 $A_1 = 500\,\text{mm}^2$，$A_2 = 800\,\text{mm}^2$，$E = 200\,\text{GPa}$，$l_2 = 2\,\text{m}$。试求各杆内力及节点 A 的竖向位移。

**解**：

一次超静定问题。

（1）**平衡方程**：

由对称性，两侧杆内力相等，$F_{N1}$（拉力）；中杆内力 $F_{N2}$（拉力或压力待定）。

节点 A 竖直方向平衡：

$$2F_{N1}\cos30° + F_{N2} - F = 0$$

$$1.732F_{N1} + F_{N2} = 100\,\text{kN} \quad \cdots (1)$$

（2）**变形协调关系**：

设节点 A 向下位移 $\delta$（由于对称性，只有竖向位移）。

两斜杆伸长（斜杆与竖直方向夹角 $\theta = 30°$）：

$$\Delta l_1 = \delta \cos30° = 0.866\delta$$

中杆伸长（$l_2 = 2 \,\text{m}$）：

$$\Delta l_2 = \delta$$

（3）**物理方程**：

$$l_1 = l_2 / \cos30° = 2 / 0.866 = 2.309\,\text{m}$$

$$\Delta l_1 = \frac{F_{N1} l_1}{EA_1} = \frac{F_{N1} \times 2.309 \times 10^3}{200 \times 10^3 \times 500} = 2.309 \times 10^{-5}\,F_{N1}$$

$$\Delta l_2 = \frac{F_{N2} l_2}{EA_2} = \frac{F_{N2} \times 2 \times 10^3}{200 \times 10^3 \times 800} = 1.25 \times 10^{-5}\,F_{N2}$$

（4）**变形协调条件**：

由 $\Delta l_1 = 0.866\,\Delta l_2$ 得（因 $\delta = \Delta l_2$）：

$$2.309 \times 10^{-5}\,F_{N1} = 0.866 \times 1.25 \times 10^{-5}\,F_{N2}$$

$$F_{N1} = 0.469\,F_{N2} \quad \cdots (2)$$

（5）**联立求解**：

将式（2）代入式（1）：

$$1.732 \times 0.469\,F_{N2} + F_{N2} = 100$$

$$0.812\,F_{N2} + F_{N2} = 100$$

$$F_{N2} = 55.2\,\text{kN}\ (\text{拉})$$

$$F_{N1} = 0.469 \times 55.2 = 25.9\,\text{kN}\ (\text{拉})$$

（6）**节点位移**：

$$\delta = \Delta l_2 = 1.25 \times 10^{-5} \times 55.2 \times 10^3 = 0.69\,\text{mm}\ (\text{向下})$$

## 3.11 本章小结

轴向拉伸与压缩是材料力学中最基本的受力形式。本章内容可归纳为以下核心要点：

**（1）内力分析**：截面法是求内力的基本方法。轴力图的绘制是进行后续分析和设计的基础。轴力符号约定——拉力为正，压力为负。

**（2）应力分析**：横截面上正应力均匀分布，$\sigma = F_N / A$。斜截面上同时存在正应力和切应力，最大切应力发生在 $45°$ 斜截面上。

**（3）应变分析**：轴向线应变 $\varepsilon = \Delta l / l$。横向变形由泊松比 $\mu$ 描述，$\varepsilon' = -\mu\varepsilon$。

**（4）本构关系**：胡克定律 $\sigma = E\varepsilon$ 和 $\Delta l = F_N l / (EA)$ 是联系应力与应变、力与变形的核心公式。$E$ 为弹性模量，反映材料刚度；$EA$ 为抗拉压刚度。

**（5）材料力学性能**：应力-应变曲线揭示了材料的力学行为。比例极限 $\sigma_p$、屈服强度 $\sigma_s$（或 $\sigma_{0.2}$）、抗拉强度 $\sigma_b$ 是关键强度指标。塑性材料与脆性材料的破坏模式有本质区别。

**（6）强度设计**：$\sigma_{\max} \leq [\sigma]$ 是基本强度条件。安全系数的合理选取是连接理论分析与工程实践的关键环节。

**（7）超静定问题**：当未知力数超过平衡方程数时，需引入变形协调条件求解。温度应力和装配应力是超静定结构的典型工程问题。

**（8）圣维南原理与应力集中**：荷载作用方式只影响其附近区域的应力分布。截面突变处的应力集中对脆性材料的影响远大于塑性材料。

轴向拉压的基本理论是学习后续弯曲、扭转、组合变形和压杆稳定等内容的基础。读者应牢固掌握截面法、轴力图的绘制、胡克定律的应用以及强度校核方法，并能熟练处理简单的超静定问题。
