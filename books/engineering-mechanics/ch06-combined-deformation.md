# 第六章：组合变形——应力与应变的综合分析

> 工程结构中的构件通常承受多种载荷，
> 组合变形分析是理解实际工程问题的基础。

---

## 一、组合变形的基本概念

### 1.1 什么是组合变形

组合变形是指构件在外部载荷作用下，同时发生两种或两种以上基本变形的现象。在实际工程中，纯粹的单一变形很少见，大多数构件承受的是组合变形。

**常见的组合变形类型：**

**弯曲与拉伸（或压缩）的组合：**
偏心拉伸或压缩是典型的弯曲与拉伸的组合变形。例如，斜拉桥的缆索同时承受轴向拉力和弯曲作用；压力容器上的接管同时承受内压产生的薄膜应力和接管区域的弯曲应力。

**弯曲与扭转的组合：**
转轴是弯曲与扭转组合变形的典型实例。当转轴传递功率时，同时承受弯矩和扭矩的作用。机械工程中的传动轴、搅拌轴等都属于这种类型。

**拉伸、弯曲与扭转的组合：**
这种组合变形最为复杂，常见于同时承受轴向载荷、横向载荷和扭矩作用的构件。例如，钻杆在钻进过程中同时承受轴向压力、弯曲载荷和扭矩。

### 1.2 组合变形的研究方法

研究组合变形的基本方法是**叠加原理**。

**叠加原理的条件：**

叠加原理适用于线性弹性范围，即应力与应变保持线性关系，且变形微小不影响载荷的作用方向。当满足这些条件时，组合变形的结果等于各个基本变形单独作用结果的叠加。

**叠加原理的应用步骤：**

首先，将组合载荷分解为若干个简单载荷，每个简单载荷只产生一种基本变形。然后，分别计算每种基本变形下的应力和应变。最后，将相同点的应力和应变进行代数叠加，得到组合变形下的总应力和总应变。

### 1.3 组合变形的强度条件

组合变形的强度条件基于**第三强度理论**（最大切应力理论）或**第四强度理论**（形状改变比能理论）。

**第三强度理论的强度条件：**

σ_max - σ_min ≤ [σ]

其中，σ_max和σ_min是危险点上最大和最小主应力，[σ]是材料的许用应力。

**第四强度理论的强度条件：**

√(σ1² + σ2² + σ3² - σ1σ2 - σ2σ3 - σ3σ1) ≤ [σ]

对于平面应力状态，第四强度理论的相当应力为：

σ_eq = √(σ_x² + σ_y² - σ_xσ_y + 3τ_xy²)

## 二、斜弯曲

### 2.1 斜弯曲的概念

当载荷的作用方向不通过截面的形心时，构件将发生斜弯曲。斜弯曲是两个平面弯曲的组合，两个方向的弯曲变形不在同一平面内。

**常见实例：**

门框上的横梁承受门扇重量的作用，载荷方向通常是倾斜的；工业厂房中的吊车梁承受吊车起重力的作用，由于吊车位置的偏心，载荷也是倾斜的；高层建筑中的框架柱承受水平风荷载和竖向重力荷载的共同作用。

### 2.2 斜弯曲的应力计算

**应力计算的基本公式：**

在斜弯曲情况下，任意点的正应力等于两个方向弯曲正应力的代数和：

σ = M_z·y / I_z ± M_y·z / I_y

其中，M_z和M_y是关于z轴和y轴的弯矩，I_z和I_y是相应的惯性矩，y和z是点到坐标轴的距离。

**应力符号的确定：**

应力符号取决于点的位置和弯矩的方向。以中性轴为界，一侧为拉应力，另一侧为压应力。拉应力取正号，压应力取负号。

### 2.3 斜弯曲的中性轴

斜弯曲的中性轴是一条通过截面形心的斜线。中性轴上各点的正应力为零。

**中性轴方程：**

令σ = 0，得到中性轴方程：

M_z·y / I_z - M_y·z / I_y = 0

即：y / (M_y·I_z / M_z·I_y) = z / (I_z / I_y)

中性轴与坐标轴的夹角为：

tan θ = I_z·M_y / (I_y·M_z)

其中，θ是中性轴与y轴的夹角。

### 2.4 斜弯曲的强度计算

**强度计算步骤：**

首先，计算危险截面上的弯矩分量M_z和M_y。然后，确定危险点（通常位于距中性轴最远的点）。最后，计算危险点的最大正应力并与许用应力比较。

**截面设计：**

对于斜弯曲构件，合理的截面形状应该使截面对两个主轴的惯性矩比值与相应的弯矩比值接近，即：

I_z / I_y ≈ M_y / M_z

这样可以使两个方向的弯曲应力同时接近材料的极限，提高材料利用率。

## 三、拉伸（或压缩）与弯曲的组合

### 3.1 偏心拉伸（或压缩）

当轴向载荷的作用线不通过构件的轴线时，产生偏心拉伸或偏心压缩。偏心载荷可以分解为一个轴向力和一个弯矩，因此偏心拉伸（或压缩）是轴向拉伸（或压缩）与弯曲的组合。

**偏心距的概念：**

偏心距e是载荷作用线到截面形心的距离。偏心距越大，弯曲效应越显著。

**应力计算公式：**

偏心拉伸（或压缩）时，截面上的正应力为：

σ = N/A ± M·y / I

其中，N是轴向力，M = N·e是偏心弯矩，A是截面面积，I是截面惯性矩。

### 3.2 截面核心

截面核心是截面形心周围的一个区域。当载荷作用点位于截面核心内时，截面上只有压应力，没有拉应力。

**截面核心的意义：**

对于脆性材料（如铸铁），由于抗拉强度较低，应力全为压应力可以避免拉应力导致的破坏。因此，偏心载荷的作用点应尽可能位于截面核心内。

**截面核心的求法：**

以矩形截面为例，截面核心是一个以截面形心为中心的菱形。菱形的对角线长度分别为b/3和h/3，其中b和h是截面的宽度和高度。

圆形截面的截面核心是一个与圆同心的圆，半径为D/4，其中D是圆截面的直径。

### 3.3 强度计算实例

**案例：压力机机架的立柱分析**

压力机立柱承受偏心拉力作用，立柱截面为矩形，宽度为b，高度为h，偏心距为e。立柱承受的拉力为N。

**应力分布：**

截面上的最大拉应力发生在靠近载荷作用点的一侧：

σ_max = N/A + N·e·y_max / I

截面上的最小应力发生在另一侧：

σ_min = N/A - N·e·y_max / I

**强度校核：**

取绝对值最大的应力进行强度校核：

σ_max,| = N/A + N·e·c / I ≤ [σ]

其中，c是边缘到形心的距离，c = h/2。

## 四、扭转与弯曲的组合

### 4.1 弯扭组合的概念

同时承受弯曲和扭转作用的构件称为弯扭组合构件。这种组合变形在工程中非常普遍，尤其是各类旋转轴。

**典型实例：**

传动轴传递功率时，同时承受弯矩和扭矩的作用。弯矩由轴上的皮带轮、齿轮等部件的重量以及传动过程中的动载荷产生；扭矩由功率传递产生。

### 4.2 弯扭组合的应力分析

**弯曲正应力：**

σ_b = M·c / I

其中，M是弯矩，c是中性轴到边缘的距离，I是截面惯性矩。

**扭转切应力：**

τ_t = T·ρ / J

其中，T是扭矩，ρ是点到圆心的距离，J是极惯性矩。

**对于圆截面构件：**

弯曲正应力最大值：σ_b,max = 32M / (πd³)

扭转切应力最大值：τ_t,max = 16T / (πd³)

其中，d是圆截面的直径。

### 4.3 弯扭组合的强度理论

**第三强度理论（最大切应力理论）：**

对于弯扭组合的圆轴，相当应力为：

σ_eq3 = √(σ_b² + 4τ_t²)

代入应力表达式：

σ_eq3 = √[(32M / πd³)² + 4(16T / πd³)²]
      = 16 / (πd³) √(M² + T²)

**第四强度理论（形状改变比能理论）：**

相当应力为：

σ_eq4 = √(σ_b² + 3τ_t²)

代入应力表达式：

σ_eq4 = 16 / (πd³) √(M² + 0.75T²)

### 4.4 弯扭组合构件的设计

**设计步骤：**

首先，根据功率和转速计算扭矩T。然后，初步考虑弯曲影响，估计弯矩M（通常取M = (0.3~0.6)T）。接着，按扭转或弯扭组合确定轴的直径。最后，进行强度校核。

**空心圆轴的优越性：**

在相同扭矩传递能力下，空心圆轴比实心圆轴使用更少的材料。但空心轴的制造难度较大，通常用于对重量敏感或材料成本较高的场合（如航空、汽车领域）。

## 五、组合变形的位移计算

### 5.1 莫尔积分法

组合变形的位移计算可以采用莫尔积分法。莫尔积分法的基本公式为：

Δ = Σ∫(M·M_bar / EI) ds

其中，M是实际载荷产生的弯矩，M_bar是单位载荷产生的弯矩，E是弹性模量，I是截面惯性矩。

对于不同类型变形的组合，需要分别计算各分量的位移，然后进行矢量合成。

### 5.2 能量法

**卡氏定理：**

卡氏定理提供了一种计算位移的系统方法。对于线性弹性系统，任意点的位移等于系统总位能对该点力的偏导数：

δ_i = ∂U / ∂P_i

其中，U是系统的总位能，P_i是作用在位移点上的广义力。

**单位载荷法：**

单位载荷法是莫尔积分法的另一种表述。在需要计算位移的点上，施加单位载荷，然后计算实际载荷和单位载荷产生的内力，最后应用莫尔积分。

### 5.3 组合变形位移计算实例

**案例：悬臂梁的组合变形**

悬臂梁承受均布载荷q和端部集中力F的作用，同时产生弯曲和剪切变形。

**弯曲位移：**

梁自由端的弯曲挠度：

v_b = (qL⁴/8EI) + (FL³/3EI)

**剪切位移：**

梁自由端的剪切挠度：

v_s = k∫(V·V_bar / GA) ds

其中，k是截面形状系数，V是实际剪力，V_bar是单位剪力。

**总位移：**

总位移为弯曲位移和剪切位移的代数和。通常情况下，弯曲位移是主要的，剪切位移较小，可以忽略。但在短粗梁中，剪切位移的影响不可忽视。

## 六、组合变形的实验研究

### 6.1 应变花测量技术

应变花是测量平面应力状态下主应力和主方向的实验技术。常用的应变花有45°直角应变花和60°三轴应变花。

**45°应变花：**

三个测量角度分别为0°、45°、90°。根据三个方向的应变值，可以计算主应变和主方向：

ε_max = (ε_0 + ε_90)/2 + (1/2)√[(ε_0 - ε_45)² + (ε_45 - ε_90)²]

γ_max = √[(ε_0 - ε_45)² + (ε_45 - ε_90)²]

tan 2θ = (2ε_45 - ε_0 - ε_90) / (ε_0 - ε_90)

### 6.2 光弹性实验方法

光弹性方法是一种基于光学原理的全场实验技术。当透明材料模型受载时，模型内产生双折射现象，通过偏振光观测，可以获得应力分布的全场信息。

**等差线条纹：**

等差线条纹反映主应力差值相等的位置。通过条纹级次，可以计算主应力差值：

σ1 - σ2 = 2n·f / t

其中，n是条纹级次，f是材料条纹值，t是模型厚度。

### 6.3 有限元分析方法

有限元方法（FEM）是分析组合变形问题的强大工具。通过将连续体离散为有限个单元，可以求解复杂几何形状和载荷条件下的应力和位移。

**分析步骤：**

首先，建立构件的几何模型，定义材料属性。然后，施加边界条件和载荷。接着，划分网格，进行有限元计算。最后，分析结果，提取关键位置的应力和位移。

**软件工具：**

ANSYS、ABAQUS、NASTRAN等是常用的有限元分析软件。这些软件可以处理线性和非线性问题，静力学和动力学问题。

## 七、组合变形的工程应用

### 7.1 压力容器设计

压力容器的简体承受内压产生的薄膜应力，同时承受自身重量引起的弯曲应力。此外，容器的接管、支座等区域存在应力集中。

**整体分析：**

简体中的薄膜应力为：

σ_θ = pR / t（环向应力）
σ_z = pR / (2t)（轴向应力）

**局部应力分析：**

在接管、人孔、支座等区域，应力可能达到薄膜应力的2-5倍，需要采用应力集中系数进行修正。设计时，应确保局部应力不超过许用应力的规定倍数。

### 7.2 转轴设计

转轴是典型的弯扭组合构件。设计时，需要根据弯矩和扭矩确定轴的直径，并考虑键槽、过渡圆角等应力集中因素的影响。

**疲劳强度校核：**

转轴在弯扭组合载荷下，可能发生疲劳破坏。设计时需要根据S-N曲线和疲劳损伤假说进行疲劳强度校核。

**安全系数：**

通常，转轴的设计安全系数取2-3，以确保足够的可靠性和使用寿命。

### 7.3 建筑结构构件

建筑结构中的柱、梁等构件通常承受组合变形。柱承受轴向压力和弯矩（来自框架的侧向力）；梁承受弯矩和剪力（有时还有扭矩）。

**稳定性考虑：**

对于细长柱，除了强度条件外，还需要进行稳定性校核，确保柱不会发生屈曲失稳。

## 八、动机心理学视角下的组合变形学习

### 8.1 组合变形学习的动机分析

组合变形是工程力学中综合性最强的章节，需要综合应用前面各章的知识。其动机结构有以下特点：

**行动动机：**

组合变形问题涉及多个知识点的综合应用，题目往往较为复杂，容易让人感到无从下手。如果缺乏系统的解题思路，"不想做"的动机容易占据上风。

**结果动机：**

组合变形的学习效果很难在短期内显现。如果学习者对结果动机过于强烈（"我必须马上会做所有题"），很容易因为遇到困难而失去信心。

**环境动机：**

学习环境和学习资源会影响组合变形的学习动机。良好的学习环境、丰富的练习题目、有效的指导，可以显著提高学习效果。

### 8.2 提高组合变形学习动机的策略

**降低行动动机的负面性：**

将组合变形问题分解为基本步骤：确定载荷类型→分解为基本变形→分别计算各分量→叠加应力或位移。严格按照步骤解题，避免跳跃思维。

**加强结果动机的画面感：**

想象自己能够熟练解决各类工程力学问题，在考试中取得好成绩，在实际工作中解决工程问题。这个具体的画面可以增强学习的动力。

**控制环境暗示：**

在学习时关闭手机通知，选择安静的学习环境。遇到困难时，不要一个人死磕，及时向老师或同学请教。

### 8.3 组合变形问题的解题策略

**明确解题思路：**

1. 将组合变形分解为基本变形的叠加
2. 确定危险截面和危险点
3. 分别计算各基本变形下的应力或位移
4. 应用强度理论或叠加原理求解
5. 进行强度校核或位移计算

**注意单位统一：**

在计算过程中，确保所有物理量的单位统一。长度用mm，应力用MPa，力用N，弯矩用N·mm。

**检查结果合理性：**

计算完成后，检查结果是否合理。例如，应力值是否在合理范围内，位移方向是否与载荷方向一致。

## 🐏的行动建议

1. **建立组合变形的分类体系**：将组合变形分为斜弯曲、偏心拉压、弯扭组合等类型，每种类型总结其特点和解题方法。

2. **练习基本变形分解**：拿到一个组合变形题目，首先识别它由哪些基本变形组成，然后分别计算。

3. **掌握强度理论的选用**：对于不同材料，选用合适的强度理论——塑性材料用第三或第四强度理论，脆性材料用第一或第二强度理论。

4. **重视单位一致性**：在计算过程中始终保持单位一致，避免因单位错误导致的结果偏差。

5. **每两周总结一次**：将组合变形的各类题型和解题方法整理成笔记，形成自己的知识体系。
