# 第十一章：振动分析——系统对激励的响应

> 振动无处不在。
> 从桥梁在风中的摆动到手机的震动模式，
> 从发动机的轰鸣到地震波的传播，
> 振动是工程世界中最普遍也最需要被理解的现象之一。
> 理解振动，就是理解工程系统如何对激励做出响应。

---

## 本章导言

振动（Vibration）是指机械系统在其平衡位置附近所作的往复运动。在工程实践中，振动有时是有害的（导致结构疲劳、噪声、设备损坏），有时是有用的（振动筛、振动压实机、手机震动提醒）。无论哪种情况，工程师都需要深入理解振动的原理和规律。

振动分析是工程力学的重要分支，涉及数学建模、微分方程求解、实验测试和信号处理等多个领域。本章将从单自由度系统出发，逐步深入到多自由度系统和连续体的振动分析，涵盖自由振动、受迫振动、阻尼效应、共振现象等核心内容，以及振动测试和控制的基本方法。

---

## 一、振动的基本概念与分类

### 1.1 什么是振动？

从物理本质上讲，振动是系统在恢复力作用下的周期性运动。当系统受到初始扰动（如被推动、被撞击）后脱离平衡位置，恢复力会将系统拉回平衡位置，但由于惯性，系统会越过平衡位置到达另一侧，然后再次被拉回——如此往复，形成振动。

**振动的三要素**：
1. **质量/惯性**：存储动能，使系统能够"越过"平衡位置
2. **刚度/弹性**：存储势能，提供恢复力将系统拉回平衡位置
3. **阻尼**：耗散能量，使振动逐渐衰减

任何具有质量和弹性的系统都可能发生振动。这意味着几乎所有的工程结构都具备振动的基本条件。

### 1.2 振动的分类

**按激励方式分类**：
- **自由振动**：系统受初始扰动后，在没有持续外部激励的情况下发生的振动。系统的振动频率由其自身属性（质量和刚度）决定，称为固有频率。
- **受迫振动**：系统在持续的外部激励作用下发生的振动。振动的频率由外部激励的频率决定，而非系统自身属性。

**按阻尼情况分类**：
- **无阻尼振动**：理想化的振动，振幅不随时间变化
- **有阻尼振动**：实际振动，振幅随时间逐渐减小
- **临界阻尼振动**：系统刚好不会产生振荡，以最快速度回到平衡位置
- **过阻尼振动**：系统缓慢回到平衡位置，不产生振荡

**按自由度分类**：
- **单自由度系统**：一个坐标即可描述系统的运动状态
- **多自由度系统**：需要多个独立坐标描述运动状态
- **连续系统**：具有无限多个自由度（如梁、板、壳等连续弹性体）

### 1.3 简谐运动

简谐运动是最基本的振动形式。系统的位移随时间按正弦或余弦规律变化。

**位移方程**：x(t) = A·sin(ωt + φ)

其中：
- A = 振幅（最大位移）
- ω = 角频率（rad/s）
- φ = 初始相位角

**速度和加速度**：
- 速度：v(t) = A·ω·cos(ωt + φ) = A·ω·sin(ωt + φ + π/2)
- 加速度：a(t) = -A·ω²·sin(ωt + φ) = A·ω²·sin(ωt + φ + π)

注意：速度领先位移 90 度相位，加速度领先位移 180 度相位。

**频率和周期**：
- 周期 T = 2π/ω
- 频率 f = 1/T = ω/2π（单位：Hz，赫兹）

例如，一根长度为 1 米的悬臂梁的自由端在受到敲击后，其固有频率可能是 10 Hz，意味着它每秒钟振动 10 次。
**简谐运动的向量表示**：
简谐运动还可以用旋转向量（相量）来表示。一个以角速度 ω 匀速旋转的向量，在垂直方向上的投影正好是简谐运动。这种表示方法在分析多个同频率振动的叠加时非常方便。两个同频率简谐运动的合成结果仍然是同频率的简谐运动，其振幅和相位由两个分量的振幅和相位差决定。当两个分量的相位差为 0 时达到最大振幅（两者同向），当相位差为 180 度时振幅最小（两者反向），当相位差为 90 度时合成振幅为两个分量的均方根值。

## 二、单自由度系统的自由振动

### 2.1 无阻尼自由振动

考虑最简单的弹簧-质量系统。一个质量为 m 的物体连接在刚度为 k 的弹簧上，在光滑水平面上运动。

**运动方程**（牛顿第二定律）：
m·x¨ + k·x = 0

这是一个二阶齐次线性常微分方程。其通解为：
x(t) = A·cos(ωn·t) + B·sin(ωn·t)

其中 ωn = √(k/m) 是系统的**无阻尼固有频率**。

**固有频率的意义**：
固有频率是系统自身的属性，取决于系统的刚度和质量。增加刚度会提高固有频率，增加质量会降低固有频率。这个简单的公式是所有振动分析的基础。

对于扭转振动，运动方程类似：
J·θ¨ + kt·θ = 0

其中 J 是转动惯量，kt 是扭转刚度。固有频率 ωn = √(kt/J)。

### 2.2 有阻尼自由振动

实际系统中总是存在阻尼。阻尼来自多种物理机制：
- 粘性阻尼：流体（空气、油液）对运动物体的阻力
- 结构阻尼：材料内部分子摩擦产生的能量耗散
- 干摩擦阻尼：接触面之间的滑动摩擦

**粘性阻尼模型**是数学上最容易处理的阻尼模型。假设阻尼力与速度成正比，阻尼系数为 c：

m·x¨ + c·x˙ + k·x = 0

引入临界阻尼系数 cc = 2√(km) 和阻尼比 ζ = c/cc：

x¨ + 2ζ·ωn·x˙ + ωn²·x = 0

**三种阻尼状态**：

**欠阻尼（ζ < 1）**：
系统产生振荡，振幅按指数规律衰减。这是工程中最常见的阻尼状态。
解的形式：x(t) = e^(-ζ·ωn·t)·[A·cos(ωd·t) + B·sin(ωd·t)]
其中 ωd = ωn·√(1-ζ²) 是**有阻尼固有频率**。

**临界阻尼（ζ = 1）**：
系统刚好不产生振荡，以最快的速度回到平衡位置。
解的形式：x(t) = (A + B·t)·e^(-ωn·t)

**过阻尼（ζ > 1）**：
系统缓慢回到平衡位置，不产生振荡。阻尼过大时，系统运动迟钝。
解的形式：x(t) = A·e^(-λ₁·t) + B·e^(-λ₂·t)

**对数衰减率**：
在欠阻尼系统中，可以通过测量相邻两个周期的振幅之比来计算阻尼比。这个比值称为对数衰减率 δ：

δ = ln(x₁/x₂) = 2πζ/√(1-ζ²)

当阻尼比很小时，可以近似为 δ ≈ 2πζ，因此 ζ ≈ δ/(2π)。

实际应用：工程师可以通过敲击一个结构并测量其振动衰减速度来估算结构的阻尼比。对于大多数钢结构，阻尼比在 0.5-2% 之间。
**阻尼对频率的影响**：
阻尼不仅使振幅衰减，还略微降低了系统的固有频率。有阻尼固有频率 ωd = ωn·√(1-ζ²)。对于阻尼比 ζ = 0.1（10%），ωd = 0.995·ωn，降低了仅 0.5%；对于 ζ = 0.5（50%），ωd = 0.866·ωn，降低了 13.4%；当 ζ 接近 1 时，ωd 趋近于零，系统不再产生振荡。工程中大多数结构的阻尼比在 0.01-0.05 之间，因此实践中通常忽略阻尼对固有频率的微小影响。

**不同材料的典型阻尼比**：
- 钢和铝合金焊接结构：0.01-0.02
- 螺栓连接的钢结构：0.03-0.07
- 钢筋混凝土结构：0.04-0.08
- 预应力混凝土结构：0.02-0.05
- 木材结构：0.05-0.12
- 橡胶隔振器：0.05-0.20

这一数据对工程实践有重要指导意义。当需要增加结构阻尼时，使用螺栓连接取代焊接、添加阻尼涂层或使用复合阻尼材料都是有效的方法。

### 2.3 能量法求固有频率

除了直接列运动方程外，还可以用能量法估算系统的固有频率。根据能量守恒原理，无阻尼自由振动的系统中，动能和势能的总和保持不变。在系统的平衡位置，势能为零而动能最大；在系统的最大位移位置，动能为零而势能最大。

瑞利法利用这一原理给出了固有频率的上限估计。假设一个合理的振型函数，计算系统的最大动能和最大势能，令两者相等，即可得到固有频率的近似值。当假设的振型恰好是真实振型时，瑞利法给出精确的固有频率；当假设的振型偏离真实振型时，瑞利法给出偏高的估计。

**瑞利法公式**：
ωn² = Umax / Tmax*

其中 Umax 是系统在最大位移时的势能，Tmax* 是系统在平衡位置时的参考动能（含ωn的平方因子）。

瑞利法对梁的横向振动特别有用，只需假设一个合理的挠曲形状，就能得到相当精确的基频估计。

### 2.4 等效系统方法

对于复杂系统，可以通过引入等效质量、等效刚度、等效阻尼的概念将其简化为单自由度系统。

**等效质量**：能量等效原则——等效质量的动能等于原系统各部分的动能之和。
**等效刚度**：变形等效原则——等效刚度产生的弹性势能等于原系统各部分弹性势能之和。
**等效阻尼**：能量耗散等效原则——等效阻尼每周期的耗散能等于原系统各阻尼元件每周期的耗散能之和。

等效系统方法在工程中应用广泛。例如，分析传动轴系时可以将其简化为一个等效的扭振系统，将各段轴和齿轮的转动惯量和扭转刚度换算到一根轴上。这种方法大大简化了计算，同时保持了足够的工程精度。
## 三、单自由度系统的受迫振动

### 3.1 简谐激励下的响应

当系统受到简谐激励 F(t) = F₀·sin(ωt) 时，运动方程为：

m·x¨ + c·x˙ + k·x = F₀·sin(ωt)

这个非齐次方程的解由两部分组成：
- **瞬态响应**：齐次解，随时间衰减（取决于阻尼）
- **稳态响应**：特解，与激励同频率但可能有相位差

稳态响应为：
xp(t) = X·sin(ωt - φ)

其中：
- 振幅 X = F₀/√[(k-mω²)² + (cω)²]
- 相位角 φ = arctan[cω/(k-mω²)]


### 3.2 放大因子与共振

在前一节给出的稳态响应表达式中，振幅和相位角都取决于激励频率与系统固有频率的关系。这个关系可以用无量纲形式表达，揭示出其普适性规律。

**频率响应函数**：
系统的频率响应函数 H(ω) 是输出（位移响应）与输入（激励力）之比，它是一个复函数，包含了幅频特性和相频特性。系统的幅频特性曲线描述了振幅随激励频率变化的关系，相频特性曲线描述了相位差随频率变化的关系。

幅频特性曲线的形状对阻尼非常敏感。当阻尼比很小时，曲线在频率比 r=1 处出现一个非常尖的峰值。随着阻尼增大，峰值降低并变宽。

**共振的危害**：


定义**频率比** r = ω/ωn 和**静位移** δst = F₀/k，则稳态振幅可以写作：

X/δst = 1/√[(1-r²)² + (2ζr)²]

这个比值称为**放大因子**（Magnification Factor）或**振幅放大率**。

**关键发现**：
1. 当 r << 1（激励频率远低于固有频率）时，X/δst ≈ 1。系统的响应接近静力响应。
2. 当 r = 1（激励频率等于固有频率）时，X/δst = 1/(2ζ)。这就是**共振条件**。
3. 当 r >> 1（激励频率远高于固有频率）时，X/δst → 0。系统对高频激励几乎没有响应。
4. 放大因子的最大值实际上出现在 r = √(1-2ζ²) 处，当 ζ 很小时非常接近 r=1。

**共振的危害**：
在共振条件下，即使很小的激励力也能引起巨大的振幅。对于无阻尼系统，振幅在理论上趋于无穷大。1940年美国塔科马海峡大桥倒塌事件就是风致共振的经典案例——风以接近桥面扭转固有频率的频率施加激励，导致振幅不断增大，最终使大桥解体。

**工程中处理共振的方法**：
1. **避开共振区**：设计时确保工作频率远离固有频率（通常要求频率比小于0.7或大于1.4）
2. **增加阻尼**：增大阻尼可以显著降低共振峰值
3. **改变系统参数**：调整刚度或质量来改变固有频率
4. **使用吸振器**：附加一个子系统的振动来抵消主系统的振动

### 3.3 不平衡激励与基础激励

**旋转不平衡**：
旋转机械（发动机、电机、风扇等）中，如果质量分布不完全对称，会产生与转速同频的离心力，激励系统产生受迫振动。这是工程中最常见的振动源之一。

旋转不平衡的激励力幅度为 F₀ = m₀·e·ω²，其中 m₀ 是不平衡质量，e 是偏心距。注意：激励力随转速的平方增大，这就是为什么高速旋转机械对平衡性要求极高的原因。

**基础激励**：
当系统的支撑结构发生振动时，系统也会受到激励。例如，安装在地震区的设备会受到地面运动的影响，在车辆中行驶的设备会受到路面不平引起的基础运动。

基础激励的运动方程比力激励更复杂，但本质相同——引起系统产生受迫振动。隔振设计就是通过选择合适的支撑刚度和阻尼来减小基础振动向敏感设备的传递。

### 3.4 任意激励下的响应

实际工程中，激励往往不是简单的简谐形式，而是任意的时变载荷。对于任意激励，可以使用**杜哈梅积分**（卷积积分）计算系统的响应。

对于线性系统，任意激励的响应等于激励函数与系统脉冲响应函数的卷积：
x(t) = ∫₀ᵗ F(τ)·h(t-τ)·dτ

其中 h(t) 是系统的单位脉冲响应函数。

对于复杂激励，数值方法（如 Runge-Kutta 方法）是更常用的求解途径。现代工程中广泛使用有限元软件进行振动响应分析。

## 四、多自由度系统的振动

### 4.1 两自由度系统

两个自由度系统的振动已经远比单自由度系统复杂。两个质量由弹簧连接，可以产生两种不同的振动模式：

**固有频率和振型**：
两自由度系统有两个固有频率（ω₁ 和 ω₂），每个固有频率对应一个**振型**（Mode Shape）——系统在特定频率下振动时的变形形态。

- **第一阶振型**（基频振型）：两个质量同向运动
- **第二阶振型**：两个质量反向运动

**振型的正交性**：
不同振型之间存在正交性关系——在一阶振型上的动能或势能不会转移到二阶振型上。这一性质是模态分析的理论基础。


### 4.2 模态叠加法的物理意义

模态叠加法的核心思想是：系统的任何复杂振动都可以分解为各阶模态振型的线性组合。每一阶模态都像一个独立的单自由度系统一样振动，各阶模态之间互不干扰（正交性）。这使复杂的多自由度问题简化为几个独立的单自由度问题。

**模态截断**：
在实际分析中，并不需要包含所有阶次的模态。通常只需要考虑对响应贡献最大的前几阶低阶模态，因为高阶模态的固有频率很高，在实际激励中很难被激发。一般取前 5-10 阶模态就可以获得足够精度的结果。这一特点大大提高了计算效率，使模态叠加法成为大型结构振动分析的标准方法。

**模态质量的物理意义**：
系统中沿某阶振型振动的"有效质量"称为该阶模态的模态质量。各阶模态的模态质量之和等于系统的总质量。模态质量可用于判断各阶模态的"重要性"——模态质量越大的模态，在系统响应中的贡献越大。


对于 N 个自由度的系统，运动方程可以写成矩阵形式：

M·x¨ + C·x˙ + K·x = F(t)

其中：
- M：质量矩阵 (N×N)
- C：阻尼矩阵 (N×N)
- K：刚度矩阵 (N×N)
- x：位移向量 (N×1)
- F(t)：激励力向量 (N×1)

**求解步骤**：
1. 求解无阻尼自由振动的特征值问题：(K - ω²M)·u = 0
2. 得到 N 个特征值 ωᵢ²（固有频率）和 N 个特征向量 uᵢ（振型）
3. 利用振型的正交性将耦合的运动方程解耦为 N 个独立的单自由度方程
4. 分别求解每个单自由度方程
5. 将各个振型的响应叠加得到系统总响应

这种方法称为**模态叠加法**（Modal Superposition Method），是大型结构振动分析的标准方法。

### 4.3 模态分析与实验

模态分析是振动工程中最重要的工具之一，它的目的是确定结构的固有频率、阻尼比和振型。

**理论模态分析**：
通过有限元模型计算结构的模态参数。工程师建立结构的有限元模型，软件自动求解特征值问题，给出各阶模态参数。

**实验模态分析**：
通过实际测量确定结构的模态参数。典型的测试过程：
1. 在结构的关键位置安装加速度传感器
2. 用力锤或激振器对结构施加已知激励
3. 测量各点的加速度响应
4. 通过频响函数分析提取模态参数

实验模态分析的结果可以用来修正和验证有限元模型，评估结构的状态，以及诊断故障。

## 五、连续系统的振动

### 5.1 弦的振动

一根张紧的弦是最简单的连续体系统。弦的横向振动由波动方程描述：

∂²y/∂t² = c²·∂²y/∂x²

其中 c = √(T/ρ) 是波速，T 是弦张力，ρ 是线密度。

**驻波模式**：
弦的振动可以看作沿弦传播的波与其在边界上的反射波叠加形成的**驻波**。驻波有固定的节点（振幅为零的点）和波腹（振幅最大的点）。弦的固有频率就是这些驻波模式的频率。

**弦的固有频率**：
fn = n·c/(2L)，n = 1, 2, 3, ...

其中 L 是弦长，n 是模态阶数。第一阶频率（n=1）称为基频，n=2 及以上称为泛音或谐波。这个公式解释了为什么吉他的弦越短（按品）、越细（线密度小）、张力越大，发出的音调越高。

### 5.2 梁的振动

梁是工程中最常见的结构元件，其横向振动的分析比弦复杂得多。

**欧拉-伯努利梁理论**：
不考虑剪切变形和转动惯量，梁的横向振动方程为：

EI·∂⁴y/∂x⁴ + ρA·∂²y/∂t² = 0

其中 E 是弹性模量，I 是截面惯性矩，ρ 是密度，A 是横截面积。

**固有频率**：
对于简支梁：ωn = (nπ/L)²·√(EI/ρA)，n = 1, 2, 3, ...

对于悬臂梁（一端固定一端自由）：ω₁ = (1.875/L)²·√(EI/ρA)，ω₂ = (4.694/L)²·√(EI/ρA)

这些公式在工程设计中广泛使用。例如，设计机器的基础时需要确保机器的工作频率远离基础梁的固有频率。

**铁木辛柯梁理论**：
对于短而粗的梁，剪切变形和转动惯量不可忽略。铁木辛柯梁理论考虑了这些效应，预测的固有频率低于欧拉-伯努利梁理论的结果，与实验结果更吻合。

### 5.3 板的振动

板的振动分析比梁更复杂，因为它有两个空间维度。

对于简支矩形板，其固有频率为：
ωmn = π²·[(m/a)² + (n/b)²]·√(D/ρh)

其中 a 和 b 是板的边长，D 是弯曲刚度，h 是板厚，m 和 n 是模态阶数。

板的振动模式比梁更加丰富，包括弯曲模式、扭转模式以及它们的组合。

## 六、振动控制与隔振

### 6.1 振动控制的基本策略

**源头控制**：
从减少振动源入手。例如：
- 旋转机械的动平衡
- 齿轮的齿形修形
- 发动机的间隔点火设计
- 路面平整度的改善

这是最根本、最有效的振动控制方法。

**传递路径控制**：
在振动传播路径上采取措施。例如：
- 使用隔振器（弹簧、橡胶垫、空气弹簧）
- 在管道中安装柔性接头
- 在结构中增加阻尼层
- 设置质量调谐吸振器

**接收端保护**：
对振动敏感的设备和人员采取保护。例如：
- 精密仪器使用主动隔振台
- 操作人员佩戴减振手套
- 在建筑中使用减振座椅


### 6.2 被动隔振设计

被动隔振是工程中最常用的隔振方法，通过安装隔振器来实现振动的衰减。

**隔振器的类型**：
- 金属弹簧：承载能力强，适用于重型设备，但自身阻尼小
- 橡胶隔振器：阻尼较大，剪切和压缩均可使用，但温度敏感
- 空气弹簧：刚度可调，隔振效果�出色，适用于精密设备
- 钢丝绳隔振器：适用于冲击和宽频带振动环境
- 软木和毛毡：简单廉价，适用于楼板隔振

**隔振器的选型原则**：
首先确定需要支撑的设备质量和静荷载分布；然后确定激励的最低频率；根据频率比大于√2的原则计算所需隔振器的固有频率；选择满足刚度要求和承载能力的隔振器型号；验证隔振器在静荷载下的变形量是否在合理范围内；最后考虑安装方式和环境因素。

**工程中常见的隔振问题**：
楼板上安装的旋转设备需要垂直方向的隔振；安装在高楼层的精密仪器不仅需要考虑垂直隔振，还需要考虑环境振动引起的低频摇晃和微振动；管道穿过墙体或楼板处需要柔性连接以减少振动的沿程传递；管道穿过墙体或楼板处需要柔性连接以减少振动的沿程传递；精密仪器的底座需要多方向的隔振系统。


隔振是通过在设备和基础之间安装弹性元件来减小振动的传递。

**力传递率**：
TR = √[1+(2ζr)²] / √[(1-r²)² + (2ζr)²]

力传递率表示传递给基础的力与激励力之比。

**隔振设计的黄金法则**：
要实现有效的隔振，激励频率与系统固有频率之比 r = ω/ωn 必须大于 √2（约 1.414）。此时力传递率小于 1，即传递给基础的力小于激励力。

**不同频率比的隔振效果**：
- r < √2：传递率 > 1，隔振系统实际上放大了振动（这是要避免的区域）
- r = √2：传递率 = 1，既不放大也不缩小
- r = 3：传递率约为 0.125，传递了 12.5% 的振动
- r = 5：传递率约为 0.04，传递了 4% 的振动

**实际设计考虑**：
1. 在满足隔振要求的前提下，隔振器的静变形不能过大
2. 需要足够的阻尼来抑制启动和停机过程中通过共振区的振幅
3. 考虑多方向的隔振需求
4. 考虑温度、湿度等环境因素对隔振器性能的影响

### 6.3 吸振器

吸振器（或称动力吸振器）是一种附加在主体结构上的弹簧-质量子系统，通过自身的振动来吸收主体结构的振动能量。

**工作原理**：
当吸振器的固有频率调谐到与主体结构的激励频率相同时，吸振器产生与主体结构大小相等、方向相反的力，使主体结构的振幅显著减小。

**应用实例**：
- 高层建筑顶部的调谐质量阻尼器（上海中心大厦顶部有重达 1000 吨的阻尼器）
- 汽车发动机的曲轴扭振减振器
- 输电线路的防舞动装置
- 桥梁上的调谐质量阻尼器

### 6.4 主动振动控制

主动振动控制通过传感器实时测量振动信号，控制器计算所需的控制力，作动器施加控制力来抵消振动。

**与被动控制的比较**：
- 被动控制：结构简单、可靠、成本低，但对低频振动效果有限
- 主动控制：可以处理宽频带的振动，适应性好，但系统复杂、成本高

**主要应用领域**：
- 精密加工设备的隔振
- 航天器上柔性结构的振动控制
- 大型望远镜的减振
- 高性能汽车的主动悬架系统

## 七、工程中的振动问题典型案例


### 7.1 旋转机械的振动问题

旋转机械是工程中最常见的振动源。汽轮机、发电机、压缩机、风机、泵、电动机等旋转设备在工作时都会产生振动。旋转机械的振动问题可以分为以下几类：

**转子不平衡**：转子质量分布不均匀，导致在旋转时产生与转速同频的离心力。这是最常见也最容易解决的问题。通过动平衡机测量和修正不平衡量，可以将振动降低到可接受的水平。动平衡分为单面平衡和双面平衡，对于较长的转子必须进行双面平衡。

**轴不对中**：相邻两根轴的轴线不在同一直线上。不对中会产生基频和两倍频的振动，并伴有较大的轴向振动。解决方法是重新对中，使用激光对中仪可以获得较高的精度。

**轴弯曲**：转子轴在制造或使用过程中发生弯曲，产生与不平衡相似的振动特征，但相位特性不同。轴弯曲的振动在各转速下都表现为与转速同频，且相位保持稳定。

**滑动轴承油膜振荡**：高速转子在滑动轴承中运行时，油膜可能产生不稳定的涡动，引起剧烈的自激振动。油膜振荡的频率约为转子一阶临界转速的一半，而不是与转速成正比。这种振动很难消除，需要通过改变轴承设计参数或调整润滑油特性来解决。

### 7.2 管道系统的振动问题

管道系统振动是工程中常见的难题，特别是在化工、电力和石油行业。管道振动的后果包括管壁疲劳开裂、法兰泄漏、支撑结构疲劳、仪表失效等。

**管道振动的主要原因**：
- 流体脉动：泵或压缩机产生的流量脉动引起管内压力波动
- 流体激振：高速流体经过弯头、阀门、变径段时产生的激振力
- 两相流：气液两相流引起的压力波动和冲击
- 机械激励：管道连接的设备振动传递到管道系统
- 水锤：阀门快速启闭产生的冲击波

**管道振动的控制措施**：
- 增加管道支撑和固定点，提高系统刚度
- 调整管路走向和支撑位置，改变固有频率
- 安装缓冲器或脉动阻尼器
- 使用柔性连接隔离设备振动
- 对流体系统进行脉动分析，优化管路设计

### 7.3 地震激励下的结构响应

地震是工程结构面临的最严峻的动态载荷。地震波通过地面运动将能量传递给建筑物、桥梁、大坝等结构，使其产生受迫振动。

**地震响应的分析方法**：
- 静力法：将地震作用简化为等效静力，适用于刚性结构
- 响应谱法：使用地震响应谱，根据结构的各阶固有频率和振型计算最大响应，然后通过模态组合得到总响应
- 时程分析法：使用实际地震加速度记录作为输入，通过数值积分获得结构完整的时程响应

**地震振动控制**：
现代抗震设计不仅依靠增加结构强度，还广泛使用各类减震技术。基础隔震技术是在建筑物底部设置隔震支座（如叠层橡胶支座），将建筑物的固有频率降低到远低于地震波主频的范围，从而有效减小地震能量向建筑物的传递。消能减震技术则在结构中安装阻尼器（粘滞阻尼器、金属屈服型阻尼器、摩擦阻尼器等），在地震时通过阻尼器的变形和能量耗散来减小主结构的响应。这些减震技术已经在实际工程中取得了良好的效果，在国内外很多重要建筑中得到了应用。
### 7.0 振动故障的诊断方法

工程振动问题的诊断通常遵循以下步骤：
第一步，观察和描述振动现象，包括振动发生的工况、振动的幅度和频率范围、受影响的结构和部位。第二步，测量振动的关键参数，包括加速度、速度和位移的幅值以及频谱。第三步，通过频谱分析识别振动的主要频率成分，并与可能的激励源频率进行对比。第四步，分析可能的振动传递路径和机理。第五步，提出并实施减振或隔振方案。第六步，验证减振措施的效果。

频谱对比是振动诊断中最常用的方法。每种激励源都有其特定的频率特征：旋转机械的不平衡产生基频振动，齿轮故障产生啮合频率及其边频带的振动，滚动轴承故障产生轴承特征频率的振动。通过将实测频谱与这些特征频率进行对比，可以快速锁定振动的来源。


### 7.1 塔科马海峡大桥倒塌

1940年11月7日，美国华盛顿州塔科马海峡大桥在每小时 65 公里的风速下发生剧烈的扭转振动，最终解体倒塌。这座桥建成仅四个月。

**事故原因分析**：
风以接近桥面某阶扭转固有频率的频率产生了涡激振动，形成了自激振动（颤振）。振幅不断增大直至结构破坏。

**工程教训**：
- 桥梁设计必须考虑气动弹性稳定性
- 风洞试验是大型桥梁设计的必要环节
- 增加了对桥梁抗风设计的理论研究和规范要求

塔科马大桥的倒塌是工程史上最有教育意义的振动事故之一，它使设计者意识到结构需要考虑气动弹性问题，而不仅仅是静态风载荷。

### 7.2 直升机"地面共振"

直升机在地面运行时，旋翼的旋转激励可能与机身和起落架系统的固有频率发生耦合，导致剧烈的自激振动，严重时可能导致直升机倾覆。

**事故原因**：
旋翼的旋转力以特定频率激励机身，而起落架提供的刚度使机身系统具有自己的固有频率。当两者匹配时，发生"地面共振"。

**工程对策**：
- 起落架系统的阻尼设计
- 旋翼系统的吸振设计
- 地面运行时避免在共振转速停留

### 7.3 飞机机翼颤振

高速飞行时，机翼的弯曲和扭转振动可能耦合形成颤振——一种发散性的自激振动。

**工程对策**：
- 在设计中确保颤振速度远高于最大使用速度（通常要求安全系数 1.2 以上）
- 机翼配重或使用特定截面形状
- 通过飞行试验验证颤振特性

## 八、非线性振动与随机振动

### 8.1 非线性振动的基本概念

前面介绍的都是线性振动理论，其核心假设是系统的刚度、质量和阻尼为常数，运动方程是线性微分方程。但实际工程中存在大量非线性因素，使系统的行为变得更复杂。

**常见的非线性因素**：
- 大变形引起的几何非线性：当结构的变形大到不可忽略其几何形状变化时
- 材料非线性：应力超过材料比例极限后，应力应变关系不再为线性
- 间隙和接触：机械结构中的间隙、松动、接触分离等
- 干摩擦：摩擦力的方向与速度有关，形成非线性的阻尼力

**非线性振动的特征**：
- 固有频率随振幅变化（振幅越大，频率可能升高或降低）
- 跳跃现象：缓慢改变激励频率时，系统振幅可能出现突跳
- 谐波响应：非线性系统可能产生激励频率的整数倍频率成分
- 次谐波响应：系统可能以激励频率的分数倍频率响应
- 内共振：不同模态之间可能发生能量交换

### 8.2 随机振动

随机振动的特点是无法用确定性函数描述，只能用概率统计的方法分析。工程中常见的随机振动来源包括：
- 路面不平对行驶车辆的激励
- 地震地面运动
- 大气湍流对飞行器的激励
- 海洋波浪对海上结构的激励

**随机振动的统计描述**：
- 均方根值：描述振动的总体强度
- 概率密度函数：描述瞬时值的分布特性
- 自相关函数：描述不同时刻振动值之间的相关性
- 功率谱密度：描述振动能量在频率域中的分布

**功率谱密度的意义**：
功率谱密度（PSD）是分析随机振动最重要的工具。它给出了振动能量在各频率上的分布情况。对结构进行随机振动分析时，将激励的PSD作为输入，利用结构的频率响应函数，就可以计算结构响应的PSD。这种分析方法广泛应用于飞机疲劳寿命评估、建筑抗震分析等领域。

### 8.3 振动疲劳

振动疲劳是指结构在循环振动载荷作用下发生的疲劳破坏。与静态疲劳不同，振动疲劳的载荷一般较小但频率很高，可能在很短的时间内就达到很高的循环次数。

**振动疲劳的特点**：
- 破坏通常出现在共振频率处
- 应力幅小但循环次数极高
- 失效没有明显的预先征兆
- 往往表现为裂纹萌生和扩展

**振动疲劳寿命预测**：
最常用的是S-N曲线法，通过材料的应力-寿命曲线和累积损伤理论（Miner线性累积损伤理论）来估算疲劳寿命。对于随机振动，则需要在频域中进行疲劳分析，利用功率谱密度和材料的疲劳特性来预测寿命。工程实践中还需要考虑安全系数和分散系数，以应对材料性能的分散性和载荷的不确定性。



### 9.1 振动测量仪器

**加速度计的工作原理**：
压电加速度计是目前应用最广泛的振动传感器。其核心元件是压电晶体，当加速度计受到振动时，内部的质量块对压电晶体施加惯性力，压电晶体产生与加速度成正比的电荷信号。电荷信号经电荷放大器转换为电压信号后，由数据采集系统记录和分析。

**加速度计的主要参数**：
- 灵敏度：输出电压与输入加速度之比，单位 mV/g
- 频率范围：加速度计能够准确测量的频率区间
- 量程：最大可测量加速度值
- 横向灵敏度：对垂直于主轴的振动的敏感程度，通常应小于 5%
- 温度范围：传感器正常工作的温度区间

**加速度计的选型原则**：
测量高频小振动时选择高灵敏度、较低固有频率的加速度计；测量低频大振动时选择大量程的加速度计；对于微型结构需要使用微型加速度计（质量小于 1 克）；高温环境需要特殊的高温加速度计。所有这些选型考虑都直接影响测量数据的准确性和可靠性。


**传感器类型**：
- **加速度计**：最常用的振动传感器，通过压电效应将加速度转换为电信号
- **速度传感器**：测量振动速度，常用于低频和超低频振动
- **位移传感器**：如电涡流传感器，非接触式测量轴和表面的振动位移
- **激光测振仪**：非接触式高精度测量，适合轻型结构和高温环境

**数据采集系统**：
现代振动测试使用数字数据采集系统，将模拟传感器信号转换为数字信号，然后用计算机进行分析。采样频率至少是最高分析频率的两倍（奈奎斯特定理），实际应用中通常取 2.56 到 4 倍。

### 9.2 频谱分析

傅里叶变换是振动信号分析的核心工具。它将时域信号（加速度随时间的变化）转换为频域信号（各频率成分的幅值）。

**频谱图**：
横轴是频率，纵轴是幅值。从频谱图上可以清晰地看到各阶固有频率对应的峰值。这是诊断机械故障最常用的方法——轴承损坏、齿轮故障、不平衡等都会在频谱图上产生特征频率的峰值。

**经典谱分析技术**：
- FFT（快速傅里叶变换）：一次性采集一段信号做频率分析
- 功率谱密度（PSD）：随机振动信号的统计特性分析
- 倒谱分析：识别频谱中的周期模式，常用于齿轮箱故障诊断

### 9.3 状态监测与故障诊断

振动状态监测是预测性维护（Predictive Maintenance）的核心技术之一。

**常见故障的振动特征**：
- **不平衡**：基频（1×转速）处出现较大的振动峰值，径向振动为主
- **不对中**：基频和2倍频（2×转速）处出现峰值，伴有轴向振动
- **轴承故障**：出现轴承特征频率（取决于轴承几何尺寸）的峰值及其边频带
- **齿轮故障**：啮合频率及其边频带，以及啮合频率的谐波
- **松动**：出现基频、2倍频及大量的谐波成分

通过定期测量和分析机械设备的振动信号，可以在设备发生严重故障之前发现早期问题，安排维修，避免非计划停机。

### 11.1 工程师在振动问题中的角色定位

在工程实践中，振动问题的分析和解决通常需要多个专业领域的工程师协作完成。机械工程师负责分析旋转机械的振动特性和诊断故障，结构工程师负责评估建筑物和桥梁的振动响应和安全性，土木工程师关注土与结构的相互作用和地震响应，而测试工程师负责振动数据的采集和分析。在大型工程项目中，设专门的振动专项负责人（或团队）已成为行业内的标准实践。跨专业协作和沟通能力对振动工程师来说变得越来越重要，因为振动问题往往涉及复杂的机电耦合、流固耦合和多场耦合现象。
### 11.1 国际和国内振动标准

工程振动问题不能仅依赖定性分析，还需要参照权威的振动标准和规范进行评估。国际上最常用的振动标准是ISO体系。

**ISO 10816系列**（机械振动评价标准）：
该标准规定了各类旋转机械的振动烈度评价方法。根据设备功率和类型，将振动分为四个等级：A级（优秀）、B级（良好）、C级（需关注）、D级（不允许）。振动烈度用振动速度的均方根值表示，单位mm/s。

**ISO 2631系列**（人体振动暴露评价）：
该标准评价人体暴露于全身振动的安全性和舒适性。标准规定了不同频率范围、不同方向的振动对健康和舒适的影响阈值，为车辆和工程机械的振动设计提供依据。

**中国振动标准体系**：
中国等效采用了很多ISO振动标准，并制定了适用于本国工业的振动标准体系：
- GB 4053.3-2009 固定式钢梯及平台安全要求
- GB 50040-1996 动力机器基础设计规范
- JB/T 8097-1999 泵的振动测量与评价方法
- GB/T 19873-2005 机器状态监测与诊断 振动状态监测

**各行业振动限值参考**：
- 一般工业机械：振动速度 v ≤ 4.5 mm/s（良好），v ≥ 11.2 mm/s（不可接受）
- 精密机床：v ≤ 0.45 mm/s
- 汽轮发电机组：轴振< 125 μm（良好），> 250 μm（报警），> 500 μm（停机）
- 建筑物振动：住宅区 v ≤ 0.1 mm/s，工业区 v ≤ 0.4 mm/s

这些标准是工程实践中判断振动严重程度的重要参考依据，实际应用时需要结合具体设备的类型、功率、使用工况等因素综合评估。



### 11.1 本章核心要点

**振动的本质与规律**：
振动是工程结构中普遍存在的物理现象。任何具有质量和弹性的系统都会在受到激励时产生振动。振动的分析需要系统的方法，从简单的单自由度模型到复杂的多自由度和连续系统模型。

**共振问题的深刻理解**：
共振是振动导致工程结构破坏的最常见原因。需要准确计算结构的固有频率，确保工作条件避免在共振频率附近运行。同时，阻尼是控制共振的强有力手段。

**数值分析与实验方法的结合**：
现代振动分析既需要理论建模和数值计算，也需要实验测量和验证。有限元分析和实验模态分析的结合，已经成为解决复杂工程振动问题的标准方法。

**振动控制的系统性思维**：
振动控制不是单一技术，而是一个系统工程。从源头上减少振动、在传递路径上隔离振动、在接收端保护敏感设备，三个层面需要综合考虑。被动控制和主动控制各有适用范围，需要根据具体情况选择最优方案。


1. **振动的本质是质量和刚度的耦合**。系统的动力学行为可以用几个关键参数描述：固有频率、阻尼比和振型。

2. **共振是振动工程中最需要关注的现象**。当激励频率接近系统固有频率时，即使很小的力也能引起很大的振动。工程设计中必须避开共振区。

3. **阻尼是控制振动的关键因素**。增加阻尼可以显著降低共振峰值，加速自由振动的衰减。

4. **模态分析是理解和解决振动问题的核心技术**。通过识���固有频率和振型，工程师可以预测结构对激励的响应，并采取针对性措施。

5. **振动控制可以从源头、传递路径和接收端三个层面入手**。隔振、吸振和主动控制是三种主要的工程手段。


### 11.2 振动工程的未来发展趋势

振动工程领域正在经历深刻的技术变革。数字化技术的应用使振动监测从定期巡检向实时在线监测转变，物联网传感器和云平台使远程诊断和大数据分析成为可能。人工智能技术在振动故障诊断中的应用也取得了显著进展，深度学习模型可以自动从振动信号中提取特征并进行故障分类，其准确性甚至超过了经验丰富的工程师。

结构健康监测（SHM）技术将振动分析从故障诊断扩展到结构寿命预测领域。通过长期监测结构的振动响应变化，可以评估结构的老化和损伤程度，预测剩余寿命，实现从被动维修到主动维护的提升。微振动控制技术在高精密制造和科学研究中变得越来越重要，纳米级定位精度对振动环境的要求已经达到了前所未有的严格程度。
### 11.2 行动建议

**对结构设计工程师**：
1. 在设计初期进行模态分析，确保结构的工作频率远离关键模态的固有频率
2. 必要时增加阻尼处理（阻尼层、阻尼合金等）
3. 对旋转机械进行严格的平衡和调校
4. 考虑环境振动对结构和设备的影响
5. 参考相关的振动规范和标准进行设计


**对设备维护工程师**：
1. 建立设备的振动基准数据（正常状态下的振动水平）
2. 制定定期的振动测量计划
3. 学习基本的频谱分析方法，能在早期发现异常
4. 建立振动报警限值和停机限值5. 积累各类故障的振动特征数据，建立故障诊断知识库


**对力学学习者和研究者**：
1. 熟练掌握单自由度系统的分析方法——这是所有振动分析的基础
2. 学习使用有限元软件进行模态分析和响应分析
3. 掌握实验模态分析的基本方法
4. 关注振动领域的新技术（主动控制、非线性振动、随机振动）5. 动手进行一些简单的振动实验（如悬臂梁的自由振动测试），将理论与实践结合起来

## 十一、总结与行动建议

### 11.1 知识体系回顾

振动分析是工程力学的核心组成部分，它建立了从基础理论到工程实践的系统桥梁。本章从单自由度系统的基本模型出发，逐步扩展到多自由度系统和连续体系统，涵盖了自由振动、受迫振动、隔振设计、模态分析和工程故障诊断等关键内容。掌握振动分析的基本方法后，工程师能够理解和分析工程中大多数常见的振动问题，从旋转机械的故障诊断到建筑物的抗震分析，从精密设备的隔振设计到管道系统的振动控制。振动工程正在向着数字化和智能化的方向快速发展，持续学习和更新知识是振动工程师的必备能力。

### 11.2 学习路径建议

对于有兴趣深入学习振动工程的读者，建议按照以下路径循序渐进：先牢固掌握单自由度系统的理论，这是所有振动分析的基础。然后学习多自由度系统的矩阵方法和模态叠加原理，掌握使用有限元软件进行模态分析的基本技能。在此基础上学习振动测试和信号分析的基本方法，将理论分析与实验验证结合起来。最后通过解决实际工程问题来积累经验。掌握这些知识后，振动问题就不再是工程中的难题，而是可以科学应对的系统性挑战。
