# 第二章：发接发战术体系

## 发球的重要性

羽毛球比赛中，**发球是唯一不受对手干扰的技术**，也是战术的起点。好的发球可以直接得分或为下一拍创造机会。

## 正手发高远球

### 技术要点

```
发球站位：T字形后半米
握拍：正手握拍
引拍：大臂带动小臂
击球：甜区偏下
 Follow-through：手腕自然下压
```

### 战术应用

| 场景 | 发球策略 | 目的 |
|------|---------|------|
| 对手后场进攻强 | 发高远球 | 消耗对手 |
| 对手体力下降 | 发高远球 | 扩大优势 |
| 比赛开局 | 发高远球 | 试探对手 |
| 领先时 | 发高远球 | 保持优势 |

## 正手发小球（短球）

### 技术要点

```
拍面：正面朝前
击球点：膝关节以下
力量：小臂+手腕
摩擦：薄切球托
落点：前发球线内
```

### 战术应用

| 场景 | 发球策略 | 目的 |
|------|---------|------|
| 对手步伐慢 | 发小球 | 调动对手 |
| 对手网前弱 | 发小球 | 制造机会 |
| 领先保持 | 发小球 | 控制节奏 |
| 对手急于进攻 | 发小球 | 破坏节奏 |

## 反手发球

### 技术要点

```
握拍：反手握拍
站位：侧身对网
引拍：肘关节先行
击球：短促有力
落点：追身或边线
```

### 战术优势

- 发球速度快
- 动作一致性高
- 难以预判
- 适合抢攻

## 接发球策略

### 基本站位

```
单打接发站位：
• 靠近前发球线
• 站在T字形略偏反手位
• 重心略前
• 球拍举起

双打接发站位：
• 站在前发球线
• 压低重心
• 举拍至腰部高度
• 随时准备推扑
```

### 接发球技术选择

| 来球 | 推荐技术 | 目的 |
|------|---------|------|
| 高远球 | 杀球/吊球 | 主动进攻 |
| 短球 | 放网/挑球 | 争夺网前 |
| 平高球 | 杀球/平抽 | 反击 |
| 平快球 | 抽球/挡网 | 相持 |

### 对手发高远球

```
应对策略：
1. 杀球——直接得分（首选）
2. 吊球——打乱步伐
3. 高远球——相持过渡
4. 点杀——落点控制
```

### 对手发小球

```
应对策略：
1. 放网——争网前
2. 挑球——控制后场
3. 推球——打追身
4. 勾对角——变化
```

## 发接发组合战术

### 发球后的跟进

```
发球后应该：
• 立刻举拍
• 观察对手回球
• 快速预判移动
• 保持进攻态势

发球后不应：
• 发完球就站着
• 等待对手回球
• 重心后仰
```

### 典型发球得分组合

**组合1：发小球+扑球**
```
发球 → 对手挑后场 → 杀球得分
```

**组合2：发高远+杀球**
```
发高远 → 对手回高远 → 杀球得分
```

**组合3：发球+吊球**
```
发球 → 对手挑球 → 吊网前得分
```

## 不同对手的发球策略

### 对手类型应对

| 对手特点 | 发球策略 |
|---------|---------|
| 后场强 | 发小球+高远 |
| 网前强 | 发高远 |
| 步伐慢 | 发小球 |
| 急躁 | 发高远+防守 |
| 体力差 | 发高远消耗 |

### 比分策略

| 比分情况 | 发球策略 |
|---------|---------|
| 领先 | 控制为主 |
| 落后 | 主动进攻 |
| 相持 | 变化为主 |
| 赛点 | 稳定发球 |
