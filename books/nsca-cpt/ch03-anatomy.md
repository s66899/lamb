# 第三章：运动解剖与肌肉系统

## 羽毛球运动解剖基础

### 羽毛球主要参与肌群

```
上肢肌群：
├── 肩带肌群：三角肌、冈上肌、冈下肌
├── 上臂肌群：肱二头肌、肱三头肌
├── 前臂肌群：屈肌、伸肌群
└── 手部肌群：握力肌群

核心肌群：
├── 腹部：腹直肌、腹内外斜肌
├── 背部：竖脊肌、背阔肌
└── 髋部：髂腰肌、臀大肌

下肢肌群：
├── 大腿：股四头肌、腘绳肌
├── 小腿：腓肠肌、比目鱼肌
└── 踝关节：踝屈伸肌群
```

## 关键肌肉功能

### 1. 肩带肌群

| 肌肉 | 功能 | 羽毛球应用 |
|------|------|-----------|
| 三角肌 | 肩外展、前屈、后伸 | 杀球、吊球、高远球 |
| 冈上肌 | 外展启动 | 挥拍启动 |
| 冈下肌 | 外旋 | 反手击球 |
| 小圆肌 | 外旋 | 挥拍加速 |

### 2. 核心肌群

| 肌肉 | 功能 | 羽毛球应用 |
|------|------|-----------|
| 腹直肌 | 屈髋、压缩腹部 | 转体发力 |
| 腹内外斜肌 | 旋转、侧屈 | 杀球转体 |
| 竖脊肌 | 伸展脊柱 | 保持姿态 |
| 髂腰肌 | 屈髋 | 启动移动 |

### 3. 下肢肌群

| 肌肉 | 功能 | 羽毛球应用 |
|------|------|-----------|
| 股四头肌 | 膝伸展 | 跳跃、启动 |
| 腘绳肌 | 膝屈曲 | 快速制动 |
| 腓肠肌 | 踝跖屈 | 踮步、跳跃 |
| 比目鱼肌 | 踝跖屈 | 维持平衡 |

## 关节活动度

### 羽毛球关键关节

```
肩关节：
• 外展：0-180°
• 内旋：0-70°
• 外旋：0-90°

肘关节：
• 屈曲：0-150°
• 伸展：0°

腕关节：
• 掌屈：0-80°
• 背伸：0-70°

髋关节：
• 屈曲：0-120°
• 外展：0-45°
• 内旋：0-35°

膝关节：
• 屈曲：0-135°
• 伸展：0°

踝关节：
• 背屈：0-20°
• 跖屈：0-50°
```

## 动力链分析

### 正手杀球动力链

```
发力顺序（从下到上）：
1. 髋关节旋转
2. 躯干旋转
3. 肩关节外展
4. 肘关节伸展
5. 腕关节屈曲

力量传递：
地面 → 腿部 → 髋部 → 躯干 → 肩 → 肘 → 腕 → 球拍
```

### 移动步伐动力链

```
启动：
• 髋关节快速屈曲
• 膝关节微屈
• 踝关节预旋

制动：
• 股四头肌离心收缩
• 腘绳肌离心收缩
• 核心稳定
```

## 常见损伤与解剖

### 1. 肩袖损伤

```
解剖位置：冈上肌、冈下肌、肩胛下肌、小圆肌

症状：
• 肩外展疼痛
• 夜间疼痛
• 力量下降

预防：
• 肩袖肌群强化
• 活动度训练
• 正确技术
```

### 2. 网球肘

```
解剖位置：肱骨外上髁（腕伸肌起点）

症状：
• 肘外侧疼痛
• 握力下降
• 挥拍疼痛

预防：
• 前臂肌群强化
• 减少过劳
• 正确握拍
```

### 3. 膝关节损伤

```
解剖位置：半月板、交叉韧带

症状：
• 膝关节肿胀
• 活动受限
• 行走疼痛

预防：
• 股四头肌强化
• 腘绳肌平衡
• 正确的跳跃落地
```

## 训练建议

### 肌肉平衡训练

```
对抗肌比例：
• 膝：股四头肌:腘绳肌 = 3:2
• 肩：外旋:内旋 = 2:3
• 髋：屈肌:伸肌 = 1:1

羽毛球特殊平衡：
• 前后肌群平衡（股四头肌与腘绳肌）
• 内外旋肌群平衡（肩袖）
• 核心稳定性训练
```

### 每周解剖训练分配

```
周一：上肢推（肩、臂）
周二：下肢（腿、踝）
周三：核心+活动度
周四：上肢拉（背、肩）
周五：下肢+爆发力
周末：休息或轻松活动
