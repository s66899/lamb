# 第五章：爆发力训练

## 爆发力定义

**爆发力 = 力量 × 速度**

羽毛球运动中几乎所有技术都需要爆发力：杀球、跳跃、启动、急停。

## 爆发力训练原则

### 训练顺序

```
1. 神经激活（神经适应期）
2. 力量基础（4-8周）
3. 爆发力转化（4-8周）
4. 专项应用（持续）
```

### 训练方法

#### 1. 奥林匹克举重

| 动作 | 主要目的 | 适用水平 |
|------|---------|---------|
| 高翻 | 全身爆发力 | 中高级 |
| 抓举 | 快速力量 | 高级 |
| 力量翻 | 基础力量 | 初学者 |

#### 2. 跳跃训练

| 动作 | 主要目的 | 羽毛球应用 |
|------|---------|-----------|
| 蹲跳 | 垂直跳跃 | 杀球高度 |
| 跳箱 | 落地缓冲 | 跳跃落地 |
| 多级跳 | 连续跳跃 | 连续跳跃 |
| 跳绳 | 脚踝力量 | 步伐 |

#### 3. 药球训练

| 动作 | 主要目的 |
|------|---------|
| 胸前传球 | 躯干旋转力量 |
| 头上抛 | 肩上发力 |
| 砸地 | 下肢爆发 |

## 爆发力训练计划

### 周计划模板

```
周一：下肢爆发（跳跃）
周三：上肢爆发（药球）
周五：全身爆发（奥林匹克举重）
```

### 训练示例

```
下肢爆发训练（周一）：

1. 激活：跳绳3分钟
2. 力量：深蹲3×5
3. 爆发：蹲跳3×6
4. 专项：跳箱3×8
5. 收尾：拉伸

重量/强度：
• 负荷：30-50%1RM
• 次数：3-6次
• 组数：3-4组
• 间歇：2-3分钟
```

## 羽毛球专项爆发力

### 杀球爆发力

```
训练动作：
• 负重蹲跳
• 药球砸地
• 挥拍速度训练

关键因素：
• 髋关节旋转速度
• 肩关节内旋速度
• 腕关节屈曲速度
```

### 启动爆发力

```
训练动作：
• 冲刺跑
• 敏捷梯
• 弹力带阻力跑

关键因素：
• 髋关节屈曲速度
• 踝关节跖屈力量
• 神经动员速度
```
