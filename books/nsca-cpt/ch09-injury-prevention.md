# 第九章：损伤预防

## 羽毛球常见损伤

### 损伤类型统计

| 损伤部位 | 占比 | 原因 |
|---------|------|------|
| 膝关节 | 30% | 跳跃、急停 |
| 肩关节 | 25% | 杀球、过劳 |
| 踝关节 | 20% | 变向、落地 |
| 肘关节 | 15% | 挥拍、发力 |
| 其他 | 10% | 碰撞、意外 |

## 损伤原因

### 内在因素

```
• 力量不平衡
• 柔韧性不足
• 关节活动度受限
• 肌肉疲劳
• 旧伤未愈
```

### 外在因素

```
• 训练量过大
• 技术错误
• 装备不当
• 场地问题
• 热身不足
```

## 预防策略

### 1. 力量平衡

```
关键肌群平衡：
• 肩袖：外旋/内旋 = 2/3
• 膝关节：股四头/腘绳 = 3/2
• 髋关节：屈/伸 = 1/1
```

### 2. 活动度训练

```
每日活动度：
• 肩关节：10分钟
• 髋关节：10分钟
• 踝关节：5分钟
```

### 3. 神经肌肉训练

```
每周2-3次：
• 平衡垫训练
• 单腿训练
• 协调性训练
```

### 4. 训练负荷管理

```
原则：
• 每周增加<10%
• 计划性休息
• 监测疲劳
```

## 常见损伤预防

### 肩袖损伤

```
预防：
• 肩袖肌群强化
• 减少过度使用
• 正确技术
• 适当休息
```

### 膝关节损伤

```
预防：
• 股四头肌强化
• 腘绳肌平衡
• 正确落地技术
• 减少跳跃
```

### 踝关节损伤

```
预防：
• 踝关节稳定性训练
• 平衡训练
• 护具使用
• 场地检查
```
