# 第四章：基础力量训练

## 力量训练基础

### 力量类型

| 力量类型 | 定义 | 羽毛球应用 |
|---------|------|-----------|
| 最大力量 | 最大收缩能力 | 杀球力度 |
| 爆发力 | 力量×速度 | 跳跃、启动 |
| 力量耐力 | 持续发力能力 | 多拍回合 |
| 快速力量 | 高速度下的力量 | 快速移动 |

## 羽毛球专项力量需求

### 上下肢力量优先级

```
上肢：
1. 肩袖肌群（旋转肌）
2. 腕屈伸肌群
3. 核心肌群

下肢：
1. 髋关节肌群
2. 膝关节肌群
3. 踝关节肌群
```

## 基础力量训练动作

### 1. 深蹲

**动作要点：**
```
• 站距与肩同宽
• 膝关节沿脚尖方向
• 髋关节先启动
• 核心保持稳定
• 重量在脚中心
```

**变化形式：**
- 颈后深蹲
- 颈前深蹲
- 箱式深蹲
- 单腿深蹲

### 2. 硬拉

**动作要点：**
```
• 握距与肩同宽
• 背部保持平直
• 髋关节铰链
• 重量沿腿上升
• 肩胛骨收紧
```

**变化形式：**
- 传统硬拉
- 罗马尼亚硬拉
- 相扑硬拉

### 3. 推举

**动作要点：**
```
• 握距略宽于肩
• 核心收紧
• 推起时肘部锁定
• 动作轨迹垂直
• 肩胛骨下沉
```

### 4. 划船

**动作要点：**
```
• 俯身约45°
• 背部保持平直
• 肘部贴紧身体
• 收缩背阔肌
• 控制离心阶段
```

## 训练计划模板

### 每周训练结构

```
周一：下肢推（深蹲类）
周三：上肢推（推举类）
周五：下肢拉/拉（硬拉/划船类）

每两周循环一次重量
```

### 训练量建议

```
初学者：
• 每周3次
• 每次3-4动作
• 每动作3组×8-12次
• 间歇60-90秒

中级：
• 每周4次
• 每次4-5动作
• 每动作3-4组×6-10次
• 间歇60-90秒
```

## 训练原则

### 渐增负荷原则

```
每周增加：
• 重量：2.5-5kg
• 或次数：1-2次
• 或组数：1组

避免：
• 每周增加>10%重量
• 动作变形
• 休息不足
```

### 动作质量原则

```
优先级：
1. 动作正确性
2. 动作完整性
3. 重量增加

标准：
• 每组最后1-2次应该力竭
• 但动作不变形
```
