# 第六章：敏捷性与灵敏训练

## 敏捷性定义

**敏捷性**是在快速变化方向中快速、准确移动的能力。羽毛球运动需要频繁的急停、急转、变向。

## 羽毛球敏捷需求

### 方向变化类型

```
羽毛球步伐方向变化：
• 前后移动：上网、后退
• 左右移动：横移
• 对角线：斜线移动
• 组合：前后左右组合
```

### 敏捷素质组成

```
反应速度：预判和启动
• 视觉反应
• 听觉反应
• 动作反应

加速能力：0-10米冲刺
• 启动速度
• 加速能力

减速能力：高速下急停
• 离心控制
• 平衡稳定

变向能力：方向转换
• 侧向移动
• 对角线变向
```

## 敏捷训练方法

### 1. 敏捷梯训练

| 动作 | 目的 | 应用 |
|------|------|------|
| 前进后腿跳 | 快速转换 | 上网步伐 |
| 侧滑步 | 横向移动 | 左右防守 |
| 交叉步 | 交叉变向 | 对角线 |
| 快速小步 | 节奏调整 | 网前 |

### 2. 锥桶训练

```
训练内容：
• Z字形跑
• 菱形跑
• 5-10-5测试
• T测试

设置：
• 间距：5-10米
• 标记清晰
• 地面平整
```

### 3. 反应训练

```
视觉反应：
• 看手势变向
• 看信号启动
• 跟随训练

听觉反应：
• 听哨音变向
• 听口令启动
• 节奏变化
```

## 训练计划

### 每周敏捷训练

```
周一：基础敏捷（梯子）
周三：方向变化（锥桶）
周五：反应训练（信号）

每次训练：
• 热身10分钟
• 训练20分钟
• 放松10分钟
```
