# 第十章：恢复策略

## 恢复的重要性

训练后恢复与训练本身同样重要。没有充分恢复，训练效果无法最大化。

## 恢复类型

### 1. 物理恢复

```
主动恢复：
• 轻度活动（慢跑、游泳）
• 拉伸
• 泡沫轴

被动恢复：
• 休息
• 睡眠
• 按摩
```

### 2. 营养恢复

```
训练后30分钟内：
• 蛋白质：20-40g
• 碳水：0.5-1g/kg

训练后2-3小时：
• 完整正餐
• 均衡营养
```

### 3. 心理恢复

```
方法：
• 冥想
• 放松训练
• 兴趣活动
• 社交
```

## 睡眠恢复

### 睡眠对运动员的重要性

```
睡眠功能：
• 激素分泌（睾酮、生长激素）
• 糖原恢复
• 肌肉修复
• 记忆巩固

建议时长：7-9小时/天
```

### 睡眠优化

```
方法：
• 固定作息时间
• 睡前避免屏幕
• 凉爽环境
• 黑暗环境
• 适量运动
```

## 主动恢复活动

### 低强度活动

```
推荐活动：
• 慢跑20-30分钟
• 游泳
• 自行车
• 瑜伽
• 拉伸

原则：
• 强度<50%最大心率
• 保持活动但不高强度
```

### 泡沫轴/按摩

```
部位：
• 股四头肌
• 腘绳肌
• 髂胫束
• 背部
• 肩部

时间：每个部位1-2分钟
```
