# 💪 NSCA-CPT 体能训练与羽毛球实战

> 科学的训练不是"练得够"，而是"练得对"。
> NSCA-CPT 体能训练体系 × 羽毛球专项实战，
> 让你从"练过的人"变成"有体系的训练者"。

---

## 📖 关于本书

本书是「九本书写作计划」的第五本，系统讲解 **NSCA-CPT（美国国家体能协会认证私人教练）** 知识体系在羽毛球运动中的实战应用。NSCA-CPT 是全球最具权威的体能训练认证之一，其知识体系涵盖运动解剖学、运动生理学、运动生物力学、营养学、训练计划设计、特殊人群训练等十大核心领域。

本书的独特之处在于：**不只是讲体能训练，而是讲如何把科学训练体系与羽毛球专项结合**。每一章都以羽毛球运动员的实际训练需求为落脚点，让你不仅"知道"知识，更能"用上"知识。

---

## 📚 如何使用这本书

**顺序阅读（推荐初学者）**：
从第一章到最后一章，循序渐进地建立完整的知识体系。

**按需查阅（推荐有基础的读者）**：
根据自己当前的训练需求，查阅对应章节。例如：
- 想了解「如何设计一周训练计划」 → 第八章
- 想了解「如何预防常见运动损伤」 → 第九章
- 想了解「运动后怎么恢复」 → 第十章

**配合训练（推荐认真实践者）**：
每章都配有"实践工具"和"思考题"，建议边读边练，把知识转化为能力。
