# 第七章：柔韧性与关节活动度

## 柔韧性定义

**柔韧性**是关节在正常范围内活动的能力。对羽毛球运动员至关重要，影响动作幅度和损伤风险。

## 羽毛球关键活动度

### 重点关节

```
优先级排序：
1. 肩关节：杀球、吊球幅度
2. 髋关节：步伐移动范围
3. 踝关节：跳跃、平衡
4. 脊柱：转体发力
5. 腕关节：灵活击球
```

## 动态拉伸

### 训练前动态拉伸

```
肩部：
• 手臂画圈（前/后）
• 肩部绕环
• 拉伸带肩绕

髋部：
• 腿部摆动（前/后/侧）
• 髋关节绕环
• 弓箭步转体

踝部：
• 踝关节绕环
• 脚尖点地走
• 脚跟点地走
```

## 静态拉伸

### 训练后静态拉伸

```
肩部拉伸：
• 胸前交叉拉伸
• 背后互握拉伸
• 肩部压拉

腿部拉伸：
• 腘绳肌拉伸
• 股四头肌拉伸
• 小腿拉伸

髋部拉伸：
• 蝴蝶拉伸
• 鸽子式拉伸
• 臀大肌拉伸
```

## 训练建议

### 每周安排

```
训练后：15-20分钟静态拉伸
每天：5-10分钟活动度训练
每周：1次专门柔韧训练
```
