# 第八章：周期化训练

## 周期化训练定义

**周期化训练**是有计划地调整训练负荷，以达到最佳竞技状态的系统方法。

## 周期化类型

### 线性周期化

```
适合：初学者、赛季目标明确

特点：
• 力量/强度逐渐增加
• 训练量逐渐减少
• 简单易行
```

### 非线性周期化

```
适合：中高级运动员

特点：
• 高低强度交替
• 训练量波动
• 更灵活
```

## 羽毛球周期安排

### 年度大周期

```
准备期（4-8周）：
• 基础体能
• 技术打磨
• 积累训练量

比赛期（12-20周）：
• 竞技状态
• 比赛为主
• 维持体能

过渡期（2-4周）：
• 轻松活动
• 身心恢复
```

### 周周期安排

```
周一：技术+力量
周二：体能+灵敏
周三：休息
周四：技术+爆发力
周五：对抗+体能
周六：比赛/模拟
周日：休息
```

### 日周期安排

```
训练日：
• 热身（15分钟）
• 主项（40-60分钟）
• 辅助（20-30分钟）
• 放松（10-15分钟）
```

## 周期阶段

### 1. 准备期

```
目标：建立基础
内容：
• 基础力量
• 有氧耐力
• 技术动作
• 关节活动度

强度：中等
量：较大
```

### 2. 基础期

```
目标：专项能力
内容：
• 力量提高
• 专项体能
• 技术强化

强度：中-高
量：中等
```

### 3. 强化期

```
目标：竞技状态
内容：
• 爆发力
• 专项对抗
• 比赛模拟

强度：高
量：中-小
```

### 4. 比赛期

```
目标：保持状态
内容：
• 比赛
• 轻技术训练
• 状态调整

强度：比赛强度
量：小
```

### 5. 过渡期

```
目标：恢复
内容：
• 轻松活动
• 拉伸
• 心理调整

强度：低
量：小
```
