## 本章导言

货币时间价值（Time Value of Money，TVM）是贯穿整个金融学体系的主线。从个人理财中的储蓄贷款计算，到公司财务中的资本预算决策，再到投资银行中的资产估值定价，几乎每一个金融问题最终都归结为"如何比较不同时点的现金流"。

本章将从零开始建立货币时间价值的完整知识框架。我们将从最基础的时间价值概念出发，逐步推进到单利复利计算、各类年金的终值现值推导、名义利率与实际利率的转换，最后落脚于净现值（NPV）与内部收益率（IRR）两大核心投资决策工具。每一节均配有具体例题，以帮助读者将抽象公式转化为可操作的解题能力。

**本章目标**：

- 深刻理解货币时间价值的经济学含义
- 掌握终值（FV）与现值（PV）在单利和复利下的计算方法
- 熟练推算普通年金、预付年金、递延年金和永续年金的终值与现值
- 理解名义利率与实际利率的区别及换算关系
- 能够运用净现值法和内部收益率法进行投资决策
- 独立完成复杂的多期现金流现值与终值计算

## 第一节：货币时间价值的基本概念

### 1.1 为什么货币有时间价值

货币时间价值是指同等金额的货币在价值上随时间而递减的现象——换句话说，今天收到的一笔钱比未来收到同等金额的钱更值钱。这个命题初看反直觉，因为它暗示"同样面额的100元，今天的和明年的不是同一种东西"。但经济学为这一命题提供了三个坚实的理论依据。

**第一，机会成本。** 今天收到的资金可以立即投入生产或借贷，从而产生回报。如果你今天收到100元并以年利率5%存入银行，一年后你将拥有105元。因此，一年后的100元在你心中的价值应等于今天的95.24元（105 ÷ 1.05）。这100元的"机会"就是放弃了一年5元的利息收入。

**第二，通货膨胀。** 物价总水平随时间上涨，货币的购买力随之下降。如果预期年通货膨胀率为2%，那么一年后100元的实际购买力只相当于今天的98.04元。持有货币的个体必须获得至少等于通货膨胀率的收益率，其财富的真实价值才不会缩水。

**第三，风险与不确定性。** 今天的100元是确定的，而承诺一年后支付的100元则存在违约风险——付款方可能破产、可能不履行承诺，或者整个经济环境可能恶化。因此，未来的现金流必须包含"风险溢价"，以补偿投资者承担的违约风险与经济不确定性。

以上三个因素共同作用，使得利率成为货币时间价值的"价格"——利率越高，说明货币的时间成本越大，未来现金流的现值越低。

### 1.2 货币时间价值的基本推论

从时间价值概念出发，可以推导出三条核心推论，它们构成了整个金融分析体系的基础：

**推论一：不同时点的现金流不可直接相加。** 这一条看似简单，但违反它却是初学者和实践中最常见的错误。一家公司在未来10年内每年产生100万元的净利润，总计1000万元——但这1000万元并不等同于当下的1000万元。正确的做法是将每年100万元折现到同一个时点（通常是当下）再做比较。

**推论二：利率越高，未来现金流的现值越低。** 当市场利率从3%上升到6%时，10年后100万元的现值会从74.4万元下降到55.8万元。这就是为什么美联储加息时，长久期资产（如长期国债、成长型科技股）往往遭遇更猛烈的价格下跌——它们远期现金流的"折价"更大了。

**推论三：时间跨度越长，复利效应越显著。** 在利率为正的前提下，期限越长，终值的增长越呈指数型加速，现值的衰减也越呈指数型加速。这一推论是资产配置中"长期投资"与"尽早开始储蓄"的理论基础。

### 1.3 时间线与符号约定

在进行货币时间价值分析时，我们将借用统一的符号体系和图示方法：
- $PV$：现值（Present Value），即当前时点（t=0）的现金流价值
- $FV_n$：终值（Future Value），即第n期期末的现金流价值
- $r$：每期利率（贴现率/折现率），通常以小数表示（如5%写作0.05）
- $n$：期数（通常以年为单位，也可为月、季度）
- $PMT$：每期等额支付额（Payment），主要用于年金的处理
- $t$：时间点，t=0为当前，t=1为第一期期末，依此类推

**时间线图示**是将上述符号可视化的标准工具。一条横轴代表时间流，从左向右递增。t=0标记为"现在"，t=1,2,...,n标记为各期期末。现金流入用向上的箭头表示（正号），现金流出用向下的箭头表示（负号）。例如，现在存入1000元、3年后取出本息和的时间线如下：

```
        PV = -1000
        ↓
t=0 ----|------|------|------ t=3
                        ↑
                   FV₃ = ?
```

这种图示方法在分析复杂的多期不等额现金流时尤为重要——绘制时间线往往是解题的第一步，也是避免混淆期数和时点的最佳方法。

## 第二节：终值与现值

### 2.1 单利的终值与现值

单利（Simple Interest）是最基础的利息计算方式：利息仅以原始本金为基数计算，每期产生的利息不加入下一期的计息基数。

**单利终值公式**：

$$FV_n = PV \times (1 + r \times n)$$

其中 $PV \times r \times n$ 就是整个期限内的累计利息总额。终值等于本金加上全部利息。

**例题2.1**：某人存入银行50000元，年利率为4%，存期5年。求：(1) 到期本利和；(2) 累计利息。

解：(1) $FV_5 = 50000 \times (1 + 0.04 \times 5) = 50000 \times 1.20 = 60000$ 元
(2) 累计利息 = $50000 \times 0.04 \times 5 = 10000$ 元

**单利现值公式**（由终值公式反解）：

$$PV = \frac{FV_n}{1 + r \times n}$$

**例题2.2**：某人3年后需要80000元支付购房首付。如果银行年利率为5%（单利），现在应存入多少？

解：$PV = \frac{80000}{1 + 0.05 \times 3} = \frac{80000}{1.15} \approx 69565.22$ 元

单利计算在商业实务中的应用相对有限，主要见于短期商业票据（如90天以内的国库券、银行承兑汇票等）的贴现计算。对于超过一年期的财务决策，几乎全部采用复利方法。因为在实际金融体系中，每期的利息都会被再投资从而产生"利滚利"效应——单利假设忽略了这个基本的资本运作逻辑。

### 2.2 复利的终值与现值

复利（Compound Interest）的含义是：每一期产生的利息自动计入下一期的本金，从而使得本金基数不断扩大。复利终值的推导过程体现了"利息再投资"的核心思想：

$$
\begin{aligned}
FV_1 &= PV \times (1 + r) \\
FV_2 &= PV \times (1 + r) \times (1 + r) = PV \times (1 + r)^2 \\
FV_3 &= PV \times (1 + r)^3 \\
&\vdots \\
FV_n &= PV \times (1 + r)^n
\end{aligned}
$$

**复利终值公式**（也是金融学中最重要的公式之一）：

$$FV_n = PV \times (1 + r)^n$$

其中 $(1 + r)^n$ 称为**复利终值系数**（Future Value Interest Factor，简记为$FVIF_{r,n}$），它衡量1元钱在n期后的价值倍数。

**例题2.3**：某人将200000元存入银行，年利率6%，按复利计息，10年后的终值是多少？

解：$FV_{10} = 200000 \times (1 + 0.06)^{10} = 200000 \times 1.7908 = 358160$ 元

**复利现值公式**（由终值公式反解）：

$$PV = \frac{FV_n}{(1 + r)^n} = FV_n \times (1 + r)^{-n}$$

其中 $\frac{1}{(1 + r)^n}$ 称为**复利现值系数**（Present Value Interest Factor，简记为$PVIF_{r,n}$），它衡量n年后1元钱在当下的等值数额。将未来现金流折算为现值的过程称为**折现**（Discounting），使用的利率r称为**折现率**或**贴现率**。

**例题2.4**：某人希望15年后拥有500000元用于子女教育。如果预期年收益率为8%（复利），现在应投资多少？

解：$PV = \frac{500000}{(1 + 0.08)^{15}} = \frac{500000}{3.1722} \approx 157619$ 元

也就是说，如果现在能拿出15.76万元，并以8%的年收益率持续投资15年，届时这笔钱将增长到50万元。

### 2.3 单利与复利的对比分析

单利与复利的差异并非简单的"殊途同归"——随着期限延长，两者的差距呈几何级扩大。我们可以通过一个具体的数值对比来直观理解这种差异。

假设本金10万元，年利率8%，分别按单利和复利计算不同持有年限下的终值：

| 年限 | 单利终值 | 复利终值 | 差额 | 复利/单利 |
|------|----------|----------|------|-----------|
| 5年  | 140,000  | 146,933  | 6,933  | 1.050 |
| 10年 | 180,000  | 215,892  | 35,892 | 1.199 |
| 20年 | 260,000  | 466,096  | 206,096| 1.793 |
| 30年 | 340,000  | 1,006,266| 666,266| 2.959 |
| 50年 | 500,000  | 4,690,161| 4,190,161| 9.380 |

上表内含着一个深刻的投资启示：在30年时间维度上，复利终值是单利终值的近3倍；在50年维度上，复利终值达到单利终值的9.38倍。复利不是简单地让钱"再滚一次"，而是让每一笔利息都成为下一轮增长的引擎——时间越长，引擎越多，增长的加速度越大。

### 2.4 72法则

在实务中，投资者经常需要快速估算：一笔钱在特定收益率下需要多久才能翻倍。**72法则**提供了一个简单但精确的近似公式：

$$翻倍年限 \approx \frac{72}{年利率(\%)}$$

例如，年收益率为6%时，资金翻倍大约需要 72 ÷ 6 = 12年；年收益率为12%时，翻倍大约需要 72 ÷ 12 = 6年。72法则的推导基础是 $\ln 2 \approx 0.693$，配合泰勒展开后近似得到，其在利率为4%至12%区间内精度相当高。

**例题2.5**：某基金年化收益率为9%，投资者投入100万元。大约多少年后这笔资金将变成400万元（即翻两番）？

解：第一次翻倍（100万→200万）需 72 ÷ 9 = 8年；第二次翻倍（200万→400万）仍需8年。所以估计共需约16年。

到第16年时的精确验证：$100 \times (1.09)^{16} = 100 \times 3.9703 = 397.03$ 万元，与400万仅差不到1%，72法则的近似效果令人满意。

### 2.5 折现率的选择

在现值计算中，折现率r的选取至关重要——不同的折现率将导致截然不同的现值结果。折现率的确定取决于以下因素：

**无风险利率（Risk-Free Rate）**：通常以国债收益率为基准，反映纯粹的时间偏好。中国金融市场中，10年期国债收益率常被用作无风险利率的参考基础。

**风险溢价（Risk Premium）**：承担额外风险所要求的补偿。权益投资的风险溢价通常高于债权投资；初创企业高于成熟企业；新兴市场高于发达市场。

**机会成本**：如果资金已有备选用途，该备选方案的最高预期收益率即为机会成本。在资本预算中，通常以公司的加权平均资本成本（WACC）作为折现率。

**通货膨胀预期**：如果使用名义现金流（未剔除通胀），则应匹配名义折现率；如果使用实际现金流（已剔除通胀），则应匹配实际折现率。名义与实际之间必须保持一致性。

## 第三节：年金

### 3.1 年金的概念与分类

**年金（Annuity）**定义为：在一定期限内，每期等额发生的系列现金流。年金有以下几个关键要素：(1) 每期金额（Payment，$PMT$）相等；(2) 相邻两期的时间间隔相等（如每年、每季、每月）；(3) 利率在期内保持不变（或可分段处理）。

年金按不同维度可划分为以下常见类型：

- 按**支付时点**：**普通年金**（期末支付）vs **预付年金**（期初支付）
- 按**起始时点**：**即期年金**（首付在t=1或t=0发生）vs **递延年金**（首付在m期后才开始）
- 按**持续期限**：**有限年金**（明确的支付期数）vs **永续年金**（无穷期）
- 按**金额变化**：**等额年金** vs **增长年金**（每期按固定增长率递增）

在金融实务中，普通年金（每期期末支付）是默认假设——银行贷款、债券利息、退休金等大多采用期末支付模式。而预付年金（每期期初支付）则常见于租赁合同、保险费等。高中教材或某些简化材料可能将"年金"等同于"普通年金"，但我们在正式分析中必须明确区分。

### 3.2 普通年金终值

普通年金的时点约定：$PMT$ 发生在每期期末，共n期，利率为r。最后一次支付发生在t=n（最后一期期末），因此最后一笔付款不生息。

普通年金终值是每笔支付在t=n时点的终值之和：

$$
\begin{aligned}
FVA_n &= PMT(1+r)^{n-1} + PMT(1+r)^{n-2} + \dots + PMT(1+r)^1 + PMT(1+r)^0 \\
&= PMT \times \frac{(1+r)^n - 1}{r}
\end{aligned}
$$

**普通年金终值公式**：

$$FVA_n = PMT \times \frac{(1+r)^n - 1}{r} = PMT \times FVIFA_{r,n}$$

其中 $\frac{(1+r)^n - 1}{r}$ 称为**年金终值系数**（$FVIFA_{r,n}$）。

**推导逻辑**：将每一笔PMT独立地复利到t=n，再对这n项等比数列求和。各笔支付在t=n的终值构成了公比为(1+r)的n项等比数列，代入等比数列求和公式即得上述表达式。

**例题3.1**：某人每年末存入银行20000元，年利率5%，连续存10年。10年后账户余额是多少？

解：$FVA_{10} = 20000 \times \frac{(1.05)^{10} - 1}{0.05} = 20000 \times \frac{1.6289 - 1}{0.05}$

$= 20000 \times \frac{0.6289}{0.05} = 20000 \times 12.578 = 251560$ 元

这个账户中的251560元包含两部分：本金20000 × 10 = 200000元，利息51560元。

**例题3.2**：某人希望在20年后退休时拥有100万元。如果年投资收益率为7%，从现在起每年末需投入多少？

解：$1000000 = PMT \times \frac{(1.07)^{20} - 1}{0.07}$

$1000000 = PMT \times \frac{3.8697 - 1}{0.07} = PMT \times \frac{2.8697}{0.07} = PMT \times 40.995$

$PMT = \frac{1000000}{40.995} \approx 24393$ 元

即每年年末只需投入约2.44万元，20年后即可拥有100万元。这体现了"积少成多"的年金储蓄力量。

### 3.3 普通年金现值

普通年金现值是每笔支付折现到t=0时的现值之和：

$$
\begin{aligned}
PVA &= \frac{PMT}{1+r} + \frac{PMT}{(1+r)^2} + \dots + \frac{PMT}{(1+r)^n} \\
&= PMT \times \frac{1 - (1+r)^{-n}}{r}
\end{aligned}
$$

**普通年金现值公式**：

$$PVA = PMT \times \frac{1 - (1+r)^{-n}}{r} = PMT \times PVIFA_{r,n}$$

其中 $\frac{1 - (1+r)^{-n}}{r}$ 称为**年金现值系数**（$PVIFA_{r,n}$）。

**推导逻辑**：将每一笔PMT独立折现到t=0，得到n项公比为 $\frac{1}{1+r}$ 的等比数列，等比数列求和即得。

**例题3.3**：某贷款总额500000元，年利率6%，分10年等额偿还（每年末还款一次）。求每年还款额。

解：$500000 = PMT \times \frac{1 - (1.06)^{-10}}{0.06}$

$500000 = PMT \times \frac{1 - 0.5584}{0.06} = PMT \times \frac{0.4416}{0.06} = PMT \times 7.3601$

$PMT = \frac{500000}{7.3601} \approx 67934$ 元

这种计算方式是商业银行等额本息贷款的标准定价方法——贷款本金等于未来各期还款额的现值之和，以贷款利率为折现率。

**例题3.4**：某人中奖可获每年末支付30000元、连续15年的年金，或一次性领取现值。市场利率为5%。一次性领取的等价金额是多少？

解：$PVA = 30000 \times \frac{1 - (1.05)^{-15}}{0.05}$

$= 30000 \times \frac{1 - 0.4810}{0.05} = 30000 \times 10.3797 \approx 311391$ 元

即选择一次性领取时，领取金额若等于31.14万元，则两种方案在经济上是等价的。如果实际一次性领取额低于此数，则分期领取更优。

### 3.4 预付年金终值与现值

预付年金（Annuity Due）要求每笔PMT发生在期初（t=0,t=1,…,t=n-1）。与普通年金的唯一区别在于——每一笔支付都因此多生息一个周期。

**预付年金终值**：

$$FVA_{\text{due}} = PMT \times \frac{(1+r)^n - 1}{r} \times (1+r) = FVA_{\text{ordinary}} \times (1+r)$$

**预付年金现值**：

$$PVA_{\text{due}} = PMT \times \frac{1 - (1+r)^{-n}}{r} \times (1+r) = PVA_{\text{ordinary}} \times (1+r)$$

简而言之：预付年金的终值和现值都是相应普通年金结果乘以(1+r)。这是因为预付年金中每笔付款都比普通年金早一个期间，因而多积累一个周期的复利效果。

**例题3.5**：某人每年初存入25000元，连续8年，年利率5%。8年末账户余额是多少？

解：$FVA_{\text{due}} = 25000 \times \frac{(1.05)^8 - 1}{0.05} \times 1.05$

$= 25000 \times \frac{1.4775 - 1}{0.05} \times 1.05 = 25000 \times 9.5491 \times 1.05$

$= 25000 \times 10.0266 \approx 250665$ 元

**例题3.6**：某设备租赁合同约定，承租方需在每年初支付租金80000元，共5年。市场利率为6%。该租赁合同现金流出总额的现值是多少（站在承租方角度）？

解：$PVA_{\text{due}} = 80000 \times \frac{1 - (1.06)^{-5}}{0.06} \times 1.06$

$= 80000 \times \frac{1 - 0.7473}{0.06} \times 1.06 = 80000 \times 4.2124 \times 1.06$

$= 80000 \times 4.4651 \approx 357208$ 元

### 3.5 递延年金

递延年金（Deferred Annuity）是指年金支付并非从t=1（或t=0）开始，而是从未来某个时点（t=m+1或t=m）开始。例如，某人可能在10年后才开始领取退休金，并连续领取20年。

递延年金的计算采用**两阶段折现法**：

- 第一步：将年金视作普通年金（或预付年金），折现到首次支付前一期的时点；
- 第二步：将上述结果再折现到t=0。

**递延年金现值公式**（以期末支付、递延m期、支付n期为例）：

$$PVA_{\text{deferred}} = PMT \times \frac{1 - (1+r)^{-n}}{r} \times (1+r)^{-m}$$

**例题3.7**：某人计划在5年后开始，每年末领取40000元，连续领取12年。折现率为6%。求该递延年金的现值。

解：第一步：将12期年金折现到t=5（首次支付的上一期期末，即第5年末）：

$PVA_5 = 40000 \times \frac{1 - (1.06)^{-12}}{0.06} = 40000 \times \frac{1 - 0.4970}{0.06}$

$= 40000 \times 8.3838 = 335352$ 元

第二步：将335352元折现到t=0：

$PVA_0 = 335352 \times (1.06)^{-5} = 335352 \times 0.7473 \approx 250622$ 元

验证：若现在存入25.06万元并按6%复利增长，5年后可得到33.54万元；再将这33.54万元按6%分12年等额支取，每年正好可取4万元。完美吻合。

### 3.6 永续年金

永续年金（Perpetuity）是指支付期数为无穷大的年金。现实中不存在真正意义上的"永续"，但英国政府的"永续公债"（Consols）以及某些优先股（支付固定股利且永不赎回）极为接近这一理论模型。

永续年金现值公式由普通年金现值公式取 $n \to \infty$ 时的极限得到：

$$PVA_{\text{perpetuity}} = \lim_{n \to \infty} PMT \times \frac{1 - (1+r)^{-n}}{r} = \frac{PMT}{r}$$

当 $n \to \infty$ 时，$(1+r)^{-n} \to 0$，因此年金现值系数退化为 $1/r$。

**例题3.8**：某优先股承诺每年末支付固定股息8元/股，市场折现率为5%。该优先股的理论价值是多少？

解：$P = \frac{8}{0.05} = 160$ 元/股

**永续增长年金（Growing Perpetuity）** 更进一步，允许每期支付额按固定增长率g递增（g < r）。这一模型在股票估值中极为重要——高登增长模型（Gordon Growth Model）正是基于永续增长年金的原理：

$$PVA_{\text{growing perpetuity}} = \frac{PMT}{r - g}$$

其中PMT为第一期末的支付金额（t=1的现金流），后续各期支付为 $PMT(1+g)^{k-1}$。

**例题3.9**：某公司预计明年末每股派息2元，此后股息将以每年3%的固定速度永续增长。投资者要求的回报率为10%。该股票的当前内在价值是多少？

解：$P = \frac{2}{0.10 - 0.03} = \frac{2}{0.07} \approx 28.57$ 元/股

这是股利折现模型（DDM）中最基础的版本，揭示了股票估值的核心逻辑：每股价值等于未来所有股利的现值之和。如果这家公司的增长前景改善，g从3%提升到4%，则股价将从28.57元跃升至33.33元——增长预期变化1个百分点，估值变动超过16%，这解释了为什么市场对上市公司增长率的变化反应如此剧烈。

### 3.7 增长年金（有限期）

在有限期数的情况下，增长年金（Growing Annuity）的公式更为复杂。假设第一期末支付为C，此后每期按固定增长率g递增，共支付n期，折现率为r：

$$PVA_{\text{growing}} = \frac{C}{r - g} \times \left[1 - \left(\frac{1+g}{1+r}\right)^n\right], \quad r \neq g$$

当 $r = g$ 时，$PVA = n \times \frac{C}{1+r}$。

**例题3.10**：某投资方案预计第一年末产生现金流50000元，此后每年增长4%，共持续10年。折现率为9%。求该方案现金流的现值。

解：$PVA = \frac{50000}{0.09 - 0.04} \times \left[1 - \left(\frac{1.04}{1.09}\right)^{10}\right]$

先计算 $\frac{1.04}{1.09} \approx 0.95413$，然后 $(0.95413)^{10} \approx 0.6246$

$PVA = 1000000 \times (1 - 0.6246) = 1000000 \times 0.3754 = 375400$ 元

## 第四节：名义利率与实际利率

### 4.1 名义利率

名义利率（Nominal Interest Rate）是指银行挂牌利率或合同明确约定的利率，不包含通货膨胀调整，也不考虑复利频率的影响。中国银行的一年期定期存款挂牌利率（如1.5%）、商业银行公布的贷款利率（如LPR+点差），本质上都是名义利率。

名义利率是金融市场中最基础的价格信号，但它并不反映资金的"真实报酬率"——如果通货膨胀率高达3%，一年期存款利率仅有1.5%，那么储户的真实报酬是每年承担约1.5%的实际购买力损失。

### 4.2 实际利率与费雪方程

实际利率（Real Interest Rate）是剔除了通货膨胀影响后的"实际购买力利率"，由经济学家欧文·费雪（Irving Fisher）提出并精确表述。其精确形式为：

$$1 + r_{\text{nominal}} = (1 + r_{\text{real}}) \times (1 + i)$$

其中 $r_{\text{nominal}}$ 为名义利率，$r_{\text{real}}$ 为实际利率，$i$ 为预期通货膨胀率。这一完整形式被称为**费雪方程**。

在实际应用中，当利率和通胀率都不太高时（例如均低于10%），可以使用近似形式：

$$r_{\text{real}} \approx r_{\text{nominal}} - i$$

**例题4.1**：某银行一年期存款名义利率为3.5%，预期年通货膨胀率为2%。实际利率是多少？

解：精确计算：$1 + r_{\text{real}} = \frac{1 + 0.035}{1 + 0.02} = \frac{1.035}{1.02} \approx 1.0147$

$r_{\text{real}} \approx 1.47\%$

近似计算：$r_{\text{real}} \approx 3.5\% - 2\% = 1.5\%$

在低通胀环境下，近似值与精确值仅差0.03个百分点，精度略可接受；但在高通胀条件下（如年通胀20%），近似值的偏差将变得显著，必须使用精确公式。

**例题4.2**：某企业借款名义利率为8%，预期通胀率为5%。该笔借款的实际成本（实际利率）是多少？

解：$r_{\text{real}} = \frac{1 + 0.08}{1 + 0.05} - 1 = \frac{1.08}{1.05} - 1 \approx 0.02857 = 2.86\%$

企业实际承担的借款成本远低于名义利率，因为在通胀环境下，企业用"贬值后的货币"偿还债务——这也是"通货膨胀对债务人有利"这一说法的数理根源。

### 4.3 有效年利率与复利频率

银行产品通常标示一个"年利率"（如12%），但利息的实际计算频率可能为年、半年、季度、月甚至每日。不同的复利频率会带来不同的实际年化收益。**有效年利率**（Effective Annual Rate，EAR）正是为统一比较不同复利频率的产品而设立的标准：

$$EAR = \left(1 + \frac{r_{\text{nom}}}{m}\right)^m - 1$$

其中 $r_{\text{nom}}$ 为名义年利率（APR，Annual Percentage Rate），$m$ 为一年内复利的次数。

**例题4.3**：某贷款名义年利率为12%，分别按下述频率复利，计算有效年利率：

(1) 每年复利一次（m=1）：$EAR = (1 + 0.12)^1 - 1 = 12.00\%$

(2) 每半年复利一次（m=2）：$EAR = (1 + 0.06)^2 - 1 = 1.1236 - 1 = 12.36\%$

(3) 每季度复利一次（m=4）：$EAR = (1 + 0.03)^4 - 1 = 1.1255 - 1 = 12.55\%$

(4) 每月复利一次（m=12）：$EAR = (1 + 0.01)^{12} - 1 = 1.1268 - 1 = 12.68\%$

(5) 每日复利一次（m=365）：$EAR = \left(1 + \frac{0.12}{365}\right)^{365} - 1 \approx 12.75\%$

关键观察：同样的名义年利率12%，复利频率越高，有效年利率越高。你的贷款合同上如果只写了"年利率12%"而实际按月计息，你实际承担的成本是12.68%而非12%。这种差异在信用卡和消费贷款中尤为常见，是金融机构重要的隐形成本来源。

### 4.4 连续复利

当复利频率趋近于无穷大时（即 $m \to \infty$），我们得到**连续复利**（Continuous Compound Interest）：

$$
\lim_{m \to \infty} \left(1 + \frac{r}{m}\right)^m = e^r
$$

因此，连续复利下的终值公式为：

$$FV_n = PV \times e^{r \times n}$$

连续复利下的有效年利率为：

$$EAR = e^r - 1$$

**例题4.4**：名义年利率10%，连续复利。求：(1) 有效年利率；(2) 10000元本金3年后的终值。

解：(1) $EAR = e^{0.10} - 1 \approx 1.10517 - 1 = 10.517\%$
(2) $FV_3 = 10000 \times e^{0.10 \times 3} = 10000 \times e^{0.30} \approx 10000 \times 1.3499 = 13499$ 元

连续复利虽然在现实银行产品中并不存在（没有银行能做到"每一个瞬间都在复利"），但它在衍生品定价（如布莱克-斯科尔斯期权定价模型）和固定收益证券理论分析中是不可或缺的数学工具。许多复杂金融模型中的利率都以连续复利形式表示，因为它拥有优美的数学性质——便于进行微积分运算和随机过程推导。

## 第五节：NPV与IRR——投资决策的量化工具

### 5.1 净现值法（NPV）

净现值（Net Present Value，NPV）是资本预算中最核心的决策准则。其定义为：项目全部预期现金流的现值之和减去初始投资额。

$$NPV = \sum_{t=1}^{n} \frac{CF_t}{(1 + r)^t} - I_0$$

有时也将初始投资$I_0$写成t=0时刻的负现金流$CF_0$，则NPV简化为所有时点（含t=0）现金流的折现值之和：

$$NPV = \sum_{t=0}^{n} \frac{CF_t}{(1 + r)^t}$$

**决策准则**：
- 若 $NPV > 0$，接受项目（项目增加了企业价值）
- 若 $NPV = 0$，项目刚好覆盖资本成本，接受与否无差异
- 若 $NPV < 0$，拒绝项目（项目会损毁企业价值）

NPV法的理论基础在于：企业存在的根本目的是为股东创造价值。NPV > 0意味着项目的回报超过了股东资金的机会成本（即折现率r），因而项目带来了股东财富的真实增加。多个独立项目选择时，只要NPV为正均可接受；多个互斥项目选择时，应选择NPV最大的那个。

**例题5.1**：某投资项目初始投资300万元，预计未来5年的净现金流分别为80万、90万、100万、110万、120万元，折现率为10%。求该项目的NPV。

解：
$$NPV = -300 + \frac{80}{1.1} + \frac{90}{1.1^2} + \frac{100}{1.1^3} + \frac{110}{1.1^4} + \frac{120}{1.1^5}$$

分别计算各期折现值：

| 年份t | 现金流CF | 折现因子(1.1)^{-t} | 现值 |
|-------|----------|---------------------|------|
| 0     | -300     | 1.0000              | -300.00 |
| 1     | 80       | 0.9091              | 72.73 |
| 2     | 90       | 0.8264              | 74.38 |
| 3     | 100      | 0.7513              | 75.13 |
| 4     | 110      | 0.6830              | 75.13 |
| 5     | 120      | 0.6209              | 74.51 |

$NPV = -300 + 72.73 + 74.38 + 75.13 + 75.13 + 74.51 = 71.88$ 万元

NPV为71.88万元 > 0，因此应接受该项目。该项目在收回全部投资和覆盖资本成本后，还额外创造了约71.88万元的价值增量。

**例题5.2**：某公司需在A、B两个互斥项目中择一。A项目初始投资500万元，未来5年每年末产生160万元净现金流；B项目初始投资800万元，未来5年每年末产生260万元净现金流。折现率均为12%。应选择哪个项目？

解：

A项目：$NPV_A = -500 + 160 \times \frac{1 - (1.12)^{-5}}{0.12}$

$= -500 + 160 \times \frac{1 - 0.5674}{0.12} = -500 + 160 \times 3.6048$

$= -500 + 576.77 = 76.77$ 万元

B项目：$NPV_B = -800 + 260 \times 3.6048 = -800 + 937.25 = 137.25$ 万元

B项目的NPV更大（137.25万 > 76.77万），应选择B项目。

### 5.2 内部收益率法（IRR）

内部收益率（Internal Rate of Return，IRR）定义为使项目NPV恰好等于零的折现率。从数学上说，IRR是下述方程的解：

$$\sum_{t=0}^{n} \frac{CF_t}{(1 + IRR)^t} = 0$$

**决策准则**：
- 若 $IRR > r$（资本成本），接受项目
- 若 $IRR < r$，拒绝项目
- 若 $IRR = r$，项目刚好覆盖资本成本

IRR反映了项目本身的内在报酬率——这个报酬率不是外部给定的，而是由项目自身的现金流结构内生决定的。因此，IRR排除了资本市场利率和公司资本成本的影响，使不同规模、不同期限的项目能够在一个统一的维度上进行比较。

**例题5.3**：某项目初始投资200万元，一年后产生240万元净现金流。求IRR。

解：$-200 + \frac{240}{1+IRR} = 0 \quad \Rightarrow \quad 1+IRR = \frac{240}{200} = 1.2 \quad \Rightarrow \quad IRR = 20\%$

如果资本成本低于20%，就可以接受该项目（比如资本成本r=15%，则IRR=20% > 15%，接受）。这个例子虽然简单到只需一步推导，但它揭示了IRR的本质：项目的IRR就是未来所有现金流恰好覆盖初始投资时所对应的回报率。

**例题5.4**：某项目初始投资1000万元，未来3年每年末产生净现金流420万元。求该项目IRR（精确到两位小数），并判断当资本成本为12%时是否接受。

解：需解方程 $-1000 + \frac{420}{1+k} + \frac{420}{(1+k)^2} + \frac{420}{(1+k)^3} = 0$

这相当于 $1000 = 420 \times \frac{1 - (1+k)^{-3}}{k}$

由于没有简单的解析解，需要用试算法（或用财务计算器/Excel的IRR函数）：

试k=12%：$PVIFA_{12\%,3} = \frac{1 - (1.12)^{-3}}{0.12} = 2.4018$，$420 \times 2.4018 = 1008.76$，NPV = 8.76 > 0

试k=13%：$PVIFA_{13\%,3} = \frac{1 - (1.13)^{-3}}{0.13} = \frac{1 - 0.6931}{0.13} = 2.3612$，$420 \times 2.3612 = 991.70$，NPV = -8.30 < 0

应用线性内插法：

$$IRR \approx 12\% + \frac{8.76}{8.76 + 8.30} \times (13\% - 12\%) \approx 12\% + \frac{8.76}{17.06} \times 1\% \approx 12.51\%$$

$IRR \approx 12.51\% > 12\%$，因此应接受该项目。

### 5.3 NPV与IRR的深层比较

NPV与IRR虽然在多数常规项目中给出相同的接受/拒绝结论，但二者在互斥项目选择中存在冲突的可能，理解这些冲突的原因是每位财务决策者必备的修养。

**冲突一：项目规模差异。** 当两个互斥项目的初始投资规模相差悬殊时，IRR可能倾向于选择回报率高但规模小、绝对价值增量较小的项目，而NPV则选择规模大、绝对价值增量大的项目。例如，将1元钱投资并赚取1000%的回报（赚10元），其IRR远高于将1000万元投资赚取20%的回报（赚200万元），但显然后者的价值创造更可观。此时应以NPV为准——股东最关心的是财富的绝对增长量，而非百分比。

**冲突二：现金流时点分布差异。** 当折现率较低时，远期现金流折现幅度较小，远期现金流充裕的项目更具吸引力；当折现率较高时则相反。这意味着IRR法（使用单一内部参数k）无法完整反映在不同资本成本下两个项目相对优劣的变化。这一问题通常通过NPV曲线图直观展示——将两个项目的NPV分别画成折现率r的函数，曲线交点对应的折现率即为两项目无差异的临界点。

**核心结论**：在所有常规条件下，NPV法在理论上更为严谨且总是与股东利益最大化一致。实务中，大多数企业将二者并用——以NPV作为第一决策准则，以IRR作为辅助参考指标，同时关注项目的回收期（Payback Period）以评估流动性风险。

### 5.4 投资回收期

投资回收期（Payback Period）是从项目开始到累计净现金流首次转正所经历的年限。其计算方法简单：将每年净现金流逐年累加，直至累计值达到或超过初始投资额。

**例题5.5**：某项目初始投资400万元，未来各年净现金流如下：第一年100万元，第二年150万元，第三年180万元，第四年200万元。求投资回收期。

解：累计净现金流：
- 第一年末累计 = -400 + 100 = -300 万元
- 第二年末累计 = -300 + 150 = -150 万元
- 第三年末累计 = -150 + 180 = +30 万元

第三年内，前 $\frac{150}{180} = 0.83$ 年即可收回剩余投资，因此回收期 = 2 + 0.83 = 2.83年。

回收期法的优点是直观易懂、强调流动性——回收期越短，项目面临的未来不确定性越小。但其缺陷也很明显：它完全忽略了回收期之后的现金流，也不考虑货币时间价值。因此实务中常使用**折现回收期**（Discounted Payback Period）加以修正——将未来各期现金流先折现再累加，计算累计折现现金流转正的时点。

## 第六节：综合例题与解答

### 6.1 终值现值综合题

**例题6.1**：某人今年25岁，计划在60岁退休时拥有200万元退休金。现有银行存款100000元，预期未来35年平均年收益率为6%。同时，他计划从今年起每年末定额储蓄一笔钱。求：(1) 现有10万元到60岁时的终值；(2) 为达到200万目标，每年末需储蓄多少？

解：(1) 现有10万元35年后的终值：$FV_{35} = 100000 \times (1.06)^{35} \approx 100000 \times 7.6861 = 768610$ 元

(2) 资金缺口 = 2000000 - 768610 = 1231390 元

需用年金终值公式解决：$1231390 = PMT \times \frac{(1.06)^{35} - 1}{0.06}$

$1231390 = PMT \times \frac{7.6861 - 1}{0.06} = PMT \times \frac{6.6861}{0.06} = PMT \times 111.435$

$PMT = \frac{1231390}{111.435} \approx 11050$ 元

即从现在起每年末储蓄约11050元，配合现有10万元本金，即可在60岁时拥有200万元。这个计算清楚地展示了"早开始"的力量——如果等到35岁才开始储蓄，剩下的25年每年需储蓄额将大幅上升，因为既少了10年的复利积累时间，现有10万元本金也少了10年的增值机会。

### 6.2 年金综合题

**例题6.2**：某企业向银行借款800万元，年利率8%，分8年等额还清。求：(1) 每年还款额；(2) 贷款期间的累计付息总额。

解：(1) $8000000 = PMT \times \frac{1 - (1.08)^{-8}}{0.08} = PMT \times \frac{1 - 0.5403}{0.08}$

$= PMT \times \frac{0.4597}{0.08} = PMT \times 5.7466$

$PMT = \frac{8000000}{5.7466} \approx 1392131$ 元

(2) 8年总还款 = $1392131 \times 8 = 11137048$ 元
累计付息 = $11137048 - 8000000 = 3137048$ 元

### 6.3 递延永续综合题

**例题6.3**：某慈善基金会接受一笔捐赠2000万元，计划将其存入银行（年利率5%），从第4年末开始每年末发放固定金额的奖学金，永续发放。求：(1) 每年可发放多少金额；(2) 如果奖学金从第1年末就开始发放，金额是多少？

解：(1) 递延永续年金：$20000000 = \frac{A}{0.05} \times (1.05)^{-3}$

先求永续年金在t=3时的现值：$P_3 = \frac{A}{0.05}$

再折现到t=0：$20000000 = \frac{A}{0.05} \times (1.05)^{-3} = \frac{A}{0.05} \times 0.8638$

$20000000 = A \times 17.276 \quad \Rightarrow \quad A = \frac{20000000}{17.276} \approx 1157700$ 元

即每年可发放约115.77万元奖学金。

(2) 如果从第一年末就开始发放（即非递延永续年金的普通情形）：

$20000000 = \frac{A}{0.05} \quad \Rightarrow \quad A = 20000000 \times 0.05 = 1000000$ 元

即每年100万元。递延三年的差异（115.77万 vs 100万）反映了2000万元本金在前三年的利息积累效果——本金以5%复利增长3年后达到约2315万元，其中每年可支取的5%约为115.77万元。

### 6.4 NPV与IRR综合题

**例题6.4**：某制造企业拟购置一台新设备，有关数据如下：
- 设备购置总价：1200万元（t=0时一次性支出）
- 预计使用年限：6年
- 预计每年增加的税后净现金流：280万元（每年末）
- 6年末设备残值：100万元（变卖净收入）
- 公司资本成本（折现率）：10%

要求：(1) 计算该项目的NPV并做决策；(2) 计算该项目的IRR（近似值）并做决策。

解：(1) NPV计算：

$NPV = -1200 + \frac{280}{1.1} + \frac{280}{1.1^2} + \dots + \frac{280}{1.1^6} + \frac{100}{1.1^6}$

经营现金流部分（6年期年金）：$280 \times \frac{1 - (1.1)^{-6}}{0.1} = 280 \times 4.3553 = 1219.48$ 万元

残值部分：$\frac{100}{1.1^6} = 100 \times 0.5645 = 56.45$ 万元

$NPV = -1200 + 1219.48 + 56.45 = 75.93$ 万元

NPV = 75.93万元 > 0，应购置该设备。

(2) IRR试算：

试k=12%：经营现金流的现值系数 = $\frac{1 - (1.12)^{-6}}{0.12} = \frac{1 - 0.5066}{0.12} = 4.1114$

$NPV = -1200 + 280 \times 4.1114 + 100 \times 0.5066 = -1200 + 1151.19 + 50.66 = 1.85$ 万元（略大于0）

试k=12.5%：$(1.125)^{-6} = 0.4936$，系数 = $\frac{1 - 0.4936}{0.125} = 4.0512$

$NPV = -1200 + 280 \times 4.0512 + 100 \times 0.4936 = -1200 + 1134.34 + 49.36 = -16.30$ 万元（略小于0）

线性内插：$IRR \approx 12\% + \frac{1.85}{1.85 + 16.30} \times 0.5\% \approx 12\% + 0.05\% = 12.05\%$

IRR ≈ 12.05% > 10%（资本成本），应接受该项目，与NPV结论一致。

## 第七节：货币时间价值在金融实务中的应用

### 7.1 债券定价

债券是最直接应用货币时间价值理论的金融工具。一张债券等价于一组未来现金流——各期利息（票息）加上到期面值——的当前折现价值：

$$\text{债券价格} = \sum_{t=1}^{n} \frac{C}{(1+y)^t} + \frac{F}{(1+y)^n}$$

其中C为每期票息，F为面值，y为到期收益率（YTM），n为剩余期数。

如果市场利率上升（即折现率y上升），债券价格下跌；市场利率下降，债券价格上涨。这就是债券投资的"利率风险"——它本质上是货币时间价值原理在固定收益市场中的直接体现。

### 7.2 贷款偿付分析

房贷、车贷、消费贷等几乎所有个人贷款的定价，都是年金现值公式的倒推：银行以贷款总额为已知的PV，以贷款利率为r，求每期等额偿付额PMT。理解这一点后，你可以自行计算提前还贷是否划算、不同利率方案的实际利息差异，以及等额本金和等额本息两种还款方式的本质区别。

### 7.3 退休规划

退休规划本质上是"如何将当期的部分收入转为未来一个确定的消费现金流"的问题。这将年金终值公式（储蓄阶段）和年金现值公式（领取阶段）连在一起，形成一条完整的时间价值链条。财务规划师为客户设计的退休方案，其计算基础完全由本章所覆盖的公式和原理构成。

### 7.4 保险精算的底层逻辑

寿险、年金险等保险产品的定价也高度依赖货币时间价值。精算师首先估算出未来预期赔付的金额和时间分布，然后以预定利率（保险产品的隐含贴现率）将这些赔付折现为当期现值，再加上运营成本和利润边际，最终得出应向投保人收取的保费。

## 本章小结

货币时间价值是金融学的语言基础。不会说这门语言，就无法进入金融学的深层。本章从最基础的概念出发，逐步建立了终值、现值、年金、利率、NPV与IRR这六大工具体系，每一个工具都配有具体例题以强化理解。

**核心公式总结**：

| 概念 | 公式 | 适用场景 |
|------|------|----------|
| 单利终值 | $FV = PV(1 + rn)$ | 短期借款、商业票据 |
| 复利终值 | $FV = PV(1 + r)^n$ | 长期投资、储蓄 |
| 复利现值 | $PV = FV(1 + r)^{-n}$ | 所有折现计算 |
| 普通年金终值 | $FVA = PMT \times \frac{(1+r)^n - 1}{r}$ | 退休储蓄、偿债基金 |
| 普通年金现值 | $PVA = PMT \times \frac{1 - (1+r)^{-n}}{r}$ | 贷款定价、债券定价 |
| 预付年金终值 | $FVA_{\text{due}} = FVA \times (1+r)$ | 租赁、保险费储蓄 |
| 预付年金现值 | $PVA_{\text{due}} = PVA \times (1+r)$ | 期初支付合同现值 |
| 永续年金现值 | $PVA = PMT / r$ | 优先股、永续公债 |
| 永续增长年金 | $PVA = PMT / (r-g)$ | 股票股利折现 |
| 费雪方程 | $1+r_{\text{nom}} = (1+r_{\text{real}})(1+i)$ | 通胀调整 |
| 有效年利率 | $EAR = (1 + r_{\text{nom}}/m)^m - 1$ | 不同复利频率比较 |
| 净现值 | $NPV = \sum CF_t (1+r)^{-t} + I_0$ | 资本预算决策 |
| 内部收益率 | $\sum CF_t (1+IRR)^{-t} + I_0 = 0$ | 项目回报率评估 |

**学习建议**：货币时间价值的掌握，不能停留在"记住这几个公式"的层面。真正有效的学习路径是：(1) 理解每个公式推导背后的经济直觉；(2) 用财务计算器或Excel反复练习，直到看到数据能自动在脑中构建时间线；(3) 将本章公式与后续章节的债券定价、股票估值、资本预算等内容联系起来，形成完整而连贯的金融知识体系。
