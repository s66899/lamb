# 第四章 八卦与六十四卦

## 4.1 八卦的本质

八卦用最简单的符号（阳爻阴爻）描述万物变化。每一卦由三个爻组成。

```html
爻的两种：
━━━━━ 阳爻（—） 代表：天 · 刚健 · 主动 · 光明 · 男
━ ━ ━ 阴爻（--） 代表：地 · 柔顺 · 被动 · 阴暗 · 女
```

## 4.3 先天八卦（伏羲八卦）方位图

```
               ☰ 乾 = 天
                 南
                 ↑
        ☱ 兑     │     ☲ 离
        东南     │     西南
                 │
    ☲ 离 ◄──────┼──────► 坎 ☵
      东        │        西
                 │
        ☳ 震     │     ☶ 艮
        东北     │     西北
                 ↓
                 北
               ☷ 坤 = 地
```

**卦序**：乾1·兑2·离3·震4·巽5·坎6·艮7·坤8

**数字规律**：1+8=9·2+7=9·3+6=9·4+5=9 → 每对相加均为9

乾（纯阳） ⇄ 坤（纯阴）   ·  离（外阳内阴） ⇄ 坎（外阴内阳）
震（阳在下） ⇄ 巽（阴在下） ·  艮（阳在上） ⇄ 兑（阴在上）

## 4.6 六十四卦生成

八卦两两相叠 → 六十四卦（六爻卦）

```html
生成过程：
                   ┌─── 乾（天）
                   │   ┌─── 夬
          ┌─── 乾 ─┤   ├─── 大有
          │       └───┤   ├─── 大壮
          │           └───┘   ...
          │
    ┌─────┤
    │     │           ┌─── 履
    │     └─── 兑 ────┤   ├─── 兑
    │                 └───┘   ...
    │
太极 ──┤     ┌─── 离 ────┐
       │     │            ├─── 离
       │     ├─── 震 ────┤
       │     │            └─── 噬嗑
       ├─────┤
       │     ├─── 巽 ────┐
       │     │            └─── 巽
       │     ├─── 坎 ────┤
       │     │            ├─── 坎
       │     ├─── 艮 ────┘
       │     ├─── 坤 ────┐
       │     │            └─── 坤
       └─────┘
```

### 六爻分析框架

每一卦六爻从下往上 → 事物发展的六个阶段：

```html
上爻 ━━━  ─── 事物终结·盛极而衰     （亢龙有悔）
五爻 ━━━  ─── 事物鼎盛·力量最强     （飞龙在天·天子位）
四爻 ━━━  ─── 深入阶段·面临选择     （或跃在渊）
三爻 ━━━  ─── 关键阶段·需谨慎       （终日乾乾）
二爻 ━━━  ─── 开始显现·力量增强     （见龙在田）
初爻 ━━━  ─── 初始阶段·力量微弱     （潜龙勿用）
```

### 关键五卦

```html
泰 卦（地天泰）
上卦 ☷ 坤（地）→ 地气下降
下卦 ☰ 乾（天）→ 天气上升
↓ 天地交合 → 通泰

否 卦（天地否）
上卦 ☰ 乾（天）→ 天气上升
下卦 ☷ 坤（地）→ 地气下降
↓ 两不相交 → 闭塞

既济（水火既济）
上卦 ☵ 坎（水）→ 水往下
下卦 ☲ 离（火）→ 火往上
↓ 看似安定 → 隐含分离

未济（火水未济）
上卦 ☲ 离（火）→ 火往上
下卦 ☵ 坎（水）→ 水往下
↓ 虽不稳定 → 潜力无限
```
