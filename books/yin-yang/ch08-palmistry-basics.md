### 手指标准比例

```
理想比例：中指最长
          食指 ≈ 无名指
          小指 ≥ 无名指第一关节
          拇指 ≥ 食指中部

食指 > 无名指 = 理性主导·有领导力
无名指 > 食指 = 感性主导·有创造力
两者相等     = 理性感性平衡
```

## 8.6 手相观察四步法

```html
第一步：定掌形 ─── 观整体
  │   ├── 大小（与身材比例）
  │   ├── 厚薄（肉多还是骨感）
  │   ├── 软硬（柔软/适中/僵硬）
  │   └── 五行分类（木火土金水）
  ▼
第二步：看掌丘 ─── 观局部
  │   ├── 八大丘隆起程度
  │   ├── 丘位颜色和弹性
  │   └── 丘上纹路分布
  ▼
第三步：察掌色 ─── 观状态
  │   ├── 掌心颜色（红润/苍白/发黄）
  │   ├── 掌丘色泽
  │   └── 温度湿度
  ▼
第四步：读掌纹 ─── 观细节
      ├── 三大主线（生命·智慧·感情）
      ├── 次要纹路（事业·财运·健康）
      └── 特殊标记（岛纹·十字·星纹）
```

## 8.7 手温·手软硬·性格对应

```html
手温：
  🔥 温热手 = 热情·主动·易急躁
  🌡️ 正常手 = 平和·动静得宜 ✅ 最理想
  ❄️ 冰冷手 = 内敛·被动·要强社交

手软硬：
  💫 柔软手 = 随和·适应力强（但可能缺乏原则）
  💪 中等手 = 刚柔相济 ✅ 最理想
  🪨 坚硬手 = 意志坚强·固执（缺乏变通）

手湿度：
  💧 干暖 = 开朗热情·人缘好
  💧 干冷 = 内向保守
  💧 湿暖 = 热情但易激动·情绪化
  💧 湿冷 = 敏感·易紧张·焦虑
```
