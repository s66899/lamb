### 架构决策
GH Pages 是纯静态网站 → 无法直接做后端 → 用本地 Node HTTP 服务器托管状态，浏览器定期 POST heartbeat 报到。

### Tracker Server 实现
**文件**：`C:\Users\Lamb\.openclaw\workspace\tracker-server.js`（也备份在 `%TEMP%\tracker-server.js`）

**配置**：
- 端口 4689
- 管理员密码：`lambadmin`（与站点密码分开）
- 持久化：`tracker-data.json`，每 30s 写一次
- CORS：`*` 开放（同源静态站 + 跨域都 OK）

**Endpoints**：
| Method | Path | 说明 | Auth |
|---|---|---|---|
| POST | `/heartbeat` | 浏览器定期上报（30s 一次） | 无 |
| GET | `/devices?pw=lambadmin` | 取设备列表 + 状态 | pw |
| POST | `/kick?pw=lambadmin` {fp} | 把某 fp 标记 kicked=true | pw |
| GET | `/status` | text "tracker alive" | 无 |

**心跳数据**（device fingerprint）：
- `fp`：浏览器指纹（hash canvas+audio+navigator+touchSupport）
- `browser`：UA 解析
- `os`：platform
- `screen`：width×height, colorDepth
- `lang`：navigator.language
- `t`：lastSeen 时间戳

**过期**：
- `lastSeen < 70s 前` ⇒ online=false
- kicked=true ⇒ 该 fp 在 `/heartbeat` 时立即收到 `{kicked:true}`，前端收到后清 localStorage + 跳到登录页

**心跳上报逻辑**（inline script）：
```js
function startHeartbeat() {
  if (HEARTBEAT_INTERVAL) clearInterval(HEARTBEAT_INTERVAL);
  HEARTBEAT_INTERVAL = setInterval(() => {
    if (TRACKER_DISABLED) return;
    try {
      fetch(TRACKER_URL + '/heartbeat', {
        method: 'POST',
        headers: {'Content-Type': 'application/json'},
        body: JSON.stringify(getFingerprintPayload())
      }).then(r => r.json()).then(d => {
        if (d.kicked) {
          localStorage.removeItem(SITE_KEY);
          localStorage.removeItem('lamb_fp');
          location.reload();
        }
      }).catch(() => {});
    } catch (e) {}
  }, 30000);
}
```
